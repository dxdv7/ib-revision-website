Presenting data: bar charts, pie charts and stem-and-leaf plots

Besides frequency tables and histograms, data can be presented as a bar chart (categorical or discrete data, bars of equal width separated by gaps), a pie chart (categories shown as proportional sectors of a circle), or, for small-to-moderate numerical data sets, a stem-and-leaf plot. In a stem-and-leaf plot, each value is split into a "stem" (all but its last digit) and a "leaf" (its last digit); every value's leaf is listed next to its stem, giving a display that shows both the shape of the distribution and every original data value.
Worked exampleTen students' quiz scores (out of 50) are: \(23, 31, 45, 28, 34, 41, 29, 37, 42, 26\). Construct a stem-and-leaf plot, using the tens digit as the stem.
Sorting the values first: \(23,26,28,29,31,34,37,41,42,45\).
Stem \(2\): leaves \(3,6,8,9\)
Stem \(3\): leaves \(1,4,7\)
Stem \(4\): leaves \(1,2,5\)
\[\boxed{\text{Stem } 2 \mid 3,6,8,9 \quad \text{Stem } 3 \mid 1,4,7 \quad \text{Stem } 4 \mid 1,2,5}\]

The five-number summary and box-and-whisker plots

The five-number summary of a data set consists of its minimum, lower quartile \(Q_1\), median, upper quartile \(Q_3\), and maximum, satisfying:
\[\text{minimum} \le Q_1 \le \text{median} \le Q_3 \le \text{maximum}\]A box-and-whisker plot displays this summary graphically: a box is drawn from \(Q_1\) to \(Q_3\) (with a line marking the median inside it), and "whiskers" extend from each end of the box out to the minimum and maximum values.
Worked exampleA sample of students' weekly expenses (in dollars) has five-number summary: minimum \(=38\), \(Q_1=50\), median \(=55\), \(Q_3=61\), maximum \(=68\). Describe the box-and-whisker plot for this data.
The box runs from \(50\) to \(61\), with a line at \(55\) marking the median. The lower whisker extends from \(50\) down to \(38\), and the upper whisker extends from \(61\) up to \(68\).
\[\boxed{\text{Box: } 50 \text{ to } 61 \text{ (median line at } 55\text{); whiskers to } 38 \text{ and } 68}\]

Identifying outliers using the fence method

An observation is classified as an outlier if it lies further than \(1.5 \times IQR\) beyond the nearer quartile. The lower and upper fences are:
\[\text{lower fence} = Q_1 - 1.5 \times IQR, \qquad \text{upper fence} = Q_3 + 1.5 \times IQR\]Any data value below the lower fence or above the upper fence is an outlier. The fences themselves are not data values; they are reference boundaries used only to test for outliers.
Worked exampleUsing the weekly expenses data above (\(Q_1=50\), \(Q_3=61\)), find the outlier fences. A new data set replaces the maximum value \(68\) with \(120\); determine whether \(120\) is an outlier.
\[IQR = Q_3-Q_1 = 61-50 = 11\]\[\text{lower fence} = 50-1.5(11) = 50-16.5 = 33.5\]\[\text{upper fence} = 61+1.5(11) = 61+16.5 = 77.5\]Since \(120 > 77.5\):
\[\boxed{120 \text{ lies beyond the upper fence of } 77.5, \text{ so it is an outlier}}\]

The effect of outliers on the mean and the median

The median is resistant (or robust) to outliers: since it depends only on the position of values in an ordered list, a single extreme value barely affects it. The mean is not resistant: since every value contributes to the sum, a single extreme value can shift the mean substantially. For this reason, the median (with the IQR) is often preferred over the mean (with the standard deviation) when a data set contains outliers or is strongly skewed.
Worked exampleA data set is \(2,3,4,5,6\). Find its mean and median. Then replace the \(6\) with \(50\) (an outlier) and find the new mean and median.
Original: \(\bar{x} = \frac{2+3+4+5+6}{5} = \frac{20}{5} = 4\), and the median (middle value of \(2,3,4,5,6\)) is \(4\).
With the outlier: \(\bar{x} = \frac{2+3+4+5+50}{5} = \frac{64}{5} = 12.8\), while the median of \(2,3,4,5,50\) is still the middle value, \(4\).
\[\boxed{\text{Mean changes from } 4 \text{ to } 12.8, \text{ but the median stays at } 4 \text{ — the median resists the outlier}}\]

Modified box-and-whisker plots

A modified box-and-whisker plot marks outliers individually (often with an asterisk) instead of extending a whisker out to them. Each whisker is drawn only as far as the most extreme data value that is not an outlier; any outliers beyond that point are plotted separately.
Worked exampleThe weekly expenses data (\(Q_1=50\), median \(=55\), \(Q_3=61\), fences \(33.5\) and \(77.5\)) has its maximum value \(68\) replaced by \(120\), with the next-largest value being \(67\). Describe the modified box-and-whisker plot.
Since \(120\) lies beyond the upper fence of \(77.5\), it is an outlier and is plotted as an isolated point rather than extending the whisker. The upper whisker instead extends only to \(67\), the largest value that is not an outlier.
\[\boxed{\text{Box } 50 \text{ to } 61 \text{ (median } 55\text{); upper whisker to } 67; \text{ outlier marked separately at } 120}\]
