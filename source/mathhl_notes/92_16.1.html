First order differential equations and initial conditions

A first order differential equation relates an unknown function \(y=y(x)\) to its first derivative, and possibly to \(x\) and \(y\) themselves:
\[\frac{dy}{dx} = f(x,y)\]Such an equation generally has infinitely many solution curves, one through almost every point of the plane. Specifying a single point as an initial condition, \(y(x_0)=y_0\), singles out one particular solution curve from this family; the equation together with this condition is called an initial value problem.
Worked exampleVerify that \(y=x^2+1\) is a solution of the initial value problem \(\dfrac{dy}{dx}=2x\), \(y(0)=1\).
Differentiating, \(\frac{dy}{dx}=2x\), which matches the right-hand side of the equation for all \(x\). Checking the initial condition: at \(x=0\), \(y=0^2+1=1\), as required.
\[\boxed{y=x^2+1 \text{ satisfies both the equation and the initial condition}}\]

Euler's method: stepping along the tangent direction

When a differential equation \(\dfrac{dy}{dx}=f(x,y)\) cannot be (or need not be) solved exactly, its solution curve through \((x_0,y_0)\) can be approximated numerically. At each point, the differential equation gives the gradient of the solution curve. Euler's method starts at the known point \((x_0,y_0)\) and moves a short horizontal distance \(h\), the step size, along the tangent line at that point (rather than along the true, curved solution), arriving at an approximate new point. Repeating this at the new point, using the gradient there, builds up a sequence of straight-line steps that approximates the solution curve.
Worked exampleFor \(\dfrac{dy}{dx}=x^2\) with \(y(1)=2\), use one Euler step of size \(h=0.1\) to approximate \(y(1.1)\).
The gradient at \((x_0,y_0)=(1,2)\) is \(f(1,2)=1^2=1\). Moving along the tangent line:
\[y(1.1) \approx y_0 + h\cdot f(x_0,y_0) = 2+0.1(1)=2.1\]\[\boxed{y(1.1)\approx 2.1}\]

The Euler iteration formula

Given \(\dfrac{dy}{dx}=f(x,y)\), an initial point \((x_0,y_0)\), and a fixed step size \(h\), successive approximations are generated by:
\[x_{n+1}=x_n+h, \qquad y_{n+1} = y_n + h\cdot f(x_n,y_n)\]Each new \(y\)-value is found by adding \(h\) times the gradient at the current point to the current \(y\)-value. Repeating this \(n\) times produces an approximation for the solution at \(x_n = x_0+nh\).
Worked exampleGiven \(\dfrac{dy}{dx}=x+y\), \(y(0)=1\), use Euler's method with step size \(h=0.1\) to approximate \(y(0.3)\).
Step 1: at \((x_0,y_0)=(0,1)\), \(f(0,1)=0+1=1\):
\[y_1 = 1+0.1(1)=1.1, \qquad x_1=0.1\]Step 2: at \((x_1,y_1)=(0.1,1.1)\), \(f(0.1,1.1)=0.1+1.1=1.2\):
\[y_2 = 1.1+0.1(1.2)=1.22, \qquad x_2=0.2\]Step 3: at \((x_2,y_2)=(0.2,1.22)\), \(f(0.2,1.22)=0.2+1.22=1.42\):
\[y_3 = 1.22+0.1(1.42)=1.362, \qquad x_3=0.3\]\[\boxed{y(0.3)\approx 1.362}\]

Step size and accuracy

Euler's method follows the tangent line rather than the true, curved solution, so each step introduces a small error. A smaller step size \(h\) means the straight-line steps stay closer to the curve for longer before the gradient is recalculated, which generally gives a more accurate final approximation — at the cost of needing more steps (more arithmetic) to reach the same value of \(x\). Halving \(h\) roughly halves the error introduced per step, though the number of steps needed doubles.
Worked exampleFor \(\dfrac{dy}{dx}=y\), \(y(0)=1\) (exact solution \(y=e^x\), so \(y(0.2)=e^{0.2}\approx1.2214\)), compare Euler approximations for \(y(0.2)\) using \(h=0.2\) (one step) and \(h=0.1\) (two steps).
With \(h=0.2\): \(y_1 = 1+0.2(1)=1.2\).
With \(h=0.1\): \(y_1=1+0.1(1)=1.1\), then \(y_2=1.1+0.1(1.1)=1.21\).
The one-step estimate \(1.2\) is further from \(1.2214\) than the two-step estimate \(1.21\).
\[\boxed{\text{Smaller } h=0.1 \text{ gives } y(0.2)\approx1.21\text{, closer to the exact value }1.2214}\]

Euler's method with a different differential equation

The same iteration formula \(y_{n+1}=y_n+h\cdot f(x_n,y_n)\) applies regardless of the particular form of \(f(x,y)\); only the function being evaluated at each step changes.
Worked exampleGiven \(\dfrac{dy}{dx}=2x-y\), \(y(0)=1\), use Euler's method with step size \(h=0.2\) to approximate \(y(0.4)\).
Step 1: at \((x_0,y_0)=(0,1)\), \(f(0,1)=2(0)-1=-1\):
\[y_1 = 1+0.2(-1)=0.8, \qquad x_1=0.2\]Step 2: at \((x_1,y_1)=(0.2,0.8)\), \(f(0.2,0.8)=2(0.2)-0.8=-0.4\):
\[y_2 = 0.8+0.2(-0.4)=0.72, \qquad x_2=0.4\]\[\boxed{y(0.4)\approx 0.72}\]
