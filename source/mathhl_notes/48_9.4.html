The vector equation of a line

A line in 2D or 3D is uniquely determined by a known point on it and a direction vector parallel to it. If \(\mathbf{a}\) is the position vector of a known point \(A\) on the line and \(\mathbf{b}\) is a direction vector parallel to the line, then the position vector \(\mathbf{r}\) of any point on the line satisfies:
\[\mathbf{r} = \mathbf{a} + \lambda\mathbf{b}\]where \(\lambda\) is a scalar parameter. As \(\lambda\) varies over all real numbers, \(\mathbf{r}\) traces out every point on the line.
Worked exampleFind a vector equation of the line through the point \(A(2,-1,4)\) and parallel to \(\mathbf{b} = \begin{pmatrix}3\\-2\\1\end{pmatrix}\).
Here \(\mathbf{a} = \begin{pmatrix}2\\-1\\4\end{pmatrix}\), so:
\[\boxed{\mathbf{r} = \begin{pmatrix}2\\-1\\4\end{pmatrix} + \lambda\begin{pmatrix}3\\-2\\1\end{pmatrix}}\]

Parametric (component) form

Writing \(\mathbf{r} = \begin{pmatrix}x\\y\\z\end{pmatrix}\), \(\mathbf{a} = \begin{pmatrix}x_0\\y_0\\z_0\end{pmatrix}\), and \(\mathbf{b} = \begin{pmatrix}b_1\\b_2\\b_3\end{pmatrix}\), the vector equation \(\mathbf{r} = \mathbf{a}+\lambda\mathbf{b}\) splits into three parametric equations, one per component:
\[x = x_0+\lambda b_1, \qquad y = y_0+\lambda b_2, \qquad z = z_0+\lambda b_3\]
Worked exampleWrite the parametric equations of the line through \(A(2,-1,4)\) with direction vector \(\mathbf{b} = \begin{pmatrix}3\\-2\\1\end{pmatrix}\).
\[\boxed{x = 2+3\lambda, \qquad y = -1-2\lambda, \qquad z = 4+\lambda}\]

The line through two given points

If a line passes through two known points \(A\) and \(B\) with position vectors \(\mathbf{a}\) and \(\mathbf{b}\), a direction vector for the line is \(\overrightarrow{AB} = \mathbf{b}-\mathbf{a}\), giving the vector equation:
\[\mathbf{r} = \mathbf{a} + \lambda(\mathbf{b}-\mathbf{a})\]
Worked exampleFind a vector equation of the line through \(A(1,0,-2)\) and \(B(4,3,1)\).
\[\overrightarrow{AB} = \begin{pmatrix}4-1\\3-0\\1-(-2)\end{pmatrix} = \begin{pmatrix}3\\3\\3\end{pmatrix}\]\[\boxed{\mathbf{r} = \begin{pmatrix}1\\0\\-2\end{pmatrix} + \lambda\begin{pmatrix}3\\3\\3\end{pmatrix}}\]

Checking whether a point lies on a line

A point \(P\) lies on the line \(\mathbf{r} = \mathbf{a}+\lambda\mathbf{b}\) exactly when there is a single value of \(\lambda\) that satisfies all three component equations at once, using \(P\)'s coordinates. If the component equations give inconsistent values of \(\lambda\), then \(P\) does not lie on the line.
Worked exampleDetermine whether \(P(8,-5,6)\) lies on the line \(\mathbf{r} = \begin{pmatrix}2\\-1\\4\end{pmatrix} + \lambda\begin{pmatrix}3\\-2\\1\end{pmatrix}\).
\[2+3\lambda = 8 \Rightarrow \lambda = 2, \qquad -1-2\lambda = -5 \Rightarrow \lambda = 2, \qquad 4+\lambda = 6 \Rightarrow \lambda = 2\]All three component equations agree on \(\lambda = 2\):
\[\boxed{P(8,-5,6) \text{ lies on the line, at } \lambda = 2}\]

Intersection of a line with a coordinate plane

A line crosses the \(xy\)-plane where \(z=0\), the \(xz\)-plane where \(y=0\), and the \(yz\)-plane where \(x=0\). Substitute the corresponding component equation set equal to \(0\), solve for \(\lambda\), then substitute that value of \(\lambda\) back into the other two component equations.
Worked exampleFind the point where the line \(\mathbf{r} = \begin{pmatrix}2\\-1\\4\end{pmatrix} + \lambda\begin{pmatrix}3\\-2\\1\end{pmatrix}\) crosses the \(xy\)-plane.
The \(xy\)-plane is where \(z=0\):
\[4+\lambda = 0 \Rightarrow \lambda = -4\]\[x = 2+3(-4) = -10, \qquad y = -1-2(-4) = 7\]\[\boxed{\text{The line crosses the } xy\text{-plane at } (-10,7,0)}\]

Equivalent vector equations of the same line

The vector equation of a line is not unique. Replacing \(\mathbf{a}\) with the position vector of any other point on the line, or replacing \(\mathbf{b}\) with any nonzero scalar multiple of itself, still describes exactly the same line.
Worked exampleShow that \(\mathbf{r} = \begin{pmatrix}5\\-3\\5\end{pmatrix} + \mu\begin{pmatrix}6\\-4\\2\end{pmatrix}\) describes the same line as \(\mathbf{r} = \begin{pmatrix}2\\-1\\4\end{pmatrix} + \lambda\begin{pmatrix}3\\-2\\1\end{pmatrix}\).
Checking that \((5,-3,5)\) lies on the original line: \(2+3\lambda=5\), \(-1-2\lambda=-3\), and \(4+\lambda=5\) all give \(\lambda=1\), so the point lies on the original line.
Checking the direction vectors: \(\begin{pmatrix}6\\-4\\2\end{pmatrix} = 2\begin{pmatrix}3\\-2\\1\end{pmatrix}\), so they are parallel.
\[\boxed{\text{The new equation uses a point on the original line and a parallel direction vector, so it is the same line}}\]
