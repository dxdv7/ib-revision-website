First order linear differential equations

A first order differential equation is linear if the unknown function \(y\) and its derivative \(\dfrac{dy}{dx}\) each appear only to the first power, with no products such as \(y\cdot\dfrac{dy}{dx}\). Its standard form is:
\[\frac{dy}{dx} + P(x)y = Q(x)\]where \(P(x)\) and \(Q(x)\) are functions of \(x\) only. Equations that are not already written this way can often be rearranged algebraically into this standard form before being solved.
Worked exampleWrite \(x\dfrac{dy}{dx} - y = x^2\) (for \(x>0\)) in standard form, and identify \(P(x)\) and \(Q(x)\).
Dividing every term by \(x\):
\[\frac{dy}{dx} - \frac{1}{x}y = x\]\[\boxed{P(x) = -\frac{1}{x}, \qquad Q(x) = x}\]

The integrating factor

For an equation in standard form \(\dfrac{dy}{dx}+P(x)y=Q(x)\), the integrating factor is:
\[I(x) = e^{\int P(x)\,dx}\]Multiplying every term of the standard form equation by \(I(x)\) makes the left-hand side exactly the derivative of a product, \(\dfrac{d}{dx}\big[I(x)y\big]\), because:
\[\frac{d}{dx}\big[I(x)y\big] = I(x)\frac{dy}{dx} + I'(x)y = I(x)\frac{dy}{dx}+I(x)P(x)y\]using \(I'(x)=P(x)e^{\int P(x)\,dx}=P(x)I(x)\). This is exactly \(I(x)\) times the left-hand side of the standard form equation, so multiplying the whole equation by \(I(x)\) and recognising this derivative is what makes the equation solvable by direct integration.
Worked exampleFind the integrating factor for \(\dfrac{dy}{dx}+\dfrac{2}{x}y = x^3\) (\(x>0\)).
Here \(P(x)=\dfrac{2}{x}\), so \(\displaystyle\int P(x)\,dx = 2\ln x = \ln x^2\):
\[\boxed{I(x) = e^{\ln x^2} = x^2}\]

Solving a linear differential equation using an integrating factor

Once the integrating factor \(I(x)\) has been found and the equation multiplied through by it, the left-hand side collapses to \(\dfrac{d}{dx}\big[I(x)y\big]\). Integrating both sides with respect to \(x\) then gives:
\[I(x)y = \int I(x)Q(x)\,dx + C\]which is rearranged to give \(y\) explicitly in terms of \(x\).
Worked exampleFind the general solution of \(\dfrac{dy}{dx}+2y = e^{-x}\).
Here \(P(x)=2\), so the integrating factor is \(I(x)=e^{\int 2\,dx}=e^{2x}\). Multiplying through:
\[e^{2x}\frac{dy}{dx}+2e^{2x}y = e^{2x}e^{-x} = e^{x}\]The left-hand side is \(\dfrac{d}{dx}\big[e^{2x}y\big]\), so:
\[\frac{d}{dx}\big[e^{2x}y\big] = e^{x}\]Integrating both sides: \(e^{2x}y = e^{x}+C\). Dividing by \(e^{2x}\):
\[\boxed{y = e^{-x} + Ce^{-2x}}\]Differentiating confirms this: \(\frac{dy}{dx}=-e^{-x}-2Ce^{-2x}\), and \(\frac{dy}{dx}+2y = -e^{-x}-2Ce^{-2x}+2e^{-x}+2Ce^{-2x}=e^{-x}\).

Using an initial condition with the integrating factor method

As with separable equations, the general solution produced by the integrating factor method contains an arbitrary constant \(C\). Substituting a given initial condition \(y(x_0)=y_0\) into the general solution determines the value of \(C\), giving the particular solution that passes through \((x_0,y_0)\).
Worked exampleFind the particular solution of \(\dfrac{dy}{dx}+2y=e^{-x}\) satisfying \(y(0)=0\).
From above, the general solution is \(y=e^{-x}+Ce^{-2x}\). Substituting \(x=0,\ y=0\):
\[0 = e^{0}+Ce^{0} = 1+C \implies C=-1\]\[\boxed{y = e^{-x} - e^{-2x}}\]Checking: at \(x=0\), \(y=1-1=0\), as required.

A second worked example with a different linear equation

The integrating factor method applies in exactly the same way whenever an equation can be written in the standard linear form \(\dfrac{dy}{dx}+P(x)y=Q(x)\), even when \(P(x)\) is not constant.
Worked exampleSolve \(\dfrac{dy}{dx}-\dfrac{1}{x}y = x\) (\(x>0\)), given \(y(1)=3\).
Here \(P(x)=-\dfrac{1}{x}\), so \(\displaystyle\int P(x)\,dx = -\ln x\), giving integrating factor \(I(x)=e^{-\ln x}=\dfrac{1}{x}\). Multiplying through by \(\dfrac{1}{x}\):
\[\frac{1}{x}\frac{dy}{dx} - \frac{1}{x^2}y = 1 \implies \frac{d}{dx}\left[\frac{y}{x}\right] = 1\]Integrating both sides: \(\dfrac{y}{x} = x+C\), so \(y = x^2+Cx\). Applying the initial condition \(x=1,\ y=3\): \(3 = 1+C\), so \(C=2\):
\[\boxed{y = x^2 + 2x}\]Differentiating confirms this: \(\frac{dy}{dx}=2x+2\), and \(\frac{dy}{dx}-\frac{1}{x}y = 2x+2-\frac{x^2+2x}{x}=2x+2-x-2=x\).
