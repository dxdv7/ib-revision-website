The structure of proof by contradiction

To prove that a statement \(P\) is true by contradiction: assume \(\neg P\) (the negation of what we want to prove); use valid logical and algebraic steps to derive a statement that is a genuine logical impossibility, such as "this integer is both even and odd" or "\(1=0\)"; then conclude that the assumption \(\neg P\) must be false, so \(P\) must be true.
Worked exampleProve that if \(m\) is a rational number and \(n\) is an irrational number, then \(m+n\) is irrational.
Assume, for contradiction, that \(m+n\) is rational. Since \(m\) is rational, \(m = \dfrac{a}{b}\) for integers \(a, b\) with \(b \neq 0\). Since \(m+n\) is rational, \(m+n = \dfrac{c}{d}\) for integers \(c, d\) with \(d \neq 0\). Then
\[n = (m+n)-m = \frac{c}{d}-\frac{a}{b} = \frac{cb-ad}{bd}\]Since \(cb-ad\) and \(bd\) are integers with \(bd \neq 0\), this shows \(n\) is rational. This contradicts the assumption that \(n\) is irrational.
Since the assumption leads to a contradiction, it must be false, and so
\[\boxed{\text{if } m \text{ is rational and } n \text{ is irrational, then } m+n \text{ is irrational}}\]

The classic proof that the square root of 2 is irrational

A real number is rational if it can be written as \(\dfrac{m}{n}\) in lowest terms, for integers \(m\) and \(n\) with \(n \neq 0\) and no common factor other than 1. A real number that cannot be written this way is irrational. Proof by contradiction is the standard method for showing a given number is irrational, since "irrational" itself has no constructive form to work with directly.
Worked exampleProve that \(\sqrt{2}\) is irrational.
Assume, for contradiction, that \(\sqrt{2}\) is rational. Then \(\sqrt{2} = \dfrac{m}{n}\) in lowest terms, for integers \(m, n\) with \(n \neq 0\) and \(\gcd(m,n)=1\). Squaring both sides:
\[2 = \frac{m^2}{n^2} \quad \implies \quad m^2 = 2n^2\]So \(m^2\) is even. By the contrapositive result that "if \(n^2\) is even then \(n\) is even", \(m\) itself must be even, so \(m = 2k\) for some integer \(k\). Substituting:
\[(2k)^2 = 2n^2 \quad \implies \quad 4k^2 = 2n^2 \quad \implies \quad n^2 = 2k^2\]So \(n^2\) is also even, and hence \(n\) is also even. But then both \(m\) and \(n\) are even, so they share the common factor 2. This contradicts the assumption that \(\gcd(m,n)=1\).
Since the assumption leads to a contradiction,
\[\boxed{\sqrt{2} \text{ is irrational}}\]

A second contradiction proof with integers

Many contradiction proofs about integers follow the same shape as the proof for \(\sqrt{2}\): assume the negation of the conclusion, rewrite it using the definition of even or odd, substitute into the hypothesis, and simplify until the hypothesis is shown to fail.
Worked exampleProve that for an integer \(n\), if \(3n+2\) is odd, then \(n\) is odd.
Assume, for contradiction, that \(3n+2\) is odd but \(n\) is not odd, that is, \(n\) is even. Then \(n = 2k\) for some integer \(k\), so
\[3n+2 = 3(2k)+2 = 6k+2 = 2(3k+1)\]which is even. This contradicts the assumption that \(3n+2\) is odd.
Since the assumption leads to a contradiction,
\[\boxed{\text{if } 3n+2 \text{ is odd, then } n \text{ is odd}}\]

Disproof by counterexample

A universal statement of the form "for every \(x\), \(P(x) \implies Q(x)\)" is disproved by a single counterexample: one value of \(x\) for which \(P(x)\) is true but \(Q(x)\) is false. Unlike a proof, which must cover every possible case, a disproof by counterexample needs only one concrete case where the statement fails.
Worked exampleDisprove the statement: "For integers \(m, n, k\), if \(m\) is divisible by \(n\), then \(m\) is divisible by \(kn\)."
Take \(m = 18\), \(n = 3\), \(k = 5\). Then \(18\) is divisible by \(3\), since \(18 = 3 \times 6\), so the hypothesis holds. But \(kn = 15\), and \(18\) is not divisible by \(15\), since \(\dfrac{18}{15}\) is not an integer, so the conclusion fails.
Since this single case satisfies the hypothesis but not the conclusion,
\[\boxed{\text{the statement is false: } m=18, n=3, k=5 \text{ is a counterexample}}\]

Counterexamples to claims about divisors

When a claimed statement involves negative integers, a counterexample can often be found by letting one quantity be the negative of another, since divisibility by negative integers behaves differently from what intuition based on positive integers suggests.
Worked exampleDisprove the statement: "For integers \(a\) and \(b\), if \(a \mid b\) and \(b \mid a\), then \(a = b\)."
Take \(a = 5\) and \(b = -5\). Then \(b = a \times (-1)\), so \(a \mid b\); and \(a = b \times (-1)\), so \(b \mid a\). Both conditions in the hypothesis hold, but \(a = 5 \neq -5 = b\), so the conclusion fails.
\[\boxed{\text{the statement is false: } a=5, b=-5 \text{ is a counterexample}}\]

Counterexamples to algebraic inequalities

A claimed inequality that is meant to hold "for all real \(x\)" can often be disproved by testing a value of \(x\) between 0 and 1, since squaring or other operations behave differently there than for integers or large numbers.
Worked exampleDisprove the statement: "For every real number \(x\), \(x^2 \geq x\)."
Take \(x = \dfrac{1}{2}\). Then
\[x^2 = \left(\frac{1}{2}\right)^2 = \frac{1}{4}\]and \(\dfrac{1}{4} < \dfrac{1}{2}\), so \(x^2 < x\) for this value, and the claimed inequality fails.
\[\boxed{\text{the statement is false: } x = \tfrac{1}{2} \text{ is a counterexample}}\]
