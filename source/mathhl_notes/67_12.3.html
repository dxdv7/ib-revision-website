Increasing and decreasing functions

A function \(f\) is increasing on an interval if its graph rises as \(x\) increases across that interval, and decreasing if its graph falls as \(x\) increases. Since \(f'(x)\) gives the gradient of the tangent at \(x\):
\[\text{If } f'(x) > 0 \text{ for all } x \text{ in } (a,b), \text{ then } f \text{ is increasing on } (a,b)\]\[\text{If } f'(x) < 0 \text{ for all } x \text{ in } (a,b), \text{ then } f \text{ is decreasing on } (a,b)\]
Worked exampleGiven \(f(x) = x^2\), with derivative \(f'(x) = 2x\), determine whether \(f\) is increasing or decreasing at \(x=3\) and at \(x=-3\).
\[f'(3) = 2(3) = 6 > 0, \qquad f'(-3) = 2(-3) = -6 < 0\]\[\boxed{f \text{ is increasing at } x=3 \text{ (since } f'(3)>0\text{) and decreasing at } x=-3 \text{ (since } f'(-3)<0\text{)}}\]

Stationary points

A point where \(f'(x) = 0\) is called a stationary point: the tangent to the curve is horizontal there, and the function is (instantaneously) neither increasing nor decreasing. Stationary points are found by solving the equation \(f'(x)=0\).
Worked exampleFind the \(x\)-coordinate of the stationary point of \(f(x) = x^2 - 6x + 5\).
First find the derivative:
\[f'(x) = 2x - 6\]Set the derivative equal to zero and solve:
\[2x-6 = 0 \implies x = 3\]\[\boxed{\text{The stationary point occurs at } x=3}\]

Using the sign of the derivative to find intervals of increase and decrease

Once the values of \(x\) where \(f'(x)=0\) are found, these values divide the domain into separate intervals. Since \(f'(x)\) changes sign only at such values (for a continuous derivative), one representative test value from each interval can be substituted into \(f'(x)\) to determine the sign of the derivative — and hence whether \(f\) is increasing or decreasing — throughout that entire interval.
Worked exampleFor \(f(x) = x^2 - 6x + 5\), with \(f'(x)=2x-6\) and stationary point at \(x=3\) (from above), determine the intervals on which \(f\) is increasing and decreasing.
Test a value in each of the two intervals \(x<3\) and \(x>3\):
\[f'(0) = 2(0)-6 = -6 < 0 \quad \text{(so } f'(x)<0 \text{ for all } x<3\text{)}\]\[f'(4) = 2(4)-6 = 2 > 0 \quad \text{(so } f'(x)>0 \text{ for all } x>3\text{)}\]\[\boxed{f \text{ is decreasing on } (-\infty,3) \text{ and increasing on } (3,\infty)}\]

Sign diagrams for the derivative

A sign diagram summarises the sign of \(f'(x)\) across the whole domain on a single number line: the critical values where \(f'(x)=0\) are marked, and a \(+\) or \(-\) is written in each resulting interval to show whether \(f\) is increasing or decreasing there. A change in sign of \(f'(x)\) at a critical value indicates that \(f\) switches between increasing and decreasing at that point.
Worked exampleConstruct a sign diagram for \(f'(x)\) given \(f(x) = x^2 - 6x + 5\), and use it to classify the stationary point at \(x=3\).
From above, \(f'(x)<0\) for \(x<3\) and \(f'(x)>0\) for \(x>3\), with \(f'(3)=0\). The sign diagram is:
\[x<3:\ f'(x)<0\ (-) \qquad x=3:\ f'(x)=0 \qquad x>3:\ f'(x)>0\ (+)\]Since the sign of \(f'(x)\) changes from negative to positive as \(x\) passes through \(3\), the curve changes from decreasing to increasing there.
\[\boxed{x=3 \text{ is a minimum point, since } f' \text{ changes from } - \text{ to } +}\]

Increasing and decreasing behaviour of cubic and trigonometric functions

The same method — differentiate, solve \(f'(x)=0\) to locate critical values, then test the sign of \(f'(x)\) in each resulting interval — applies to any differentiable function, including cubics (which may have two stationary points) and combinations involving \(\sin x\) and \(\cos x\).
Worked exampleFind the intervals on which \(f(x) = x^3 - 3x\) is increasing and decreasing.
Differentiate:
\[f'(x) = 3x^2 - 3 = 3(x^2-1) = 3(x-1)(x+1)\]Set \(f'(x)=0\): critical values at \(x=-1\) and \(x=1\), dividing the domain into three intervals. Testing a point in each:
\[f'(-2) = 3(4)-3 = 9 > 0, \quad f'(0) = 3(0)-3 = -3 < 0, \quad f'(2) = 3(4)-3 = 9 > 0\]\[\boxed{f \text{ is increasing on } (-\infty,-1) \text{ and } (1,\infty), \text{ and decreasing on } (-1,1)}\]
