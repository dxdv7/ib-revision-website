The angle between a line and a plane

The angle \(\theta\) between a line with direction vector \(\mathbf{d}\) and a plane with normal vector \(\mathbf{n}\) is defined as the angle between the line and its projection onto the plane. Since \(\mathbf{n}\) is perpendicular to the plane, \(\theta\) is the complement of the angle \(\phi\) between \(\mathbf{d}\) and \(\mathbf{n}\) themselves, so \(\theta = 90^\circ - \phi\). Since \(\cos\phi = \frac{\mathbf{d}\cdot\mathbf{n}}{|\mathbf{d}||\mathbf{n}|}\) and \(\sin\theta = \cos\phi\):
\[\sin\theta = \frac{|\mathbf{d}\cdot\mathbf{n}|}{|\mathbf{d}||\mathbf{n}|}\]The absolute value keeps \(\theta\) the acute angle, between \(0^\circ\) and \(90^\circ\). Note that this formula uses sine, not cosine, precisely because it measures the complement of the angle between the line and the normal.
Worked exampleFind the angle between the line with direction vector \(\mathbf{d}=\begin{pmatrix}1\\2\\2\end{pmatrix}\) and the plane with normal vector \(\mathbf{n}=\begin{pmatrix}2\\2\\1\end{pmatrix}\).
\[\mathbf{d}\cdot\mathbf{n} = 1(2)+2(2)+2(1) = 2+4+2=8\]\[|\mathbf{d}| = \sqrt{1^2+2^2+2^2} = \sqrt{9} = 3, \qquad |\mathbf{n}| = \sqrt{2^2+2^2+1^2} = \sqrt{9} = 3\]\[\sin\theta = \frac{|8|}{3 \times 3}\]\[\boxed{\sin\theta = \frac{8}{9}, \text{ so } \theta = \sin^{-1}\left(\frac{8}{9}\right)}\]

Lines perpendicular to a plane

If the direction vector \(\mathbf{d}\) of a line is parallel to the normal vector \(\mathbf{n}\) of a plane, that is \(\mathbf{d}\) is a scalar multiple of \(\mathbf{n}\), then the line is perpendicular to the plane. In this case \(|\mathbf{d}\cdot\mathbf{n}| = |\mathbf{d}||\mathbf{n}|\), so \(\sin\theta=1\) and \(\theta=90^\circ\).
Worked exampleFind the angle between the line \(\mathbf{r}=\begin{pmatrix}2\\1\\0\end{pmatrix}+t\begin{pmatrix}2\\-2\\1\end{pmatrix}\) and the plane \(2x-2y+z=3\).
The direction vector is \(\mathbf{d}=\begin{pmatrix}2\\-2\\1\end{pmatrix}\) and the normal vector is \(\mathbf{n}=\begin{pmatrix}2\\-2\\1\end{pmatrix}\). Since \(\mathbf{d}=\mathbf{n}\), \(\mathbf{d}\) is a scalar multiple of \(\mathbf{n}\) with scalar \(1\), so the line is perpendicular to the plane:
\[\boxed{\theta = 90^\circ}\]

Lines parallel to a plane

If a line's direction vector \(\mathbf{d}\) is perpendicular to a plane's normal vector \(\mathbf{n}\), that is \(\mathbf{d}\cdot\mathbf{n}=0\), then \(\sin\theta=0\) and the angle between the line and the plane is \(0^\circ\). The line is then either strictly parallel to the plane, meeting it nowhere, or it lies entirely within the plane.
Worked exampleFind the angle between the line \(\mathbf{r}=\begin{pmatrix}0\\0\\0\end{pmatrix}+s\begin{pmatrix}1\\1\\0\end{pmatrix}\) and the plane \(x-y+2z=5\).
The direction vector is \(\mathbf{d}=\begin{pmatrix}1\\1\\0\end{pmatrix}\) and the normal vector is \(\mathbf{n}=\begin{pmatrix}1\\-1\\2\end{pmatrix}\).
\[\mathbf{d}\cdot\mathbf{n} = 1(1)+1(-1)+0(2) = 1-1+0=0\]\[\boxed{\sin\theta=0, \text{ so } \theta=0^\circ \text{ and the line is parallel to the plane}}\]

The angle between two planes

The angle \(\theta\) between two planes with normal vectors \(\mathbf{n_1}\) and \(\mathbf{n_2}\) is defined as the acute angle between them. This is equal to the acute angle between the normals themselves, found directly using the standard dot-product cosine formula:
\[\cos\theta = \frac{|\mathbf{n_1}\cdot\mathbf{n_2}|}{|\mathbf{n_1}||\mathbf{n_2}|}\]Unlike the line-and-plane case, this formula uses cosine, since the angle between the planes is being compared directly with the angle between their normal vectors, with no complement involved. The absolute value again ensures \(\theta\) is between \(0^\circ\) and \(90^\circ\).
Worked exampleFind the angle between the planes \(P: x+2y-2z=5\) and \(Q: 2x-y+2z=3\).
The normal vectors are \(\mathbf{n_1}=\begin{pmatrix}1\\2\\-2\end{pmatrix}\) and \(\mathbf{n_2}=\begin{pmatrix}2\\-1\\2\end{pmatrix}\).
\[\mathbf{n_1}\cdot\mathbf{n_2} = 1(2)+2(-1)+(-2)(2) = 2-2-4=-4\]\[|\mathbf{n_1}| = \sqrt{1^2+2^2+2^2} = \sqrt{9} = 3, \qquad |\mathbf{n_2}| = \sqrt{2^2+1^2+2^2} = \sqrt{9} = 3\]\[\cos\theta = \frac{|-4|}{3\times 3}\]\[\boxed{\cos\theta = \frac{4}{9}, \text{ so } \theta = \cos^{-1}\left(\frac{4}{9}\right)}\]

Parallel planes

Two planes are parallel if their normal vectors are scalar multiples of each other. If the normals are also equal up to a scalar multiple that makes their equations identical, the planes coincide; otherwise they are distinct parallel planes, which never intersect.
Worked exampleShow that the planes \(P: x+y+z=4\) and \(Q: 2x+2y+2z=9\) are parallel, and determine whether they are the same plane.
The normal vectors are \(\mathbf{n_1}=\begin{pmatrix}1\\1\\1\end{pmatrix}\) and \(\mathbf{n_2}=\begin{pmatrix}2\\2\\2\end{pmatrix}=2\mathbf{n_1}\), so the normals are scalar multiples of each other and the planes are parallel. Dividing \(Q\) by \(2\) gives \(x+y+z=4.5\), which has a different constant from \(P\)'s equation \(x+y+z=4\).
\[\boxed{\text{the planes are parallel but distinct, since } 4 \ne 4.5}\]

Perpendicular planes

Two planes are perpendicular if their normal vectors are perpendicular, that is \(\mathbf{n_1}\cdot\mathbf{n_2}=0\). This corresponds to \(\cos\theta=0\) in the angle formula, giving \(\theta=90^\circ\).
Worked exampleShow that the planes \(P: x+y=3\) and \(Q: x-y+z=2\) are perpendicular.
The normal vectors are \(\mathbf{n_1}=\begin{pmatrix}1\\1\\0\end{pmatrix}\) and \(\mathbf{n_2}=\begin{pmatrix}1\\-1\\1\end{pmatrix}\).
\[\mathbf{n_1}\cdot\mathbf{n_2} = 1(1)+1(-1)+0(1) = 1-1+0=0\]\[\boxed{\cos\theta=0, \text{ so } \theta=90^\circ \text{ and the planes are perpendicular}}\]
