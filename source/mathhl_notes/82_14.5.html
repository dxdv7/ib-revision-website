Integration by inspection: reversing the chain rule

For an integrand of the form \(f(g(x))\cdot g'(x)\), a common shortcut is to guess an antiderivative based on the "outer" structure, then differentiate the guess to check it, adjusting by a constant factor if needed. For a power of a linear expression:
\[\int (ax+b)^n\,dx = \frac{(ax+b)^{n+1}}{a(n+1)}+C \qquad (n\neq -1)\]This is simply the chain rule run backwards: differentiating the right-hand side brings down the factor \(a(n+1)\) from the power rule and the chain rule, which cancels with the denominator.
Worked exampleEvaluate \(\int (2x+1)^4\,dx\) by inspection.
Guess \((2x+1)^5\). Differentiating gives \(5(2x+1)^4 \cdot 2 = 10(2x+1)^4\), which is \(10\) times too large, so divide the guess by \(10\):
\[\boxed{\int (2x+1)^4\,dx = \frac{(2x+1)^5}{10}+C}\]

A shortcut for linear inner functions

More generally, if \(F\) is an antiderivative of \(f\), then for a linear inner function \(ax+b\):
\[\int f(ax+b)\,dx = \frac{1}{a}F(ax+b)+C\]This follows because the chain rule contributes an extra factor of \(a\) (the derivative of the inner function) whenever \(F(ax+b)\) is differentiated, so dividing by \(a\) exactly compensates.
Worked exampleUse the linear inner function rule to evaluate (a) \(\int e^{5x}\,dx\) and (b) \(\int \cos(3x)\,dx\).
(a) Here \(f(u)=e^u\) with antiderivative \(F(u)=e^u\), and \(a=5\):
\[\int e^{5x}\,dx = \frac{1}{5}e^{5x}+C\]
(b) Here \(f(u)=\cos u\) with antiderivative \(F(u)=\sin u\), and \(a=3\):
\[\boxed{\int e^{5x}\,dx = \frac{e^{5x}}{5}+C, \qquad \int \cos(3x)\,dx = \frac{\sin(3x)}{3}+C}\]

u-substitution as a systematic method

When the inner function is not linear, inspection becomes harder to guess directly, so a systematic substitution is used. Let \(u=g(x)\) be a chosen inner function, so that \(du=g'(x)\,dx\). Rewrite the entire integral in terms of \(u\) only, integrate with respect to \(u\), then substitute \(g(x)\) back in for \(u\):
\[\int f(g(x))\cdot g'(x)\,dx = \int f(u)\,du = F(u)+C = F(g(x))+C\]A good choice of \(u\) is usually an inner expression whose derivative (up to a constant multiple) also appears in the integrand.
Worked exampleEvaluate \(\int 2x(x^2+1)^3\,dx\) using substitution.
Let \(u=x^2+1\), so \(du=2x\,dx\). The integrand already contains exactly \(2x\,dx\), so:
\[\int 2x(x^2+1)^3\,dx = \int u^3\,du = \frac{u^4}{4}+C\]Substituting back \(u=x^2+1\):
\[\boxed{\int 2x(x^2+1)^3\,dx = \frac{(x^2+1)^4}{4}+C}\]

Substitution with a missing constant factor

If the derivative of the chosen \(u\) is present only up to a missing constant multiple, multiply the integrand by that constant and divide by it outside the integral (or equivalently solve \(du=g'(x)\,dx\) for \(dx\) and substitute directly). The constant can always be pulled outside the integral sign since it does not depend on \(x\).
Worked exampleEvaluate \(\int x(x^2+1)^3\,dx\) using substitution.
Let \(u=x^2+1\), so \(du=2x\,dx\), which means \(x\,dx=\frac{1}{2}du\). Substituting:
\[\int x(x^2+1)^3\,dx = \int u^3 \cdot \frac{1}{2}\,du = \frac{1}{2}\cdot\frac{u^4}{4}+C = \frac{u^4}{8}+C\]Substituting back \(u=x^2+1\):
\[\boxed{\int x(x^2+1)^3\,dx = \frac{(x^2+1)^4}{8}+C}\]

Substitution with more complex composite functions

The same method applies when the outer function is a root (a fractional power) rather than an integer power: write the root as a fractional exponent, substitute \(u\) for the expression under it, and integrate using the power rule on \(u\).
Worked exampleEvaluate \(\int x\sqrt{x^2+9}\,dx\).
Let \(u=x^2+9\), so \(du=2x\,dx\), giving \(x\,dx=\frac{1}{2}du\). Rewriting \(\sqrt{x^2+9}=u^{1/2}\):
\[\int x\sqrt{x^2+9}\,dx = \int u^{1/2}\cdot\frac{1}{2}\,du = \frac{1}{2}\cdot\frac{u^{3/2}}{3/2}+C = \frac{u^{3/2}}{3}+C\]Substituting back \(u=x^2+9\):
\[\boxed{\int x\sqrt{x^2+9}\,dx = \frac{(x^2+9)^{3/2}}{3}+C}\]

Substitution with definite integrals: changing the limits

When substitution is applied to a definite integral, the limits of integration must also be converted from values of \(x\) to the corresponding values of \(u=g(x)\), after which the new integral is evaluated entirely in terms of \(u\) without returning to \(x\):
\[\int_a^b f(g(x))\cdot g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du\]
Worked exampleEvaluate \(\int_0^3 x\sqrt{x^2+16}\,dx\).
Let \(u=x^2+16\), so \(du=2x\,dx\), giving \(x\,dx=\frac{1}{2}du\). The limits convert as \(u(0)=0^2+16=16\) and \(u(3)=3^2+16=25\):
\[\int_0^3 x\sqrt{x^2+16}\,dx = \frac{1}{2}\int_{16}^{25} u^{1/2}\,du = \frac{1}{2}\left[\frac{u^{3/2}}{3/2}\right]_{16}^{25} = \frac{1}{3}\left[u^{3/2}\right]_{16}^{25}\]\[= \frac{1}{3}\left(125-64\right) = \frac{61}{3}\]\[\boxed{\int_0^3 x\sqrt{x^2+16}\,dx = \frac{61}{3}}\]
