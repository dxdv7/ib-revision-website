The principle of mathematical induction

To prove that a statement \(S(n)\) is true for every integer \(n \geq n_0\) (usually \(n_0 = 1\)), the principle of mathematical induction requires two steps:
\[\text{Base case: } S(n_0) \text{ is shown to be true.}\]\[\text{Inductive step: assuming } S(k) \text{ is true for some integer } k \geq n_0 \text{ (the inductive hypothesis), it is shown that } S(k+1) \text{ must also be true.}\]If both steps are completed, the conclusion is that \(S(n)\) is true for every integer \(n \geq n_0\).
Worked exampleProve by induction that \(\displaystyle\sum_{i=1}^{n} i = \frac{n(n+1)}{2}\) for all positive integers \(n\).
Let \(S(n)\) denote the statement \(\displaystyle\sum_{i=1}^{n} i = \frac{n(n+1)}{2}\).
Base case: for \(n=1\),
\[\sum_{i=1}^{1} i = 1 \qquad \text{and} \qquad \frac{1(1+1)}{2} = 1\]so \(S(1)\) is true.
Inductive hypothesis: assume \(S(k)\) is true for some positive integer \(k\), that is
\[\sum_{i=1}^{k} i = \frac{k(k+1)}{2}\]Inductive step: add the next term \((k+1)\) to both sides:
\[\sum_{i=1}^{k+1} i = \sum_{i=1}^{k} i + (k+1)\]\[= \frac{k(k+1)}{2} + (k+1)\]\[= \frac{k(k+1) + 2(k+1)}{2}\]\[= \frac{(k+1)(k+2)}{2}\]This is exactly the formula \(\frac{n(n+1)}{2}\) with \(n = k+1\), so \(S(k+1)\) is true whenever \(S(k)\) is true.
\[\boxed{\text{Since } S(1) \text{ is true and } S(k) \Rightarrow S(k+1), \text{ by induction } \sum_{i=1}^{n} i = \frac{n(n+1)}{2} \text{ for all positive integers } n}\]

The base case

The base case verifies, by direct substitution, that the statement \(S(n)\) holds for the smallest value of \(n\) under consideration (usually \(n=1\), sometimes \(n=0\)). The inductive step alone only shows that truth passes from \(k\) to \(k+1\); without a true base case, there is nothing for that chain of implications to start from, so the base case can never be omitted.
Worked exampleVerify the base case of the statement \(S(n): 1 + 2 + 4 + \cdots + 2^{n-1} = 2^{n} - 1\) for \(n = 1\).
The left side of \(S(1)\) has only one term:
\[\text{left side} = 2^{1-1} = 2^{0} = 1\]\[\text{right side} = 2^{1} - 1 = 1\]
\[\boxed{S(1) \text{ is true, since both sides equal } 1}\]

The inductive hypothesis and inductive step

In the inductive step, the inductive hypothesis \(S(k)\) is assumed true and used algebraically to derive \(S(k+1)\). The usual strategy is to write the left side of \(S(k+1)\) as the left side of \(S(k)\) plus the next term, substitute the inductive hypothesis, and simplify until the result matches the right side of \(S(k+1)\) exactly.
Worked exampleProve by induction that the sum of the first \(n\) positive odd integers is \(n^{2}\), that is \(\displaystyle\sum_{i=1}^{n} (2i-1) = n^{2}\).
Let \(S(n)\) denote the statement \(\displaystyle\sum_{i=1}^{n} (2i-1) = n^{2}\).
Base case: for \(n=1\),
\[2(1) - 1 = 1 \qquad \text{and} \qquad 1^{2} = 1\]so \(S(1)\) is true.
Inductive hypothesis: assume \(S(k)\) is true, that is
\[\sum_{i=1}^{k} (2i-1) = k^{2}\]Inductive step: the \((k+1)\)th odd integer is \(2(k+1)-1\), so
\[\sum_{i=1}^{k+1} (2i-1) = \sum_{i=1}^{k} (2i-1) + \left(2(k+1)-1\right)\]\[= k^{2} + 2k + 1\]\[= (k+1)^{2}\]so \(S(k+1)\) is true whenever \(S(k)\) is true.
\[\boxed{\text{Since } S(1) \text{ is true and } S(k) \Rightarrow S(k+1), \text{ by induction } \sum_{i=1}^{n} (2i-1) = n^{2} \text{ for all positive integers } n}\]

Divisibility proof by induction

To prove that an integer \(d\) divides \(f(n)\) for all \(n \geq n_0\) by induction, the inductive step writes \(f(k+1)\) in terms of \(f(k)\). If \(f(k+1) = f(k) + dm\) for some integer \(m\), then because the inductive hypothesis gives \(f(k) = dp\) for some integer \(p\), it follows that \(f(k+1) = d(p+m)\), which is a multiple of \(d\).
Worked exampleProve by induction that \(n^{3} - n\) is divisible by \(3\) for all positive integers \(n\).
Let \(S(n)\) denote the statement that \(3\) divides \(n^{3}-n\).
Base case: for \(n=1\),
\[1^{3} - 1 = 0 = 3(0)\]so \(3\) divides \(1^{3}-1\), and \(S(1)\) is true.
Inductive hypothesis: assume \(S(k)\) is true, that is, there exists an integer \(m\) such that
\[k^{3} - k = 3m\]Inductive step: consider \((k+1)^{3} - (k+1)\):
\[(k+1)^{3} - (k+1) = k^{3} + 3k^{2} + 3k + 1 - k - 1\]\[= \left(k^{3} - k\right) + 3k^{2} + 3k\]\[= 3m + 3\left(k^{2}+k\right)\]\[= 3\left(m + k^{2} + k\right)\]Since \(m + k^{2} + k\) is an integer, \((k+1)^{3}-(k+1)\) is divisible by \(3\), so \(S(k+1)\) is true whenever \(S(k)\) is true.
\[\boxed{\text{Since } S(1) \text{ is true and } S(k) \Rightarrow S(k+1), \text{ by induction } 3 \text{ divides } n^{3}-n \text{ for all positive integers } n}\]

Induction with a geometric series

A series formula can also be proved by induction; the inductive step adds the next term of the series to both sides of the inductive hypothesis and factors the result to match the next term of the pattern on the right side.
Worked exampleProve by induction that \(1 + 2 + 4 + \cdots + 2^{n-1} = 2^{n} - 1\) for all positive integers \(n\).
Let \(S(n)\) denote the statement \(1 + 2 + 4 + \cdots + 2^{n-1} = 2^{n}-1\).
Base case: for \(n=1\), the left side is \(2^{0}=1\) and the right side is \(2^{1}-1=1\), so \(S(1)\) is true.
Inductive hypothesis: assume \(S(k)\) is true, that is
\[1 + 2 + 4 + \cdots + 2^{k-1} = 2^{k} - 1\]Inductive step: add the next term \(2^{k}\) to both sides:
\[1 + 2 + 4 + \cdots + 2^{k-1} + 2^{k} = \left(2^{k}-1\right) + 2^{k}\]\[= 2\left(2^{k}\right) - 1\]\[= 2^{k+1} - 1\]so \(S(k+1)\) is true whenever \(S(k)\) is true.
\[\boxed{\text{Since } S(1) \text{ is true and } S(k) \Rightarrow S(k+1), \text{ by induction } 1+2+4+\cdots+2^{n-1} = 2^{n}-1 \text{ for all positive integers } n}\]
