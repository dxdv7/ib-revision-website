Partial fractions: distinct linear factors

If the denominator of a proper rational expression factorises into distinct linear factors, write a constant over each linear factor:
\[\frac{f(x)}{(x-p)(x-q)} = \frac{A}{x-p} + \frac{B}{x-q}\]Multiplying both sides by \((x-p)(x-q)\) gives an identity \(f(x) = A(x-q) + B(x-p)\) that holds for every value of \(x\). Substituting \(x = p\) eliminates \(B\) and gives \(A\) directly; substituting \(x = q\) eliminates \(A\) and gives \(B\) directly. This is called the cover-up method.
Worked exampleFind the partial fraction decomposition of \(\dfrac{x+1}{(x+2)(x+3)}\).
Write \(\dfrac{x+1}{(x+2)(x+3)} = \dfrac{A}{x+2} + \dfrac{B}{x+3}\), so \(x+1 = A(x+3) + B(x+2)\).
Let \(x = -2\):
\[-2+1 = A(-2+3)\]\[-1 = A\]Let \(x = -3\):
\[-3+1 = B(-3+2)\]\[-2 = -B\]\[B = 2\]\[\boxed{\frac{x+1}{(x+2)(x+3)} = \frac{-1}{x+2} + \frac{2}{x+3}}\]

Partial fractions: equating coefficients

As an alternative to substituting convenient values, expand the right side of the identity and collect like powers of \(x\). Since the two sides must be identical polynomials, the coefficient of each power of \(x\) on the left must equal the coefficient of the same power on the right. This produces a system of equations that can be solved for the unknown constants.
Worked exampleDecompose \(\dfrac{5x^2+16x+17}{(2x-1)(x+2)(x+3)}\) into partial fractions.
Write \(\dfrac{5x^2+16x+17}{(2x-1)(x+2)(x+3)} = \dfrac{A}{2x-1} + \dfrac{B}{x+2} + \dfrac{C}{x+3}\), so
\[5x^2+16x+17 = A(x+2)(x+3) + B(2x-1)(x+3) + C(2x-1)(x+2)\]Expanding and collecting powers of \(x\) gives the system:
\[5A + 2B + 2C = 5\]\[5A + 5B + 3C = 16\]\[6A - 3B - 2C = 17\]Solving this system gives \(A = 3\), \(B = -1\), \(C = 2\).
\[\boxed{\frac{5x^2+16x+17}{(2x-1)(x+2)(x+3)} = \frac{3}{2x-1} - \frac{1}{x+2} + \frac{2}{x+3}}\]

Partial fractions: repeated linear factors

If a linear factor \((x-p)\) is repeated \(n\) times in the denominator, the decomposition must include a term with denominator \((x-p)^k\) for every power \(k = 1, 2, \ldots, n\), each with a constant numerator:
\[\frac{f(x)}{(x-p)^n} = \frac{A_1}{x-p} + \frac{A_2}{(x-p)^2} + \cdots + \frac{A_n}{(x-p)^n}\]
Worked exampleWrite \(\dfrac{x-1}{x^2+4x+4}\) as the sum of partial fractions.
Factorise the denominator:
\[x^2+4x+4 = (x+2)^2\]Since \((x+2)\) is a repeated linear factor, write
\[\frac{x-1}{(x+2)^2} = \frac{A}{x+2} + \frac{B}{(x+2)^2}\]Multiplying both sides by \((x+2)^2\) gives \(x-1 = A(x+2) + B\). Let \(x = -2\):
\[-2-1 = B\]\[B = -3\]Equating the coefficient of \(x\) gives \(A = 1\).
\[\boxed{\frac{x-1}{x^2+4x+4} = \frac{1}{x+2} - \frac{3}{(x+2)^2}}\]

Partial fractions: irreducible quadratic factors

If the denominator contains an irreducible quadratic factor (one with no real zeros, so its discriminant is negative), the numerator placed over that factor must be a full linear expression, not just a constant:
\[\frac{f(x)}{(x-p)(x^2+bx+c)} = \frac{A}{x-p} + \frac{Dx+E}{x^2+bx+c}\]
Worked exampleDecompose \(\dfrac{3x^2-2x+5}{(x-1)(x^2+4)}\) into partial fractions.
Since \(x^2+4\) has discriminant \(0^2 - 4(1)(4) = -16 < 0\), it is irreducible, so write
\[\frac{3x^2-2x+5}{(x-1)(x^2+4)} = \frac{A}{x-1} + \frac{Dx+E}{x^2+4}\]so that \(3x^2-2x+5 = A(x^2+4) + (Dx+E)(x-1)\). Let \(x=1\):
\[3-2+5 = A(5)\]\[A = \frac{6}{5}\]Equating the coefficients of \(x^2\) and the constant term gives \(D = \dfrac{9}{5}\) and \(E = -\dfrac{1}{5}\).
\[\boxed{\frac{3x^2-2x+5}{(x-1)(x^2+4)} = \frac{6}{5(x-1)} + \frac{9x-1}{5(x^2+4)}}\]

Improper rational expressions

Partial fraction decomposition applies only to a proper rational expression, where the degree of the numerator is less than the degree of the denominator. If the expression is improper, divide the numerator by the denominator first; the rational expression equals the polynomial quotient plus the remainder over the original divisor, and only that remaining proper fraction is decomposed into partial fractions.
Worked exampleDecompose \(\dfrac{x^3+2x^2-5}{(x-2)(x+1)}\) into partial fractions.
The numerator has degree 3 and the denominator has degree 2, so the expression is improper. Divide first:
\[x^3+2x^2-5 = (x^2-x-2)(x+3) + (5x+1)\]\[\frac{x^3+2x^2-5}{(x-2)(x+1)} = x+3 + \frac{5x+1}{(x-2)(x+1)}\]Decomposing the remaining proper fraction using the cover-up method gives \(\dfrac{11}{3(x-2)} + \dfrac{4}{3(x+1)}\).
\[\boxed{\frac{x^3+2x^2-5}{(x-2)(x+1)} = x+3 + \frac{11}{3(x-2)} + \frac{4}{3(x+1)}}\]

Verifying a partial fraction decomposition

A decomposition can always be checked by reversing the process: write each partial fraction over the original common denominator and add the numerators. If the result simplifies back to the original rational expression, the decomposition is correct.
Worked exampleVerify that \(\dfrac{2}{x+3} - \dfrac{1}{x+2} = \dfrac{x+1}{(x+2)(x+3)}\).
Combine the left side over the common denominator \((x+2)(x+3)\):
\[\frac{2}{x+3} - \frac{1}{x+2} = \frac{2(x+2) - (x+3)}{(x+2)(x+3)}\]\[= \frac{2x+4-x-3}{(x+2)(x+3)}\]\[= \frac{x+1}{(x+2)(x+3)}\]This matches the original expression.
\[\boxed{\text{decomposition confirmed}}\]
