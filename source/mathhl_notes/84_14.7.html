Deriving the integration by parts formula

The product rule states \(\dfrac{d}{dx}\big(u(x)v(x)\big) = u(x)v'(x)+u'(x)v(x)\). Writing this in differential form, \(d(uv) = u\,dv + v\,du\), and integrating both sides gives \(uv = \int u\,dv + \int v\,du\). Rearranging for \(\int u\,dv\) produces the formula:
\[\int u\,dv = uv - \int v\,du\]This turns an integral that is hard to evaluate directly, \(\int u\,dv\), into a (hopefully easier) integral \(\int v\,du\), plus the already-known product \(uv\).
Worked exampleUse integration by parts to evaluate \(\int x\cos x\,dx\).
Let \(u=x\) and \(dv=\cos x\,dx\), so \(du=dx\) and \(v=\sin x\). Applying the formula:
\[\int x\cos x\,dx = x\sin x - \int \sin x\,dx = x\sin x - (-\cos x)+C\]\[\boxed{\int x\cos x\,dx = x\sin x+\cos x+C}\]

Choosing u and dv wisely

Integration by parts only simplifies the problem if \(u\) and \(dv\) are chosen well. Two practical guidelines: choose \(dv\) to be a factor that can actually be integrated, and choose \(u\) to be the factor that becomes simpler (or at least no more complicated) when differentiated. A common mnemonic for preference order when choosing \(u\) is "LIATE": Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, Exponential, with earlier types in this list usually making the better choice of \(u\).
Worked exampleShow that choosing \(u=\cos x\), \(dv=x\,dx\) for \(\int x\cos x\,dx\) is a poor choice.
Here \(du=-\sin x\,dx\) and \(v=\frac{x^2}{2}\), giving:
\[\int x\cos x\,dx = \frac{x^2}{2}\cos x + \int \frac{x^2}{2}\sin x\,dx\]The new integral contains \(x^2\), which is more complicated than the original integrand \(x\cos x\), so this choice makes the problem worse rather than simpler.
\[\boxed{\text{Correct choice: } u=x,\ dv=\cos x\,dx \text{ (algebraic before trigonometric in LIATE)}}\]

Integration by parts with an exponential factor

When the integrand is a polynomial multiplied by an exponential, such as \(xe^x\), the polynomial factor is chosen as \(u\) (it simplifies on differentiation) and the exponential factor as \(dv\) (it integrates to itself, up to a constant):
\[u = x^n, \qquad dv = e^{kx}\,dx\]
Worked exampleEvaluate \(\int xe^x\,dx\).
Let \(u=x\) and \(dv=e^x\,dx\), so \(du=dx\) and \(v=e^x\). Applying the formula:
\[\int xe^x\,dx = xe^x - \int e^x\,dx\]\[\boxed{\int xe^x\,dx = xe^x-e^x+C}\]Differentiating the right-hand side confirms this: \(\frac{d}{dx}(xe^x-e^x) = e^x+xe^x-e^x = xe^x\).

Applying integration by parts twice

If the polynomial factor has degree 2 or higher, a single application of integration by parts reduces the power by one but does not eliminate it; the formula must be applied again to the new integral, being careful to keep the same roles for \(u\) and \(dv\) (always differentiating the polynomial part) so the process does not undo itself.
Worked exampleEvaluate \(\int x^2e^x\,dx\).
Let \(u=x^2\), \(dv=e^x\,dx\), so \(du=2x\,dx\), \(v=e^x\):
\[\int x^2e^x\,dx = x^2e^x - \int 2xe^x\,dx = x^2e^x - 2\int xe^x\,dx\]Using the result \(\int xe^x\,dx = xe^x-e^x+C\) from above:
\[\boxed{\int x^2e^x\,dx = x^2e^x-2xe^x+2e^x+C}\]

Integration by parts with definite integrals

The formula adapts directly to definite integrals by evaluating the \(uv\) term between the limits, while the remaining integral is also evaluated between the same limits:
\[\int_a^b u\,dv = \Big[uv\Big]_a^b - \int_a^b v\,du\]
Worked exampleEvaluate \(\int_0^1 xe^x\,dx\).
Using \(u=x\), \(dv=e^x\,dx\), \(du=dx\), \(v=e^x\):
\[\int_0^1 xe^x\,dx = \Big[xe^x\Big]_0^1 - \int_0^1 e^x\,dx = \Big[xe^x-e^x\Big]_0^1\]Evaluating at the limits: at \(x=1\), \(1\cdot e-e=0\); at \(x=0\), \(0-1=-1\):
\[\boxed{\int_0^1 xe^x\,dx = 0-(-1) = 1}\]

Circular integration by parts: solving for the integral algebraically

For integrands such as \(e^x\cos x\), where \(u\) and \(dv\) are both exponential/trigonometric, applying integration by parts twice (consistently) returns a multiple of the original integral rather than a new, simpler one. Letting \(I\) denote the original integral, this produces an equation in \(I\) which can be solved algebraically.
Worked exampleEvaluate \(I=\int e^x\cos x\,dx\).
Let \(u=\cos x\), \(dv=e^x\,dx\), so \(du=-\sin x\,dx\), \(v=e^x\):
\[I = e^x\cos x + \int e^x\sin x\,dx\]For the new integral, let \(u=\sin x\), \(dv=e^x\,dx\), so \(du=\cos x\,dx\), \(v=e^x\):
\[\int e^x\sin x\,dx = e^x\sin x - \int e^x\cos x\,dx = e^x\sin x - I\]Substituting back:
\[I = e^x\cos x + e^x\sin x - I \implies 2I = e^x(\cos x+\sin x)\]\[\boxed{\int e^x\cos x\,dx = \frac{e^x(\cos x+\sin x)}{2}+C}\]
