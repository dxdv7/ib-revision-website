The cosine of a difference

For any two angles \(A\) and \(B\):
\[\cos(A - B) = \cos A\cos B + \sin A\sin B\]
Worked exampleFind the exact value of \(\cos\dfrac{\pi}{12}\) by writing \(\dfrac{\pi}{12} = \dfrac{\pi}{3} - \dfrac{\pi}{4}\).
\[\cos\frac{\pi}{12} = \cos\left(\frac{\pi}{3} - \frac{\pi}{4}\right) = \cos\frac{\pi}{3}\cos\frac{\pi}{4} + \sin\frac{\pi}{3}\sin\frac{\pi}{4}\]\[\cos\frac{\pi}{12} = \left(\frac{1}{2}\right)\left(\frac{\sqrt{2}}{2}\right) + \left(\frac{\sqrt{3}}{2}\right)\left(\frac{\sqrt{2}}{2}\right)\]\[\boxed{\cos\frac{\pi}{12} = \frac{\sqrt{6} + \sqrt{2}}{4}}\]

The cosine of a sum

For any two angles \(A\) and \(B\):
\[\cos(A + B) = \cos A\cos B - \sin A\sin B\]
Worked exampleFind the exact value of \(\cos\dfrac{5\pi}{12}\) by writing \(\dfrac{5\pi}{12} = \dfrac{\pi}{4} + \dfrac{\pi}{6}\).
\[\cos\frac{5\pi}{12} = \cos\frac{\pi}{4}\cos\frac{\pi}{6} - \sin\frac{\pi}{4}\sin\frac{\pi}{6}\]\[\cos\frac{5\pi}{12} = \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) - \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right)\]\[\boxed{\cos\frac{5\pi}{12} = \frac{\sqrt{6} - \sqrt{2}}{4}}\]

The sine of a sum

For any two angles \(A\) and \(B\):
\[\sin(A + B) = \sin A\cos B + \cos A\sin B\]
Worked exampleFind the exact value of \(\sin\dfrac{5\pi}{12}\) by writing \(\dfrac{5\pi}{12} = \dfrac{\pi}{4} + \dfrac{\pi}{6}\).
\[\sin\frac{5\pi}{12} = \sin\frac{\pi}{4}\cos\frac{\pi}{6} + \cos\frac{\pi}{4}\sin\frac{\pi}{6}\]\[\sin\frac{5\pi}{12} = \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) + \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right)\]\[\boxed{\sin\frac{5\pi}{12} = \frac{\sqrt{6} + \sqrt{2}}{4}}\]

The sine of a difference

For any two angles \(A\) and \(B\):
\[\sin(A - B) = \sin A\cos B - \cos A\sin B\]
Worked exampleFind the exact value of \(\sin\dfrac{\pi}{12}\) by writing \(\dfrac{\pi}{12} = \dfrac{\pi}{3} - \dfrac{\pi}{4}\).
\[\sin\frac{\pi}{12} = \sin\frac{\pi}{3}\cos\frac{\pi}{4} - \cos\frac{\pi}{3}\sin\frac{\pi}{4}\]\[\sin\frac{\pi}{12} = \left(\frac{\sqrt{3}}{2}\right)\left(\frac{\sqrt{2}}{2}\right) - \left(\frac{1}{2}\right)\left(\frac{\sqrt{2}}{2}\right)\]\[\boxed{\sin\frac{\pi}{12} = \frac{\sqrt{6} - \sqrt{2}}{4}}\]

Using compound angle identities with given ratios

When exact values of \(\sin A\) and \(\cos B\) (rather than the angles \(A\) and \(B\) themselves) are given, first use the Pythagorean identity to find the remaining ratios \(\cos A\) and \(\sin B\), then substitute directly into a compound angle identity.
Worked exampleGiven that \(\sin A = \dfrac{3}{5}\) and \(\cos B = \dfrac{5}{13}\), where \(A\) and \(B\) are both in the first quadrant, find the exact value of \(\cos(A + B)\).
Since \(A\) and \(B\) are in the first quadrant, \(\cos A > 0\) and \(\sin B > 0\):
\[\cos A = \sqrt{1 - \sin^2 A} = \sqrt{1 - \frac{9}{25}} = \frac{4}{5} \qquad \sin B = \sqrt{1 - \cos^2 B} = \sqrt{1 - \frac{25}{169}} = \frac{12}{13}\]\[\cos(A + B) = \cos A\cos B - \sin A\sin B = \left(\frac{4}{5}\right)\left(\frac{5}{13}\right) - \left(\frac{3}{5}\right)\left(\frac{12}{13}\right)\]\[\boxed{\cos(A + B) = -\frac{16}{65}}\]

The double angle identity for tangent

Setting \(A = B = \theta\) in the compound angle identity for \(\tan(A + B)\) gives the double angle identity for tangent:
\[\tan(\theta + \theta) = \frac{\tan\theta + \tan\theta}{1 - \tan\theta\tan\theta}\]\[\boxed{\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta}}\]
Worked exampleGiven that \(\tan\theta = \dfrac{3}{4}\), find the exact value of \(\tan 2\theta\).
\[\tan 2\theta = \frac{2\left(\frac{3}{4}\right)}{1 - \left(\frac{3}{4}\right)^2} = \frac{\frac{3}{2}}{1 - \frac{9}{16}} = \frac{\frac{3}{2}}{\frac{7}{16}}\]\[\boxed{\tan 2\theta = \frac{24}{7}}\]
