The law of total probability

Let \(E_1, E_2, \ldots, E_n\) be mutually exclusive events that together partition the whole sample space \(U\) (every outcome belongs to exactly one \(E_i\)). For any event \(F\):
\[P(F) = \sum_{i=1}^{n} P(E_i)\,P(F \mid E_i) = P(E_1)P(F\mid E_1) + P(E_2)P(F\mid E_2) + \cdots + P(E_n)P(F\mid E_n)\]This builds up the overall probability of \(F\) from its probability within each partition class.
Worked exampleA factory has two machines. Machine A produces 60% of all items, of which 2% are defective. Machine B produces the remaining 40%, of which 5% are defective. Find the overall probability that a randomly chosen item is defective.
\[P(D) = P(A)P(D\mid A) + P(B)P(D\mid B) = (0.6\times0.02) + (0.4\times0.05)\]\[P(D) = 0.012 + 0.02\]\[\boxed{P(D) = 0.032}\]

Bayes' theorem

Conditional probability looks forward: knowing the earlier event, find the probability of the later one. Bayes' theorem reverses this: knowing the later event occurred, it finds the probability of each earlier, partitioning event. For a partition \(E_1, E_2\) of \(U\) and any event \(F\) with \(P(F) \neq 0\):
\[P(E_1 \mid F) = \frac{P(E_1 \cap F)}{P(F)} = \frac{P(E_1)\,P(F \mid E_1)}{P(E_1)\,P(F\mid E_1) + P(E_2)\,P(F\mid E_2)}\]The denominator is simply \(P(F)\), expanded using the law of total probability.
Worked exampleUsing the factory from above, an item is checked and found defective. Find the probability it was produced by Machine B.
\[P(B \cap D) = P(B)\,P(D\mid B) = 0.4\times0.05 = 0.02, \qquad P(D) = 0.032\]\[P(B \mid D) = \frac{P(B\cap D)}{P(D)} = \frac{0.02}{0.032}\]\[\boxed{P(B \mid D) = 0.625}\]

Bayes' theorem and the base-rate fallacy

For a medical-style test, write \(D\) for "has the condition" and \(+\) for "tests positive". The test's sensitivity is \(P(+\mid D)\) and its specificity is \(P(-\mid D')\), so the false-positive rate is \(P(+\mid D') = 1-P(-\mid D')\). Bayes' theorem gives:
\[P(D \mid {+}) = \frac{P(D)\,P({+}\mid D)}{P(D)\,P({+}\mid D) + P(D')\,P({+}\mid D')}\]When the condition is rare, this posterior probability can be surprisingly small even for a seemingly accurate test — confusing \(P(+\mid D)\) with \(P(D\mid{+})\) is a common error known as the base-rate fallacy.
Worked exampleA disease affects 1% of a population. A test has sensitivity 95% (\(P({+}\mid D)=0.95\)) and specificity 90% (\(P({-}\mid D')=0.90\), so \(P({+}\mid D')=0.10\)). Given a positive result, find the probability the person actually has the disease.
\[P({+}) = (0.01\times0.95) + (0.99\times0.10) = 0.0095+0.099 = 0.1085\]\[P(D\mid{+}) = \frac{0.0095}{0.1085}\]\[\boxed{P(D\mid{+}) \approx 0.0876, \text{ i.e. about } 8.8\%}\]

Bayes' theorem for three or more partition events

For a partition \(E_1, E_2, \ldots, E_n\) of \(U\) and any event \(F\) with \(P(F)\neq 0\), the same reversal applies to any one partition class \(E_i\):
\[P(E_i \mid F) = \frac{P(E_i)\,P(F\mid E_i)}{\displaystyle\sum_{j=1}^{n} P(E_j)\,P(F\mid E_j)}\]The denominator sums over every partition event, so all \(n\) branches of the underlying tree diagram must be included.
Worked exampleA manufacturer buys hard disks from three suppliers: X supplies 50% of disks (3% defective), Y supplies 30% (4% defective), and Z supplies 20% (6% defective). A disk is checked and found defective. Find the probability it came from Z.
\[P(D) = (0.5\times0.03)+(0.3\times0.04)+(0.2\times0.06) = 0.015+0.012+0.012 = 0.039\]\[P(Z\mid D) = \frac{0.2\times0.06}{0.039} = \frac{0.012}{0.039}\]\[\boxed{P(Z\mid D) = \frac{4}{13} \approx 0.308}\]

How the prior probability shapes the posterior

In Bayes' theorem, \(P(E_i)\) is called the prior probability (what is known before testing), \(P(F\mid E_i)\) is the likelihood (how well the evidence fits that class), and \(P(E_i\mid F)\) is the posterior probability (updated belief after the evidence). The same test applied to populations with different priors can produce very different posteriors.
Worked exampleApply the same test from before (sensitivity 0.95, specificity 0.90) to a high-risk group where the prior prevalence is \(P(D)=0.5\) instead of 0.01. Find the new \(P(D\mid{+})\) and compare with the earlier result.
\[P({+}) = (0.5\times0.95)+(0.5\times0.10) = 0.475+0.05 = 0.525\]\[P(D\mid{+}) = \frac{0.475}{0.525}\]\[\boxed{P(D\mid{+}) = \frac{19}{21} \approx 0.905, \text{ versus about } 0.088 \text{ when the prior was } 0.01}\]
