Vertical asymptotes of a rational function

Let \(R(x) = \dfrac{f(x)}{g(x)}\) where \(f\) and \(g\) are polynomials with no common factor. A vertical asymptote of the graph of \(R\) occurs at every real value of \(x\) for which the denominator is zero:
\[g(x) = 0\]Each such value is excluded from the domain of \(R\).
Worked exampleFind the vertical asymptotes of \(f(x) = \dfrac{3x^2 - 12}{x^2 + 3x - 4}\).
Factorise completely:
\[f(x) = \frac{3(x-2)(x+2)}{(x+4)(x-1)}\]The numerator and denominator share no common factor. Set the denominator equal to zero:
\[(x+4)(x-1) = 0\]\[\boxed{x = -4 \text{ and } x = 1}\]

Sign analysis near a vertical asymptote

Near a vertical asymptote \(x = d\), test a value of \(x\) slightly less than \(d\) and a value slightly greater than \(d\) in the factorised form of \(R(x)\). If \(R(x) > 0\) on that side, the branch of the graph rises toward \(+\infty\); if \(R(x) < 0\), the branch falls toward \(-\infty\).
Worked exampleDescribe the behaviour of \(f(x) = \dfrac{3(x-2)(x+2)}{(x+4)(x-1)}\) on each side of the vertical asymptote \(x = 1\).
Test \(x = 0.9\) (just to the left of 1):
\[f(0.9) = \frac{3(0.9-2)(0.9+2)}{(0.9+4)(0.9-1)} = \frac{3(-1.1)(2.9)}{(4.9)(-0.1)} > 0\]Test \(x = 1.1\) (just to the right of 1):
\[f(1.1) = \frac{3(1.1-2)(1.1+2)}{(1.1+4)(1.1-1)} = \frac{3(-0.9)(3.1)}{(5.1)(0.1)} < 0\]\[\boxed{\text{as } x \to 1^-,\ f(x) \to +\infty; \text{ as } x \to 1^+,\ f(x) \to -\infty}\]

Horizontal asymptotes and end behaviour

Let \(R(x) = \dfrac{a_nx^n + \cdots + a_0}{b_mx^m + \cdots + b_0}\) with \(a_n \neq 0\) and \(b_m \neq 0\).
\[\text{if } n < m, \text{ the horizontal asymptote is } y = 0\]\[\text{if } n = m, \text{ the horizontal asymptote is } y = \frac{a_n}{b_m}\]\[\text{if } n > m, \text{ there is no horizontal asymptote}\]
Worked exampleState the horizontal asymptote, if any, of (a) \(f(x) = \dfrac{3x^2 - 12}{x^2 + 3x - 4}\) and (b) \(g(x) = \dfrac{2x + 5}{x^2 - 9}\).
For (a), the numerator and denominator both have degree 2, with leading coefficients 3 and 1:
\[y = \frac{3}{1}\]For (b), the numerator has degree 1 and the denominator has degree 2, so \(n < m\):
\[\boxed{\text{(a) } y = 3; \text{ (b) } y = 0}\]

Oblique asymptotes

If the degree of \(f\) is exactly one greater than the degree of \(g\), then \(R(x) = \dfrac{f(x)}{g(x)}\) has an oblique (slant) asymptote. Dividing \(f\) by \(g\) gives
\[f(x) = g(x) \cdot Q(x) + r(x), \qquad \deg r < \deg g\]so that \(R(x) = Q(x) + \dfrac{r(x)}{g(x)}\). As \(x \to \pm\infty\), \(\dfrac{r(x)}{g(x)} \to 0\), so the oblique asymptote is the line \(y = Q(x)\).
Worked exampleFind the oblique asymptote of \(p(x) = \dfrac{x^2 - 9}{x - 4}\).
Divide \(x^2 - 9\) by \(x - 4\):
\[x^2 - 9 = (x-4)(x+4) + 7\]\[p(x) = x + 4 + \frac{7}{x-4}\]As \(x \to \pm\infty\), \(\dfrac{7}{x-4} \to 0\):
\[\boxed{y = x + 4}\]

Holes (removable discontinuities)

If \(f(x) = \dfrac{(x-c)h(x)}{(x-c)k(x)}\) where \((x-c)\) is a common factor of the numerator and denominator and \(k(c) \neq 0\), then \(f\) is undefined at \(x = c\) but simplifies to \(\dfrac{h(x)}{k(x)}\) for \(x \neq c\). The graph of \(f\) has a hole at \(\left(c, \dfrac{h(c)}{k(c)}\right)\) rather than a vertical asymptote there.
Worked exampleLocate the hole in the graph of \(f(x) = \dfrac{x^2 - 1}{x - 1}\).
Factorise the numerator:
\[f(x) = \frac{(x-1)(x+1)}{x-1} = x + 1, \quad x \neq 1\]Evaluate the simplified expression at \(x = 1\):
\[1 + 1 = 2\]\[\boxed{\text{hole at } (1, 2)}\]

Domain and range of a rational function

The domain of \(R(x) = \dfrac{f(x)}{g(x)}\) in lowest terms is all real \(x\) except the zeros of \(g(x)\). The range must be read from the full graph: between two vertical asymptotes the function is often continuous and unbounded in both directions, so by the intermediate value property it can take every real value there, even though a horizontal asymptote exists for the rest of the graph.
Worked exampleState the domain and range of \(f(x) = \dfrac{3(x-2)(x+2)}{(x+4)(x-1)}\).
The domain excludes the zeros of the denominator, \(x = -4\) and \(x = 1\).
From the sign analysis, as \(x \to -4^+\), \(f(x) \to -\infty\), and as \(x \to 1^-\), \(f(x) \to +\infty\); since \(f\) is continuous on \((-4, 1)\), it takes every real value on that interval.
\[\boxed{x \in \mathbb{R},\ x \neq -4, 1; \qquad y \in \mathbb{R}}\]
