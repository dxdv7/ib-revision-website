The logarithmic function

For \(b > 0\) and \(b \neq 1\), the logarithmic function with base \(b\) is the inverse of the exponential function with base \(b\):
\[y = \log_{b}x \quad \text{if and only if} \quad x = b^{y}\]The domain of \(y = \log_{b}x\) is \(x > 0\) and its range is all real numbers. The y-axis (\(x = 0\)) is a vertical asymptote of the graph, and the graph passes through \((1,0)\).
Worked exampleFind the domain of \(f(x) = \log_{2}(4 - x^{2})\).
\[4 - x^{2} > 0\]\[x^{2} < 4\]\[\boxed{-2 < x < 2}\]

Evaluating logarithms using the definition

To evaluate \(\log_{b}x\), set the expression equal to \(y\) and rewrite it in exponential form \(b^{y} = x\). Then use the fact that if \(b^{m} = b^{n}\), then \(m = n\).
Worked exampleEvaluate (a) \(\log_{4}64\) and (b) \(\log_{6}\sqrt{6}\) without using a calculator.
(a)
\[y = \log_{4}64\]\[4^{y} = 64\]\[4^{y} = 4^{3}\]\[\boxed{y = 3}\]
(b)
\[y = \log_{6}\sqrt{6}\]\[6^{y} = 6^{\frac{1}{2}}\]\[\boxed{y = \frac{1}{2}}\]

Common and natural logarithms

The common logarithm has base \(10\) and is written \(\log x\) (the base is omitted). The natural logarithm has base \(e\) and is written \(\ln x\); it is the inverse of \(y = e^{x}\).
Worked exampleEvaluate (a) \(\log\left(\frac{1}{100}\right)\), (b) \(\ln\left(\frac{1}{e^{3}}\right)\) and (c) \(10^{\log 7}\).
(a)
\[\log\left(\frac{1}{100}\right) = \log(10^{-2})\]\[\boxed{\log\left(\frac{1}{100}\right) = -2}\]
(b)
\[\ln\left(\frac{1}{e^{3}}\right) = \ln(e^{-3})\]\[\boxed{\ln\left(\frac{1}{e^{3}}\right) = -3}\]
(c)
\[\boxed{10^{\log 7} = 7}\]

Basic properties of logarithms

For \(b > 0\) and \(b \neq 1\):
\[\log_{b}1 = 0 \qquad \log_{b}b = 1\]\[\log_{b}(b^{x}) = x \qquad b^{\log_{b}x} = x\]
Worked exampleSimplify (a) \(\log_{9}(9^{7})\), (b) \(5^{\log_{5}13}\) and (c) \(\log_{6}1\).
\[\boxed{\log_{9}(9^{7}) = 7}\]\[\boxed{5^{\log_{5}13} = 13}\]\[\boxed{\log_{6}1 = 0}\]

Laws of logarithms

Given \(M > 0\), \(N > 0\) and any real number \(k\), for \(b > 0\) and \(b \neq 1\):
\[\log_{b}(MN) = \log_{b}M + \log_{b}N\]\[\log_{b}\left(\frac{M}{N}\right) = \log_{b}M - \log_{b}N\]\[\log_{b}(M^{k}) = k\log_{b}M\]
Worked example(a) Write \(\log_{b}\left(x^{3}\sqrt[3]{y}\right)\) as a sum of simple logarithms.
\[\log_{b}\left(x^{3}\sqrt[3]{y}\right) = \log_{b}(x^{3}) + \log_{b}\left(y^{\frac{1}{3}}\right)\]\[\boxed{= 3\log_{b}x + \frac{1}{3}\log_{b}y}\]
(b) Write \(2\ln a + 3\ln b - \ln c\) as a single logarithm.
\[2\ln a + 3\ln b - \ln c = \ln(a^{2}) + \ln(b^{3}) - \ln c\]\[\boxed{2\ln a + 3\ln b - \ln c = \ln\left(\frac{a^{2}b^{3}}{c}\right)}\]

Change of base formula

For positive reals \(a\), \(b\), \(x\) with \(a \neq 1\) and \(b \neq 1\):
\[\log_{b}x = \frac{\log_{a}x}{\log_{a}b}\]In particular, using common or natural logarithms:
\[\log_{b}x = \frac{\log x}{\log b} = \frac{\ln x}{\ln b}\]
Worked exampleUse the change of base formula to evaluate \(\log_{5}40\), giving the answer to 4 significant figures.
\[\log_{5}40 = \frac{\log 40}{\log 5}\]\[\boxed{\log_{5}40 \approx 2.292}\]
