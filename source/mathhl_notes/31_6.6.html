Definitions of the reciprocal trigonometric functions

For any angle \(\theta\), the three reciprocal trigonometric functions are defined as the reciprocals of sine, cosine, and tangent:
\[\sec\theta = \frac{1}{\cos\theta}, \ \cos\theta \neq 0 \qquad \csc\theta = \frac{1}{\sin\theta}, \ \sin\theta \neq 0 \qquad \cot\theta = \frac{1}{\tan\theta}, \ \tan\theta \neq 0\]
Worked exampleGiven that \(\cos\theta = \dfrac{3}{5}\) and \(\sin\theta = \dfrac{4}{5}\), with \(\theta\) in the first quadrant, find the exact values of \(\sec\theta\), \(\csc\theta\), and \(\cot\theta\).
\[\sec\theta = \frac{1}{\cos\theta} = \frac{1}{3/5} = \frac{5}{3} \qquad \csc\theta = \frac{1}{\sin\theta} = \frac{1}{4/5} = \frac{5}{4}\]\[\cot\theta = \frac{\cos\theta}{\sin\theta} = \frac{3/5}{4/5} = \frac{3}{4}\]\[\boxed{\sec\theta = \frac{5}{3}, \ \csc\theta = \frac{5}{4}, \ \cot\theta = \frac{3}{4}}\]

Cotangent as the ratio of cosine to sine

Since \(\cot\theta = \dfrac{1}{\tan\theta}\) and \(\tan\theta = \dfrac{\sin\theta}{\cos\theta}\), cotangent can also be written directly as a ratio:
\[\cot\theta = \frac{1}{\tan\theta} = \frac{\cos\theta}{\sin\theta}, \ \sin\theta \neq 0\]
Worked exampleFind the exact value of \(\cot\dfrac{\pi}{3}\).
\[\cot\frac{\pi}{3} = \frac{\cos(\pi/3)}{\sin(\pi/3)} = \frac{1/2}{\sqrt{3}/2}\]\[\boxed{\cot\frac{\pi}{3} = \frac{\sqrt{3}}{3}}\]

Domains of the reciprocal trigonometric functions

Each reciprocal function is undefined wherever its corresponding denominator is zero:
\[\sec\theta \text{ is undefined when } \cos\theta = 0, \text{ i.e. } \theta = \frac{\pi}{2} + k\pi, \ k \in \mathbb{Z}\]\[\csc\theta \text{ and } \cot\theta \text{ are undefined when } \sin\theta = 0, \text{ i.e. } \theta = k\pi, \ k \in \mathbb{Z}\]
Worked exampleFind all values of \(\theta\) in the interval \([0, 2\pi)\) for which \(\sec\theta\) is undefined.
\(\sec\theta\) is undefined whenever \(\cos\theta = 0\):
\[\boxed{\theta = \frac{\pi}{2}, \ \frac{3\pi}{2}}\]

Graphs and asymptotes of the reciprocal functions

Because \(\csc\theta\) and \(\sec\theta\) have the same period as \(\sin\theta\) and \(\cos\theta\) (namely \(2\pi\)), while \(\cot\theta\) has the same period as \(\tan\theta\) (namely \(\pi\)):
\[y = \csc\theta \text{ has vertical asymptotes at } \theta = k\pi, \ k \in \mathbb{Z}, \text{ and range } |y| \geq 1\]\[y = \sec\theta \text{ has vertical asymptotes at } \theta = \frac{\pi}{2} + k\pi, \ k \in \mathbb{Z}, \text{ and range } |y| \geq 1\]\[y = \cot\theta \text{ has vertical asymptotes at } \theta = k\pi, \ k \in \mathbb{Z}, \text{ and range all real numbers}\]
Worked exampleState the vertical asymptotes of \(y = \sec x\) on the interval \((0, 2\pi)\).
\(\sec x\) is undefined wherever \(\cos x = 0\):
\[\boxed{x = \frac{\pi}{2} \text{ and } x = \frac{3\pi}{2}}\]

The Pythagorean identity for tangent and secant

Dividing the Pythagorean identity \(\sin^2\theta + \cos^2\theta = 1\) through by \(\cos^2\theta\) gives an identity relating tangent and secant:
\[\frac{\sin^2\theta}{\cos^2\theta} + \frac{\cos^2\theta}{\cos^2\theta} = \frac{1}{\cos^2\theta}\]\[\boxed{1 + \tan^2\theta = \sec^2\theta}\]
Worked exampleGiven that \(\tan\theta = \dfrac{3}{4}\) and \(\theta\) lies in the third quadrant, find the exact value of \(\sec\theta\).
\[\sec^2\theta = 1 + \tan^2\theta = 1 + \frac{9}{16} = \frac{25}{16}\]\[\sec\theta = \pm\frac{5}{4}\]In the third quadrant \(\cos\theta < 0\), so \(\sec\theta < 0\):
\[\boxed{\sec\theta = -\frac{5}{4}}\]

The Pythagorean identity for cotangent and cosecant

Dividing the Pythagorean identity \(\sin^2\theta + \cos^2\theta = 1\) through by \(\sin^2\theta\) gives an identity relating cotangent and cosecant:
\[\frac{\sin^2\theta}{\sin^2\theta} + \frac{\cos^2\theta}{\sin^2\theta} = \frac{1}{\sin^2\theta}\]\[\boxed{1 + \cot^2\theta = \csc^2\theta}\]
Worked exampleGiven that \(\cot\theta = -2\) and \(\theta\) lies in the second quadrant, find the exact value of \(\csc\theta\).
\[\csc^2\theta = 1 + \cot^2\theta = 1 + 4 = 5\]In the second quadrant \(\sin\theta > 0\), so \(\csc\theta > 0\):
\[\boxed{\csc\theta = \sqrt{5}}\]
