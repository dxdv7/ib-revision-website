The structure of a direct proof

A direct proof of a conditional statement \(P \implies Q\) begins by assuming that the hypothesis \(P\) is true. It then uses definitions, algebraic manipulation, and previously established results, step by step, to show that the conclusion \(Q\) must also be true:
\[\text{Assume } P. \quad \text{Deduce } \ldots \quad \text{Deduce } Q.\]A direct proof must work for every object satisfying the hypothesis, not just one chosen example; testing a single case is not a proof.
Worked exampleProve that the sum of any two odd integers is an even integer.
Let \(m\) and \(n\) be odd integers. By definition, there exist integers \(r\) and \(s\) such that \(m = 2r+1\) and \(n = 2s+1\). Then
\[m+n = (2r+1)+(2s+1) = 2(r+s+1)\]Since \(r+s+1\) is an integer, \(m+n\) has the form \(2k\) for an integer \(k\), so \(m+n\) is even.
\[\boxed{\text{if } m \text{ and } n \text{ are odd integers, then } m+n \text{ is even}}\]

Definitions of even and odd integers

An integer \(n\) is even if \(n = 2k\) for some integer \(k\). An integer \(n\) is odd if \(n = 2k+1\) for some integer \(k\). Every integer is either even or odd, never both, and a direct proof involving parity almost always starts by writing the hypothesis in one of these two forms.
Worked exampleProve that the product of two odd integers is an odd integer.
Let \(m\) and \(n\) be odd integers, so \(m = 2r+1\) and \(n = 2s+1\) for integers \(r\) and \(s\). Then
\[mn = (2r+1)(2s+1) = 4rs+2r+2s+1 = 2(2rs+r+s)+1\]Since \(2rs+r+s\) is an integer, \(mn\) has the form \(2k+1\), so \(mn\) is odd.
\[\boxed{\text{if } m \text{ and } n \text{ are odd integers, then } mn \text{ is odd}}\]

Proof by cases

A proof by cases splits the hypothesis into two or more cases that together cover every possibility (the cases must be exhaustive). The conclusion is then proved separately within each case. Since the cases exhaust all possibilities, the conclusion is established in general.
Worked exampleProve that for every integer \(n\), \(n^2 + n\) is even.
Every integer is either even or odd, so there are two exhaustive cases.
Case 1: \(n = 2k\) for some integer \(k\). Then
\[n^2+n = 4k^2+2k = 2(2k^2+k)\]which is even.
Case 2: \(n = 2k+1\) for some integer \(k\). Then
\[n^2+n = (2k+1)^2+(2k+1) = 4k^2+4k+1+2k+1 = 4k^2+6k+2 = 2(2k^2+3k+1)\]which is even.
Since \(n^2+n\) is even in both exhaustive cases,
\[\boxed{n^2+n \text{ is even for every integer } n}\]

Direct proofs about divisibility

An integer \(a\) is divisible by an integer \(b\), written \(b \mid a\), if there exists an integer \(k\) such that \(a = bk\). Divisibility statements are often proved directly: write the hypothesis using this definition, then manipulate algebraically until the required form is reached for the conclusion.
Worked exampleProve that for integers \(m\) and \(n\), if \(m\) is divisible by \(n\), then \(m^2\) is divisible by \(n^2\).
Assume \(m\) is divisible by \(n\). By definition, \(m = kn\) for some integer \(k\). Then
\[m^2 = (kn)^2 = k^2n^2\]Since \(k^2\) is an integer, \(m^2\) has the form \(n^2\) multiplied by an integer, so \(n^2\) divides \(m^2\).
\[\boxed{\text{if } n \mid m \text{, then } n^2 \mid m^2}\]

The structure of proof by contrapositive

To prove \(P \implies Q\) by contrapositive, instead give a direct proof of \(\neg Q \implies \neg P\): assume \(Q\) is false, and use definitions and algebra to deduce that \(P\) is false. Because \(\neg Q \implies \neg P\) is logically equivalent to \(P \implies Q\), this establishes the original statement. Contraposition is most useful when \(\neg Q\) is easier to work with algebraically than \(Q\) itself.
Worked exampleProve that for an integer \(n\), if \(n^2\) is even, then \(n\) is even.
We prove the contrapositive: if \(n\) is odd, then \(n^2\) is odd.
Assume \(n\) is odd, so \(n = 2k+1\) for some integer \(k\). Then
\[n^2 = (2k+1)^2 = 4k^2+4k+1 = 2(2k^2+2k)+1\]which is odd. This proves the contrapositive, and since the contrapositive is logically equivalent to the original statement,
\[\boxed{\text{if } n^2 \text{ is even, then } n \text{ is even}}\]

Contrapositive proofs involving irrational numbers

A real number is rational if it can be written as \(\dfrac{p}{q}\) for integers \(p\) and \(q\) with \(q \neq 0\); otherwise it is irrational. Claims about irrational numbers are often hard to prove directly, since "not rational" is an awkward hypothesis to compute with, but the contrapositive replaces it with the much more workable statement "is rational".
Worked exampleProve that for any real number \(x\), if \(x^2\) is irrational, then \(x\) is irrational.
We prove the contrapositive: if \(x\) is rational, then \(x^2\) is rational.
Assume \(x\) is rational, so \(x = \dfrac{p}{q}\) for integers \(p, q\) with \(q \neq 0\). Then
\[x^2 = \frac{p^2}{q^2}\]where \(p^2\) and \(q^2\) are integers and \(q^2 \neq 0\), so \(x^2\) is rational. This proves the contrapositive, so
\[\boxed{\text{if } x^2 \text{ is irrational, then } x \text{ is irrational}}\]
