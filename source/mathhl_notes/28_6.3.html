The Pythagorean identity for sine and cosine

For every real number \(\theta\):
\[\sin^2\theta + \cos^2\theta = 1\]Rearranged to isolate either squared term:
\[\sin^2\theta = 1 - \cos^2\theta \qquad \cos^2\theta = 1 - \sin^2\theta\]
Worked exampleGiven that \(\sin\theta = \dfrac{5}{13}\) and that \(\dfrac{\pi}{2} < \theta < \pi\), find the exact value of \(\cos\theta\).
\[\cos^2\theta = 1 - \sin^2\theta\]\[\cos^2\theta = 1 - \frac{25}{169} = \frac{144}{169}\]\[\cos\theta = \pm\frac{12}{13}\]Since \(\theta\) is in quadrant II, \(\cos\theta < 0\).
\[\boxed{\cos\theta = -\frac{12}{13}}\]

The double angle identity for sine

For every real number \(\theta\):
\[\sin 2\theta = 2\sin\theta\cos\theta\]
Worked exampleGiven that \(\sin\theta = \dfrac{5}{13}\) and \(\cos\theta = -\dfrac{12}{13}\), find the exact value of \(\sin 2\theta\).
\[\sin 2\theta = 2\sin\theta\cos\theta\]\[\sin 2\theta = 2\left(\frac{5}{13}\right)\left(-\frac{12}{13}\right)\]\[\boxed{\sin 2\theta = -\frac{120}{169}}\]

The double angle identities for cosine

For every real number \(\theta\), there are three equivalent forms:
\[\cos 2\theta = \cos^2\theta - \sin^2\theta\]\[\cos 2\theta = 2\cos^2\theta - 1\]\[\cos 2\theta = 1 - 2\sin^2\theta\]The second and third forms follow from the first by substituting the Pythagorean identity \(\sin^2\theta + \cos^2\theta = 1\).
Worked exampleGiven that \(\sin\theta = \dfrac{5}{13}\) and \(\cos\theta = -\dfrac{12}{13}\), find the exact value of \(\cos 2\theta\) using each of the three forms.
\[\cos 2\theta = \left(-\frac{12}{13}\right)^2 - \left(\frac{5}{13}\right)^2 = \frac{144}{169} - \frac{25}{169} = \frac{119}{169}\]\[\cos 2\theta = 2\left(-\frac{12}{13}\right)^2 - 1 = \frac{288}{169} - 1 = \frac{119}{169}\]\[\cos 2\theta = 1 - 2\left(\frac{5}{13}\right)^2 = 1 - \frac{50}{169} = \frac{119}{169}\]\[\boxed{\cos 2\theta = \frac{119}{169}}\]

Choosing the most useful form of the cosine double angle identity

When only one of \(\sin\theta\) or \(\cos\theta\) is known, choosing the form of \(\cos 2\theta\) written entirely in that function avoids first having to find the other ratio:
\[\cos 2\theta = 2\cos^2\theta - 1 \quad \text{(when } \cos\theta \text{ is known)}\]\[\cos 2\theta = 1 - 2\sin^2\theta \quad \text{(when } \sin\theta \text{ is known)}\]
Worked exampleGiven that \(\sin x = \dfrac{2}{5}\) and \(0 < x < \dfrac{\pi}{2}\), find the exact value of \(\cos 2x\) without first finding \(\cos x\).
\[\cos 2x = 1 - 2\sin^2 x\]\[\cos 2x = 1 - 2\left(\frac{2}{5}\right)^2\]\[\cos 2x = 1 - \frac{8}{25}\]\[\boxed{\cos 2x = \frac{17}{25}}\]

Using the Pythagorean identity to simplify an expression

Substituting \(\sin^2\theta = 1 - \cos^2\theta\) or \(\cos^2\theta = 1 - \sin^2\theta\) rewrites an expression containing both squared functions in terms of a single trigonometric function.
Worked exampleExpress \(2\sin^2 x + 3\cos x\) in terms of \(\cos x\) only.
\[2\sin^2 x + 3\cos x = 2(1 - \cos^2 x) + 3\cos x\]\[\boxed{= -2\cos^2 x + 3\cos x + 2}\]

Finding sin 2x and cos 2x from a single known ratio

Given one trigonometric ratio and the quadrant in which an angle lies, the Pythagorean identity gives the other ratio (with the correct sign), and the double angle identities then give \(\sin 2\theta\) and \(\cos 2\theta\) exactly.
Worked exampleGiven that \(\cos x = -\dfrac{3}{5}\) and \(\pi < x < \dfrac{3\pi}{2}\), find the exact values of (a) \(\sin x\), (b) \(\sin 2x\), and (c) \(\cos 2x\).
(a)
\[\sin^2 x = 1 - \cos^2 x = 1 - \frac{9}{25} = \frac{16}{25}\]\[\sin x = \pm\frac{4}{5}\]Since \(x\) is in quadrant III, \(\sin x < 0\).
\[\boxed{\sin x = -\frac{4}{5}}\]
(b)
\[\sin 2x = 2\sin x\cos x = 2\left(-\frac{4}{5}\right)\left(-\frac{3}{5}\right)\]\[\boxed{\sin 2x = \frac{24}{25}}\]
(c)
\[\cos 2x = 2\cos^2 x - 1 = 2\left(\frac{9}{25}\right) - 1\]\[\boxed{\cos 2x = -\frac{7}{25}}\]
