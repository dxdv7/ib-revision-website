The general form of a polynomial function

A polynomial function of degree \(n\) can be written in general form as
\[P(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0\]where \(n\) is a non-negative integer and \(a_n, a_{n-1}, \ldots, a_0\) are real coefficients with \(a_n \neq 0\). The term \(a_nx^n\) is the leading term, \(a_n\) is the leading coefficient, and \(a_0\) is the constant term.
Worked exampleFor \(P(x) = 3x^4 - 2x^3 + x - 7\), state the degree, leading coefficient, leading term and constant term.
\[\boxed{\text{degree } 4; \text{ leading coefficient } 3; \text{ leading term } 3x^4; \text{ constant term } -7}\]

Graphs of polynomial functions

The graph of a polynomial function of degree \(n\) is a smooth, continuous, unbroken curve with no sharp corners, gaps or jumps, and has at most \(n - 1\) turning points. Its end behaviour (how the curve behaves as \(x \to \infty\) and as \(x \to -\infty\)) is determined by the degree \(n\) and the sign of the leading coefficient \(a_n\): if \(n\) is even the two ends point in the same direction, and if \(n\) is odd they point in opposite directions; if \(a_n > 0\) the right end rises, and if \(a_n < 0\) the right end falls.
Worked exampleDescribe the end behaviour and state the maximum possible number of turning points of \(P(x) = -2x^5 + 3x^2 - 1\).
The degree is \(n = 5\) (odd) and the leading coefficient is \(a_5 = -2 < 0\).
\[\boxed{\text{as } x \to \infty,\ P(x) \to -\infty; \text{ as } x \to -\infty,\ P(x) \to \infty; \text{ at most 4 turning points}}\]

Zeros, roots and factors

If \(P\) is a polynomial function and \(c\) is a real number, the following statements are equivalent: \(x = c\) is a zero of \(P\); \(x = c\) is a root (solution) of the equation \(P(x) = 0\); \((x - c)\) is a linear factor of \(P(x)\); and \((c, 0)\) is an \(x\)-intercept of the graph of \(P\).
Worked exampleShow that \(x = 3\) is a root of \(P(x) = x^3 - 4x^2 + x + 6\), and hence state a linear factor of \(P(x)\).
\[P(3) = 3^3 - 4(3)^2 + 3 + 6\]\[P(3) = 27 - 36 + 3 + 6\]\[P(3) = 0\]\[\boxed{x = 3 \text{ is a root, so } (x - 3) \text{ is a factor of } P(x)}\]

The remainder theorem

If a polynomial function \(P(x)\) is divided by the linear polynomial \((x - c)\), the remainder is equal to \(P(c)\):
\[P(x) = (x - c) \cdot Q(x) + P(c)\]where \(Q(x)\) is the quotient polynomial. This means the remainder can be found directly by evaluating the polynomial at \(x = c\), without performing the division.
Worked exampleFind the remainder when \(g(x) = 2x^3 + 5x^2 - 8x + 3\) is divided by \(x + 4\).
Since \(x + 4 = x - (-4)\), the remainder equals \(g(-4)\):
\[g(-4) = 2(-4)^3 + 5(-4)^2 - 8(-4) + 3\]\[g(-4) = 2(-64) + 5(16) + 32 + 3\]\[g(-4) = -128 + 80 + 32 + 3\]\[\boxed{g(-4) = -13}\]

The factor theorem

The factor theorem states that \((x - c)\) is a factor of the polynomial \(P(x)\) if and only if \(P(c) = 0\). This is a biconditional statement: if \(P(c) = 0\) then \((x - c)\) is a factor, and if \((x - c)\) is a factor then \(P(c) = 0\).
Worked exampleFind the value of \(k\) such that \((x - 2)\) is a factor of \(P(x) = x^3 - 3x^2 + kx - 4\).
By the factor theorem, \(P(2) = 0\):
\[2^3 - 3(2)^2 + k(2) - 4 = 0\]\[8 - 12 + 2k - 4 = 0\]\[2k - 8 = 0\]\[\boxed{k = 4}\]

Sum and product of the roots of a polynomial equation

For a polynomial equation of degree \(n\) given by \(a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0 = 0\) with \(a_n \neq 0\), the sum and product of all \(n\) roots can be found directly from the coefficients:
\[\text{sum of roots} = -\frac{a_{n-1}}{a_n}, \qquad \text{product of roots} = (-1)^n\frac{a_0}{a_n}\]For a quadratic \(ax^2 + bx + c = 0\) this gives sum \(= -\dfrac{b}{a}\) and product \(= \dfrac{c}{a}\). For a cubic \(ax^3 + bx^2 + cx + d = 0\) with roots \(\alpha, \beta, \gamma\), this gives
\[\alpha + \beta + \gamma = -\frac{b}{a}, \qquad \alpha\beta\gamma = -\frac{d}{a}\]
Worked exampleTwo roots of the equation \(x^3 - 3x^2 + kx + 75 = 0\) are opposite in sign. Find all three roots and the value of \(k\).
Let the roots be \(\alpha\), \(-\alpha\) and \(\beta\).
\[\alpha + (-\alpha) + \beta = -\frac{-3}{1} = 3 \implies \beta = 3\]\[\alpha(-\alpha)(\beta) = -\frac{75}{1} = -75 \implies -\alpha^2(3) = -75\]\[\alpha^2 = 25 \implies \alpha = \pm 5\]The three roots are \(5\), \(-5\) and \(3\). Expanding the factored form gives \(k\):
\[(x - 5)(x + 5)(x - 3) = (x^2 - 25)(x - 3)\]\[(x^2-25)(x-3) = x^3 - 3x^2 - 25x + 75\]\[\boxed{\text{roots } 5, -5, 3; \quad k = -25}\]
