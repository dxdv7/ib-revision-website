Addition and subtraction of vectors

For vectors \(\mathbf{u} = \begin{pmatrix}u_1\\u_2\\u_3\end{pmatrix}\) and \(\mathbf{v} = \begin{pmatrix}v_1\\v_2\\v_3\end{pmatrix}\):
\[\mathbf{u}+\mathbf{v} = \begin{pmatrix}u_1+v_1\\u_2+v_2\\u_3+v_3\end{pmatrix}, \qquad \mathbf{u}-\mathbf{v} = \begin{pmatrix}u_1-v_1\\u_2-v_2\\u_3-v_3\end{pmatrix}\]By the triangle rule, if the initial point of \(\mathbf{v}\) is placed at the terminal point of \(\mathbf{u}\), then \(\mathbf{u}+\mathbf{v}\) is the vector from the initial point of \(\mathbf{u}\) to the terminal point of \(\mathbf{v}\). Equivalently, \(\mathbf{u}+\mathbf{v}\) is the diagonal of the parallelogram with sides \(\mathbf{u}\) and \(\mathbf{v}\).
Worked exampleGiven \(\mathbf{u} = \begin{pmatrix}3\\-1\\2\end{pmatrix}\) and \(\mathbf{v} = \begin{pmatrix}-2\\4\\1\end{pmatrix}\), find \(\mathbf{u}+\mathbf{v}\) and \(\mathbf{u}-\mathbf{v}\).
\[\mathbf{u}+\mathbf{v} = \begin{pmatrix}3+(-2)\\-1+4\\2+1\end{pmatrix} = \begin{pmatrix}1\\3\\3\end{pmatrix}\]\[\mathbf{u}-\mathbf{v} = \begin{pmatrix}3-(-2)\\-1-4\\2-1\end{pmatrix} = \begin{pmatrix}5\\-5\\1\end{pmatrix}\]\[\boxed{\mathbf{u}+\mathbf{v} = \begin{pmatrix}1\\3\\3\end{pmatrix}, \qquad \mathbf{u}-\mathbf{v} = \begin{pmatrix}5\\-5\\1\end{pmatrix}}\]

The zero vector and the negative of a vector

If the initial and terminal points of a vector coincide, the vector has magnitude zero and is called the zero vector:
\[\mathbf{0} = \begin{pmatrix}0\\0\\0\end{pmatrix}\]The negative of \(\mathbf{v} = \begin{pmatrix}v_1\\v_2\\v_3\end{pmatrix}\) is the vector \(-\mathbf{v}\), with the same magnitude as \(\mathbf{v}\) but the opposite direction:
\[-\mathbf{v} = \begin{pmatrix}-v_1\\-v_2\\-v_3\end{pmatrix}, \qquad \mathbf{v}+(-\mathbf{v}) = \mathbf{0}\]
Worked exampleGiven \(\mathbf{v} = \begin{pmatrix}3\\-2\\5\end{pmatrix}\), find \(-\mathbf{v}\) and verify that \(\mathbf{v}+(-\mathbf{v}) = \mathbf{0}\).
\[-\mathbf{v} = \begin{pmatrix}-3\\2\\-5\end{pmatrix}\]\[\mathbf{v}+(-\mathbf{v}) = \begin{pmatrix}3-3\\-2+2\\5-5\end{pmatrix} = \begin{pmatrix}0\\0\\0\end{pmatrix}\]\[\boxed{-\mathbf{v} = \begin{pmatrix}-3\\2\\-5\end{pmatrix}, \text{ and the sum is confirmed to be } \mathbf{0}}\]

Scalar multiplication

For a scalar \(k\) and vector \(\mathbf{v} = \begin{pmatrix}v_1\\v_2\\v_3\end{pmatrix}\):
\[k\mathbf{v} = \begin{pmatrix}kv_1\\kv_2\\kv_3\end{pmatrix}\]The vector \(k\mathbf{v}\) has magnitude \(|k\mathbf{v}| = |k||\mathbf{v}|\). If \(k>0\), \(k\mathbf{v}\) points in the same direction as \(\mathbf{v}\); if \(k<0\), it points in the opposite direction.
Worked exampleGiven \(\mathbf{v} = \begin{pmatrix}4\\-6\\2\end{pmatrix}\), find \(3\mathbf{v}\) and \(-\frac{1}{2}\mathbf{v}\).
\[3\mathbf{v} = \begin{pmatrix}3(4)\\3(-6)\\3(2)\end{pmatrix} = \begin{pmatrix}12\\-18\\6\end{pmatrix}\]\[-\frac{1}{2}\mathbf{v} = \begin{pmatrix}-\frac{1}{2}(4)\\-\frac{1}{2}(-6)\\-\frac{1}{2}(2)\end{pmatrix} = \begin{pmatrix}-2\\3\\-1\end{pmatrix}\]\[\boxed{3\mathbf{v} = \begin{pmatrix}12\\-18\\6\end{pmatrix}, \qquad -\frac{1}{2}\mathbf{v} = \begin{pmatrix}-2\\3\\-1\end{pmatrix}}\]

Parallel vectors

Two non-zero vectors \(\mathbf{u}\) and \(\mathbf{v}\) are parallel if and only if one is a scalar multiple of the other:
\[\mathbf{u} \parallel \mathbf{v} \iff \mathbf{u} = k\mathbf{v} \text{ for some scalar } k\]If \(k>0\) the vectors point in the same direction; if \(k<0\) they point in opposite directions.
Worked exampleShow that \(\mathbf{u} = \begin{pmatrix}-6\\9\\-3\end{pmatrix}\) is parallel to \(\mathbf{v} = \begin{pmatrix}4\\-6\\2\end{pmatrix}\), and state whether they point in the same or opposite direction.
Testing each component for a common scalar \(k\) with \(\mathbf{u} = k\mathbf{v}\):
\[\frac{-6}{4} = -\frac{3}{2}, \qquad \frac{9}{-6} = -\frac{3}{2}, \qquad \frac{-3}{2} = -\frac{3}{2}\]Since all three ratios give the same scalar \(k = -\frac{3}{2}\):
\[\boxed{\mathbf{u} = -\frac{3}{2}\mathbf{v}, \text{ so } \mathbf{u} \parallel \mathbf{v}, \text{ pointing in opposite directions since } k<0}\]

Magnitude of a vector

The magnitude (length, modulus, or norm) of \(\mathbf{v} = \begin{pmatrix}v_1\\v_2\\v_3\end{pmatrix}\) is:
\[|\mathbf{v}| = \sqrt{v_1^2+v_2^2+v_3^2}\]For a scalar multiple, \(|k\mathbf{v}| = |k||\mathbf{v}|\): the magnitude of a multiple of a vector is the absolute value of the multiple, times the magnitude of the vector.
Worked exampleFind the magnitude of \(\mathbf{v} = \begin{pmatrix}2\\-3\\6\end{pmatrix}\).
\[|\mathbf{v}| = \sqrt{2^2+(-3)^2+6^2} = \sqrt{4+9+36} = \sqrt{49}\]\[\boxed{|\mathbf{v}| = 7}\]

Unit vectors

A vector of magnitude 1 is called a unit vector. The unit vector in the same direction as a non-zero vector \(\mathbf{v}\) is found by scaling \(\mathbf{v}\) by the reciprocal of its own magnitude:
\[\hat{\mathbf{v}} = \frac{1}{|\mathbf{v}|}\mathbf{v} = \frac{\mathbf{v}}{|\mathbf{v}|}\]
Worked exampleFind the unit vector in the direction of \(\mathbf{v} = \mathbf{i} - 2\mathbf{j} + 2\mathbf{k}\).
\[|\mathbf{v}| = \sqrt{1^2+(-2)^2+2^2} = \sqrt{1+4+4} = \sqrt{9} = 3\]\[\hat{\mathbf{v}} = \frac{1}{3}(\mathbf{i} - 2\mathbf{j} + 2\mathbf{k})\]\[\boxed{\hat{\mathbf{v}} = \frac{1}{3}\mathbf{i} - \frac{2}{3}\mathbf{j} + \frac{2}{3}\mathbf{k}}\]
