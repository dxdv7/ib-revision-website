Separable differential equations

A first order differential equation is variables separable if it can be written in the form:
\[\frac{dy}{dx} = f(x)g(y)\]that is, the right-hand side factors into a function of \(x\) alone multiplied by a function of \(y\) alone. Provided \(g(y)\neq0\), the variables can be separated onto opposite sides and both sides integrated:
\[\int \frac{1}{g(y)}\,dy = \int f(x)\,dx\]
Worked exampleFind the general solution of \(\dfrac{dy}{dx}=xy\).
Separating variables (dividing by \(y\), \(y\neq0\)):
\[\int \frac{1}{y}\,dy = \int x\,dx \implies \ln|y| = \frac{x^2}{2}+c\]Exponentiating both sides, \(|y| = e^{c}e^{x^2/2}\), so writing \(A=\pm e^{c}\) for the arbitrary constant:
\[\boxed{y = Ae^{x^2/2}}\]Differentiating confirms this: \(\frac{dy}{dx}=Ax\,e^{x^2/2}=x\cdot\left(Ae^{x^2/2}\right)=xy\).

Recognising equations that need rearranging before separating

Not every separable equation is presented with \(f(x)\) and \(g(y)\) already isolated as separate factors; sometimes simple algebraic rearrangement (factorising, or rewriting a sum as a product) is needed first to see that the equation has the form \(\frac{dy}{dx}=f(x)g(y)\).
Worked exampleFind the general solution of \(\dfrac{dy}{dx}=y\cos x\).
This is already in separable form with \(f(x)=\cos x\) and \(g(y)=y\). Separating variables:
\[\int \frac{1}{y}\,dy = \int \cos x\,dx \implies \ln|y| = \sin x + c\]\[\boxed{y = Ae^{\sin x}}\]Differentiating confirms this: \(\frac{dy}{dx}=A\cos x\,e^{\sin x}=\cos x\cdot\left(Ae^{\sin x}\right)=y\cos x\).

Using an initial condition to find a particular solution

The general solution of a separable differential equation contains an arbitrary constant, representing a whole family of solution curves. Substituting a given initial condition \(y(x_0)=y_0\) into the general solution determines the value of that constant, picking out the single particular solution curve passing through \((x_0,y_0)\).
Worked exampleSolve \(\dfrac{dy}{dx}=\dfrac{x}{y}\), given \(y(0)=3\).
Separating variables:
\[\int y\,dy = \int x\,dx \implies \frac{y^2}{2}=\frac{x^2}{2}+c \implies y^2 = x^2 + C\]Applying the initial condition \(x=0,\ y=3\): \(9 = 0+C\), so \(C=9\). Since \(y(0)=3>0\), the positive root is taken:
\[\boxed{y = \sqrt{x^2+9}}\]Differentiating confirms this: \(\frac{dy}{dx}=\frac{x}{\sqrt{x^2+9}}=\frac{x}{y}\).

Homogeneous differential equations and the substitution y = vx

A first order differential equation of the form:
\[\frac{dy}{dx} = f\left(\frac{y}{x}\right)\]is called homogeneous: the right-hand side depends only on the ratio \(\frac{y}{x}\), not on \(x\) and \(y\) separately, so it is generally not separable as it stands. The substitution \(y=vx\), where \(v\) is a new function of \(x\), converts it into a separable equation. Differentiating \(y=vx\) using the product rule gives:
\[\frac{dy}{dx} = v + x\frac{dv}{dx}\]Substituting both \(y=vx\) and this expression for \(\frac{dy}{dx}\) into the original equation turns it into an equation relating \(v\), \(x\), and \(\frac{dv}{dx}\) only, which is separable in \(v\) and \(x\).
Worked exampleShow that \(\dfrac{dy}{dx}=\dfrac{x+y}{x}\) is homogeneous, and write it in terms of \(v=\dfrac{y}{x}\).
Dividing numerator and denominator by \(x\): \(\dfrac{x+y}{x}=1+\dfrac{y}{x}\), which depends only on \(\dfrac{y}{x}\), confirming the equation is homogeneous.
\[\boxed{\frac{dy}{dx} = 1+v, \text{ where } v=\frac{y}{x}}\]

Solving a homogeneous differential equation via substitution

Once the substitution \(y=vx\), \(\dfrac{dy}{dx}=v+x\dfrac{dv}{dx}\) has reduced a homogeneous equation to a separable one in \(v\) and \(x\), it is solved exactly as any other separable equation. The resulting solution in \(v\) is then converted back to \(y\) using \(v=\dfrac{y}{x}\).
Worked exampleSolve \(\dfrac{dy}{dx}=\dfrac{x+y}{x}\), given \(y(1)=2\).
Let \(y=vx\), so \(\dfrac{dy}{dx}=v+x\dfrac{dv}{dx}\). Substituting into \(\dfrac{dy}{dx}=1+v\) (shown above):
\[v+x\frac{dv}{dx} = 1+v \implies x\frac{dv}{dx}=1\]This is separable: \(\displaystyle\int dv = \int \frac{1}{x}\,dx\), giving \(v=\ln|x|+C\). Substituting back \(v=\dfrac{y}{x}\):
\[\frac{y}{x} = \ln|x|+C \implies y = x\big(\ln|x|+C\big)\]Applying the initial condition \(x=1,\ y=2\): \(2 = 1(\ln1+C)=C\), so \(C=2\):
\[\boxed{y = x\big(\ln|x|+2\big)}\]Differentiating confirms this: \(\frac{dy}{dx}=\ln|x|+2+1=\ln|x|+3\), and \(\frac{x+y}{x}=1+\frac{y}{x}=1+\ln|x|+2=\ln|x|+3\).
