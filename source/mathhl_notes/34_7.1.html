Distance between two points in three dimensions

The distance formula in three dimensions is a straightforward extension of the 2D distance formula, found by applying the Pythagorean theorem twice (once for the base rectangle, once for the diagonal of the prism). The distance \(d\) between \(P(x_1, y_1, z_1)\) and \(Q(x_2, y_2, z_2)\) is:
\[d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}\]
Worked exampleFind the distance between the points \(A(1, -2, 3)\) and \(B(4, 2, 15)\).
\[d = \sqrt{(4-1)^2 + (2-(-2))^2 + (15-3)^2}\]\[d = \sqrt{3^2 + 4^2 + 12^2} = \sqrt{9 + 16 + 144}\]\[\boxed{d = \sqrt{169} = 13}\]

Midpoint of a line segment in three dimensions

The midpoint \(M\) of the line segment joining \(P(x_1, y_1, z_1)\) and \(Q(x_2, y_2, z_2)\) has coordinates equal to the average of the corresponding coordinates of the two endpoints:
\[M = \left(\frac{x_1 + x_2}{2}, \ \frac{y_1 + y_2}{2}, \ \frac{z_1 + z_2}{2}\right)\]
Worked exampleFind the midpoint of the line segment with endpoints \(A(-1, 3, 5)\) and \(B(5, -1, 9)\).
\[M = \left(\frac{-1 + 5}{2}, \ \frac{3 + (-1)}{2}, \ \frac{5 + 9}{2}\right)\]\[\boxed{M = (2, 1, 7)}\]

Testing whether three points are collinear

Three points \(F\), \(G\), and \(H\) are collinear (lie on the same line) if the sum of the distances between two pairs of the points equals the distance between the remaining pair. In other words, the middle point lies exactly on the segment joining the two outer points.
Worked exampleUse the distance formula to show that \(F(1, -1, 3)\), \(G(2, -4, 5)\), and \(H(5, -13, 11)\) are collinear.
\[FG = \sqrt{(1-2)^2 + (-1-(-4))^2 + (3-5)^2} = \sqrt{1 + 9 + 4} = \sqrt{14}\]\[GH = \sqrt{(2-5)^2 + (-4-(-13))^2 + (5-11)^2} = \sqrt{9 + 81 + 36} = \sqrt{126} = 3\sqrt{14}\]\[FH = \sqrt{(1-5)^2 + (-1-(-13))^2 + (3-11)^2} = \sqrt{16 + 144 + 64} = \sqrt{224} = 4\sqrt{14}\]\[\boxed{FG + GH = \sqrt{14} + 3\sqrt{14} = 4\sqrt{14} = FH}\]Since \(FG + GH = FH\), the points \(F\), \(G\), and \(H\) are collinear.

Using midpoints to find an unknown vertex of a parallelogram

The diagonals of a parallelogram bisect each other. If \(ABCD\) is a parallelogram, then diagonals \([AC]\) and \([BD]\) share the same midpoint. Setting the midpoint of each diagonal equal gives three equations that can be solved for an unknown vertex.
Worked exampleThree vertices of parallelogram \(ABCD\) are \(A(3, -1, 2)\), \(B(1, 2, -4)\), and \(C(-1, 1, 2)\). Find the coordinates of vertex \(D\).
The midpoint of \([AC]\) is:
\[M = \left(\frac{3 + (-1)}{2}, \ \frac{-1 + 1}{2}, \ \frac{2 + 2}{2}\right) = (1, 0, 2)\]Let \(D = (x, y, z)\). Since \([BD]\) must have the same midpoint:
\[\left(\frac{1 + x}{2}, \ \frac{2 + y}{2}, \ \frac{-4 + z}{2}\right) = (1, 0, 2)\]Solving each coordinate: \(1 + x = 2\), \(2 + y = 0\), \(-4 + z = 4\).
\[\boxed{D = (1, -2, 8)}\]

Classifying a triangle using side lengths from the distance formula

Given three points in space, computing all three side lengths with the distance formula allows the triangle to be classified: scalene (no equal sides), isosceles (two equal sides), or equilateral (three equal sides). The converse of the Pythagorean theorem can then be applied to the three side lengths to test for a right angle.
Worked exampleShow that the triangle with vertices \(A(0, 7, 10)\), \(B(-1, 6, 6)\), and \(C(-4, 9, 6)\) is a right-angled isosceles triangle.
\[AB = \sqrt{(0-(-1))^2 + (7-6)^2 + (10-6)^2} = \sqrt{1 + 1 + 16} = \sqrt{18}\]\[BC = \sqrt{(-1-(-4))^2 + (6-9)^2 + (6-6)^2} = \sqrt{9 + 9 + 0} = \sqrt{18}\]\[AC = \sqrt{(0-(-4))^2 + (7-9)^2 + (10-6)^2} = \sqrt{16 + 4 + 16} = \sqrt{36} = 6\]Since \(AB = BC\), the triangle is isosceles. Checking the converse of the Pythagorean theorem:
\[AB^2 + BC^2 = 18 + 18 = 36 = AC^2\]\[\boxed{\text{Triangle } ABC \text{ is right-angled at } B \text{ and isosceles}}\]

Distance from a point to the coordinate axes and origin

The distance from a point \((x, y, z)\) to the origin and to each coordinate axis follows from the 3D distance formula, treating the nearest point on the axis as having the matching coordinates set to zero:
\[\text{distance to origin} = \sqrt{x^2 + y^2 + z^2}\]\[\text{distance to } x\text{-axis} = \sqrt{y^2 + z^2}, \quad \text{distance to } y\text{-axis} = \sqrt{x^2 + z^2}, \quad \text{distance to } z\text{-axis} = \sqrt{x^2 + y^2}\]
Worked exampleFind the distance of the point \((2, 6, -3)\) from (a) the origin, and (b) the \(x\)-axis.
\[\text{distance to origin} = \sqrt{2^2 + 6^2 + (-3)^2} = \sqrt{4 + 36 + 9} = \sqrt{49}\]\[\boxed{= 7}\]\[\text{distance to } x\text{-axis} = \sqrt{6^2 + (-3)^2} = \sqrt{36 + 9} = \sqrt{45}\]\[\boxed{= 3\sqrt{5}}\]
