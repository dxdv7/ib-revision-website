Solving basic equations of the form sin x = k

To solve \(\sin x = k\) over a given domain: find the reference angle \(\alpha = \arcsin(|k|)\), with \(0 \le \alpha \le \frac{\pi}{2}\). If \(k > 0\), the solutions lie in quadrants I and II, namely \(x = \alpha\) and \(x = \pi - \alpha\) (plus multiples of the period \(2\pi\)). If \(k < 0\), the solutions lie in quadrants III and IV, namely \(x = \pi + \alpha\) and \(x = 2\pi - \alpha\) (plus multiples of \(2\pi\)).
Worked exampleSolve \(\sin x = -\frac{1}{2}\) for \(0 \le x < 2\pi\).
\[\alpha = \arcsin\left(\frac{1}{2}\right) = \frac{\pi}{6}\]Since \(\sin x < 0\), the solutions lie in quadrants III and IV:
\[x = \pi + \frac{\pi}{6} = \frac{7\pi}{6} \qquad \text{or} \qquad x = 2\pi - \frac{\pi}{6} = \frac{11\pi}{6}\]\[\boxed{x = \frac{7\pi}{6}, \frac{11\pi}{6}}\]

Solving basic equations of the form cos x = k and tan x = k

For \(\cos x = k\): using reference angle \(\alpha = \arccos(|k|)\), if \(k > 0\) the solutions lie in quadrants I and IV, \(x = \alpha\) and \(x = 2\pi - \alpha\); if \(k < 0\) the solutions lie in quadrants II and III, \(x = \pi - \alpha\) and \(x = \pi + \alpha\). For \(\tan x = k\): using reference angle \(\alpha = \arctan(|k|)\) and period \(\pi\), if \(k > 0\) the solutions are \(x = \alpha\) and \(x = \alpha + \pi\); if \(k < 0\) the solutions are \(x = \pi - \alpha\) and \(x = 2\pi - \alpha\) (adjusted to fit the given domain).
Worked exampleSolve \(2\cos x + \sqrt{3} = 0\) for \(0 \le x < 2\pi\).
\[\cos x = -\frac{\sqrt{3}}{2}\]\[\alpha = \arccos\left(\frac{\sqrt{3}}{2}\right) = \frac{\pi}{6}\]Since \(\cos x < 0\), the solutions lie in quadrants II and III:
\[x = \pi - \frac{\pi}{6} = \frac{5\pi}{6} \qquad \text{or} \qquad x = \pi + \frac{\pi}{6} = \frac{7\pi}{6}\]\[\boxed{x = \frac{5\pi}{6}, \frac{7\pi}{6}}\]

Rearranging an equation before solving

Many equations must be rearranged to isolate a single trig ratio, or factored, before the reference-angle method can be applied: collect like terms and factor out common factors, but never divide both sides of an equation by a trigonometric expression that could equal zero, since this can lose solutions.
Worked exampleSolve \(2\sin x\cos x = \sin x\) for \(0 \le x < 2\pi\).
\[2\sin x\cos x - \sin x = 0\]\[\sin x(2\cos x - 1) = 0\]\[\sin x = 0 \qquad \text{or} \qquad \cos x = \frac{1}{2}\]For \(\sin x = 0\): \(x = 0\) or \(x = \pi\). For \(\cos x = \frac{1}{2}\): \(x = \frac{\pi}{3}\) or \(x = \frac{5\pi}{3}\).
\[\boxed{x = 0, \frac{\pi}{3}, \pi, \frac{5\pi}{3}}\]

Equations with a squared trigonometric ratio

When an equation contains the square of a trig ratio, such as \(\sin^2 x = k\) with \(k \ge 0\), take the square root of both sides, remembering both the positive and negative roots: \(\sin x = \pm\sqrt{k}\). Each sign gives its own family of solutions, all of which must be checked against the given domain.
Worked exampleSolve \(\sin^2 x = \frac{1}{4}\) for \(0 \le x < 2\pi\).
\[\sin x = \pm\frac{1}{2}\]For \(\sin x = \frac{1}{2}\): \(x = \frac{\pi}{6}\) or \(x = \frac{5\pi}{6}\).
For \(\sin x = -\frac{1}{2}\): \(x = \frac{7\pi}{6}\) or \(x = \frac{11\pi}{6}\).
\[\boxed{x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{7\pi}{6}, \frac{11\pi}{6}}\]

Using identities to simplify a mixed-argument equation

Some equations mix different trig functions, or the same function with different arguments (such as \(x\) and \(2x\)). Use the Pythagorean identity \(\sin^2 x + \cos^2 x = 1\) or a double angle identity (\(\sin 2x = 2\sin x\cos x\), \(\cos 2x = 2\cos^2 x - 1 = 1 - 2\sin^2 x = \cos^2 x - \sin^2 x\)) to rewrite the equation in terms of a single trig function of the same argument, then solve by factoring.
Worked exampleSolve \(\cos 2x = \cos x\) for \(0 \le x < 2\pi\).
\[2\cos^2 x - 1 = \cos x\]\[2\cos^2 x - \cos x - 1 = 0\]\[(2\cos x + 1)(\cos x - 1) = 0\]\[\cos x = -\frac{1}{2} \qquad \text{or} \qquad \cos x = 1\]For \(\cos x = 1\): \(x = 0\). For \(\cos x = -\frac{1}{2}\): \(x = \frac{2\pi}{3}\) or \(x = \frac{4\pi}{3}\).
\[\boxed{x = 0, \frac{2\pi}{3}, \frac{4\pi}{3}}\]

Quadratic-in-trig equations

An equation that is quadratic in a single trig ratio, such as \(a\sin^2 x + b\sin x + c = 0\), can be solved by substituting \(u = \sin x\) to obtain \(au^2 + bu + c = 0\). Solve this quadratic for \(u\), discard any value with \(|u| > 1\) (impossible for sine or cosine), then solve \(\sin x = u\) for \(x\) in the given domain.
Worked exampleSolve \(2\sin^2 x - 3\sin x + 1 = 0\) for \(0 \le x < 2\pi\).
Let \(u = \sin x\):
\[2u^2 - 3u + 1 = 0\]\[(2u - 1)(u - 1) = 0\]\[u = \frac{1}{2} \qquad \text{or} \qquad u = 1\]For \(\sin x = 1\): \(x = \frac{\pi}{2}\). For \(\sin x = \frac{1}{2}\): \(x = \frac{\pi}{6}\) or \(x = \frac{5\pi}{6}\).
\[\boxed{x = \frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}}\]
