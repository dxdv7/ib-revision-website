Grouping continuous data into class intervals

When a continuous variable takes many different values, raw data is organised into a grouped frequency table by dividing the range of values into non-overlapping class intervals, usually of equal width, and counting the number of data values (the frequency) that fall into each interval. An interval such as \(5 \le t < 10\) contains every value from \(5\) up to, but not including, \(10\). The class width of an interval is the difference between its upper and lower boundaries:
\[\text{class width} = \text{upper boundary} - \text{lower boundary}\]
Worked exampleThe times, in minutes, taken by \(12\) customers to be served are: \(3, 8, 11, 14, 6, 19, 9, 12, 2, 17, 13, 7\). Group this data into class intervals of width \(5\), starting at \(0\).
Sorting the values into each interval:
\(0 \le t < 5\): \(3, 2\) — frequency \(2\)
\(5 \le t < 10\): \(8, 6, 9, 7\) — frequency \(4\)
\(10 \le t < 15\): \(11, 14, 12, 13\) — frequency \(4\)
\(15 \le t < 20\): \(19, 17\) — frequency \(2\)
\[\boxed{2+4+4+2=12, \text{ which matches the total number of customers}}\]

Mid-interval values and interval boundaries

For a class interval with lower boundary \(a\) and upper boundary \(b\), the mid-interval value (or midpoint) is:
\[m = \frac{a+b}{2}\]This single value is used to represent every data value that falls inside the interval, since the individual raw values inside each class are no longer known once the data has been grouped.
Worked exampleThe waiting times, in minutes, of \(40\) passengers at a bus stop are grouped as follows:
\(0 \le t < 5\): frequency \(4\)
\(5 \le t < 10\): frequency \(9\)
\(10 \le t < 15\): frequency \(14\)
\(15 \le t < 20\): frequency \(8\)
\(20 \le t < 25\): frequency \(5\)
Find the mid-interval value of the class \(10 \le t < 15\), and check that the frequencies total \(40\).
\[m = \frac{10+15}{2}\]\[\boxed{m=12.5}\]Checking the total frequency: \(4+9+14+8+5=40\), which matches the \(40\) passengers given.

Frequency histograms

A frequency histogram represents a grouped frequency table graphically. Class boundaries are marked on the horizontal axis, and a bar is drawn above each class interval. When all class widths are equal, as is the case throughout this course, the height of each bar is directly proportional to (and usually equal to) the frequency of that class, so taller bars represent more frequently occurring classes. Unlike a bar chart for categorical data, the bars in a histogram are drawn with no gaps between them, since the horizontal axis is a continuous numerical scale.
Worked exampleUsing the bus-stop waiting time data above, state the height of each bar of the frequency histogram, and identify the tallest bar.
Since every class has the same width of \(5\) minutes, the height of each bar equals its frequency:
\(0 \le t < 5\): height \(4\)
\(5 \le t < 10\): height \(9\)
\(10 \le t < 15\): height \(14\)
\(15 \le t < 20\): height \(8\)
\(20 \le t < 25\): height \(5\)
\[\boxed{\text{The tallest bar is } 10 \le t < 15, \text{ with height } 14}\]

The modal class

For grouped data, the exact mode usually cannot be found, since the individual values inside each class are unknown. Instead, the modal class is reported: the class interval with the highest frequency. On a histogram, the modal class corresponds to the tallest bar.
Worked exampleState the modal class of the bus-stop waiting time data.
The frequencies of the five classes are \(4, 9, 14, 8, 5\). The greatest of these is \(14\), corresponding to the class \(10 \le t < 15\).
\[\boxed{\text{modal class} = 10 \le t < 15}\]

Relative frequency and percentage frequency distributions

The relative frequency of a class is the proportion of the total data that falls into it:
\[\text{relative frequency} = \frac{f}{n}\]where \(f\) is the frequency of the class and \(n\) is the total frequency. Multiplying by \(100\) converts a relative frequency into a percentage frequency. Relative and percentage frequency distributions are useful for comparing groups of different overall sizes, since they describe proportions rather than raw counts.
Worked exampleFind the percentage frequency of each class in the bus-stop waiting time data, and check that the percentages total \(100\%\).
\[\frac{4}{40}\times100=10, \qquad \frac{9}{40}\times100=22.5, \qquad \frac{14}{40}\times100=35, \qquad \frac{8}{40}\times100=20, \qquad \frac{5}{40}\times100=12.5\]\[\boxed{10\%, 22.5\%, 35\%, 20\%, 12.5\%, \text{ totalling } 100\%}\]
