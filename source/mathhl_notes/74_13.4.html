Derivative of the exponential function e^x

The exponential function \(f(x)=e^x\) has the remarkable property that it is its own derivative:
\[\frac{d}{dx}(e^x)=e^x\]This follows from the definition of \(e\) as the number for which \(\displaystyle\lim_{h\to0}\frac{e^h-1}{h}=1\), so that \(f'(x)=\displaystyle\lim_{h\to0}\frac{e^{x+h}-e^x}{h}=e^x\displaystyle\lim_{h\to0}\frac{e^h-1}{h}=e^x\).
Worked exampleFind the gradient of the curve \(y=e^x\) at the point where \(x=0\), and at the point where \(x=2\) (to 3 s.f.).
\[\frac{dy}{dx}=e^x\]At \(x=0\): \(\dfrac{dy}{dx}=e^0=1\).
At \(x=2\): \(\dfrac{dy}{dx}=e^2\approx7.39\).
\[\boxed{\left.\frac{dy}{dx}\right|_{x=0}=1, \qquad \left.\frac{dy}{dx}\right|_{x=2}\approx7.39}\]

Derivative of e^g(x) via the chain rule

For a composite exponential function with inner function \(g(x)\):
\[\frac{d}{dx}\big[e^{g(x)}\big]=e^{g(x)}\cdot g'(x)\]
Worked exampleDifferentiate \(y=e^{3x^2-x}\).
Here \(g(x)=3x^2-x\), so \(g'(x)=6x-1\).
\[\frac{dy}{dx}=e^{3x^2-x}(6x-1)\]\[\boxed{\frac{dy}{dx}=(6x-1)e^{3x^2-x}}\]

Derivative of the natural logarithm ln x

For \(x>0\), the derivative of the natural logarithm function is:
\[\frac{d}{dx}(\ln x)=\frac{1}{x}\]This can be derived by writing \(y=\ln x\) as \(e^y=x\) and differentiating implicitly: \(e^y\dfrac{dy}{dx}=1\), so \(\dfrac{dy}{dx}=\dfrac{1}{e^y}=\dfrac{1}{x}\).
Worked exampleFind the gradient of \(y=\ln x\) at \(x=5\) (to 3 s.f.).
\[\frac{dy}{dx}=\frac{1}{x}\]At \(x=5\): \(\dfrac{dy}{dx}=\dfrac{1}{5}=0.2\).
\[\boxed{\left.\frac{dy}{dx}\right|_{x=5}=0.2}\]

Derivative of ln(g(x)) via the chain rule

For a composite logarithmic function with inner function \(g(x)\), where \(g(x)>0\):
\[\frac{d}{dx}\big[\ln(g(x))\big]=\frac{g'(x)}{g(x)}\]
Worked exampleDifferentiate \(y=\ln(x^2+4x)\).
Here \(g(x)=x^2+4x\), so \(g'(x)=2x+4\).
\[\frac{dy}{dx}=\frac{2x+4}{x^2+4x}\]\[\boxed{\frac{dy}{dx}=\frac{2x+4}{x^2+4x}}\]

Derivative of a^x for a general base

For a general base \(a>0\), \(a\neq1\), writing \(a^x=e^{x\ln a}\) and using the chain rule:
\[\frac{d}{dx}(a^x)=\frac{d}{dx}\big(e^{x\ln a}\big)=e^{x\ln a}\cdot\ln a=a^x\ln a\]So:
\[\frac{d}{dx}(a^x)=a^x\ln a\]
Worked exampleDifferentiate \(y=2^x\), and find the gradient at \(x=3\) (to 3 s.f.).
\[\frac{dy}{dx}=2^x\ln2\]At \(x=3\): \(\dfrac{dy}{dx}=2^3\ln2=8\ln2\approx5.55\).
\[\boxed{\frac{dy}{dx}=2^x\ln2, \qquad \left.\frac{dy}{dx}\right|_{x=3}\approx5.55}\]

Combining exponential and logarithmic derivatives with product and quotient rules

When \(e^x\) or \(\ln x\) (or their chain-rule forms) appear as a factor in a product or quotient, differentiate using the product rule \(\dfrac{d}{dx}(uv)=u'v+uv'\) or the quotient rule \(\dfrac{d}{dx}\!\left(\dfrac{u}{v}\right)=\dfrac{u'v-uv'}{v^2}\), substituting the exponential or logarithmic derivative for whichever factor it is.
Worked exampleDifferentiate \(y=x^2e^x\) and \(y=\dfrac{\ln x}{x}\).
For \(y=x^2e^x\): let \(u=x^2\), \(v=e^x\), so \(u'=2x\), \(v'=e^x\).
\[\frac{dy}{dx}=u'v+uv'=2xe^x+x^2e^x=x(2+x)e^x\]For \(y=\dfrac{\ln x}{x}\): let \(u=\ln x\), \(v=x\), so \(u'=\dfrac{1}{x}\), \(v'=1\).
\[\frac{dy}{dx}=\frac{u'v-uv'}{v^2}=\frac{\frac{1}{x}\cdot x-\ln x\cdot1}{x^2}=\frac{1-\ln x}{x^2}\]\[\boxed{\frac{d}{dx}(x^2e^x)=x(2+x)e^x, \qquad \frac{d}{dx}\left(\frac{\ln x}{x}\right)=\frac{1-\ln x}{x^2}}\]
