Unit circle definitions of sine, cosine, and tangent

For a real number \(\theta\), let \((x, y)\) be the point on the unit circle \(x^2 + y^2 = 1\) reached by an arc of length \(\theta\) starting at \((1, 0)\), measured anti-clockwise for \(\theta > 0\) and clockwise for \(\theta < 0\). The trigonometric functions are defined by:
\[\cos\theta = x \qquad \sin\theta = y \qquad \tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{y}{x}, \ \cos\theta \neq 0\]
Worked exampleAn angle \(\theta\) in standard position has its terminal side intersecting the unit circle at the point \(\left(\dfrac{5}{13}, -\dfrac{12}{13}\right)\). Find the exact values of \(\sin\theta\), \(\cos\theta\), and \(\tan\theta\).
\[\sin\theta = -\frac{12}{13} \qquad \cos\theta = \frac{5}{13}\]\[\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{-12/13}{5/13}\]\[\boxed{\tan\theta = -\frac{12}{5}}\]

Exact values at common first-quadrant angles

The exact values of sine, cosine, and tangent at \(0\), \(\dfrac{\pi}{6}\), \(\dfrac{\pi}{4}\), \(\dfrac{\pi}{3}\), and \(\dfrac{\pi}{2}\) should be memorised:
\[\sin 0 = 0, \quad \sin\frac{\pi}{6} = \frac{1}{2}, \quad \sin\frac{\pi}{4} = \frac{\sqrt{2}}{2}, \quad \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}, \quad \sin\frac{\pi}{2} = 1\]\[\cos 0 = 1, \quad \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}, \quad \cos\frac{\pi}{4} = \frac{\sqrt{2}}{2}, \quad \cos\frac{\pi}{3} = \frac{1}{2}, \quad \cos\frac{\pi}{2} = 0\]\[\tan 0 = 0, \quad \tan\frac{\pi}{6} = \frac{\sqrt{3}}{3}, \quad \tan\frac{\pi}{4} = 1, \quad \tan\frac{\pi}{3} = \sqrt{3}, \quad \tan\frac{\pi}{2} \text{ is undefined}\]
Worked exampleFind the exact value of \(\sin\dfrac{\pi}{3} + \cos\dfrac{\pi}{6}\).
\[\sin\frac{\pi}{3} + \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2} + \frac{\sqrt{3}}{2}\]\[\boxed{= \sqrt{3}}\]

Signs of the trigonometric functions by quadrant

The sign of each trigonometric function depends on the quadrant containing the terminal side of \(\theta\), since \(\cos\theta = x\) and \(\sin\theta = y\):
\[\text{Quadrant I: } \sin\theta, \cos\theta, \tan\theta \text{ all positive}\]\[\text{Quadrant II: only } \sin\theta \text{ positive}\]\[\text{Quadrant III: only } \tan\theta \text{ positive}\]\[\text{Quadrant IV: only } \cos\theta \text{ positive}\]
Worked exampleState the sign of \(\sin\theta\), \(\cos\theta\), and \(\tan\theta\) for \(\theta = \dfrac{5\pi}{4}\).
Since \(\pi < \dfrac{5\pi}{4} < \dfrac{3\pi}{2}\), the terminal side lies in quadrant III.
\[\boxed{\sin\theta < 0, \ \cos\theta < 0, \ \tan\theta > 0}\]

Exact values using reference angles

For an angle \(\theta\) that is not in the first quadrant, the reference angle is the acute angle between the terminal side and the \(x\)-axis. The trigonometric ratios of \(\theta\) have the same magnitude as those of the reference angle, with the sign determined by the quadrant (CAST rule).
Worked exampleFind the exact values of \(\sin\dfrac{7\pi}{4}\), \(\cos\dfrac{7\pi}{4}\), and \(\tan\dfrac{7\pi}{4}\).
The reference angle is \(2\pi - \dfrac{7\pi}{4} = \dfrac{\pi}{4}\), and \(\dfrac{7\pi}{4}\) lies in quadrant IV, where cosine is positive and sine and tangent are negative.
\[\boxed{\sin\frac{7\pi}{4} = -\frac{\sqrt{2}}{2}, \quad \cos\frac{7\pi}{4} = \frac{\sqrt{2}}{2}, \quad \tan\frac{7\pi}{4} = -1}\]

Tangent as the ratio of sine to cosine

For any angle \(\theta\) where \(\cos\theta \neq 0\):
\[\tan\theta = \frac{\sin\theta}{\cos\theta}\]This ratio is undefined whenever \(\cos\theta = 0\), that is, when \(\theta = \dfrac{\pi}{2} + k\pi\), where \(k\) is an integer.
Worked exampleGiven that \(\sin\dfrac{4\pi}{3} = -\dfrac{\sqrt{3}}{2}\) and \(\cos\dfrac{4\pi}{3} = -\dfrac{1}{2}\), find the exact value of \(\tan\dfrac{4\pi}{3}\).
\[\tan\frac{4\pi}{3} = \frac{-\sqrt{3}/2}{-1/2}\]\[\boxed{\tan\frac{4\pi}{3} = \sqrt{3}}\]
