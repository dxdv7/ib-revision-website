Recognising and decomposing rational functions for integration

Before a rational function can be integrated directly, its denominator is often factorised and the fraction split into simpler pieces. For a proper fraction (numerator degree less than denominator degree) whose denominator factorises into two distinct linear factors:
\[\frac{P(x)}{(x-a)(x-b)} = \frac{A}{x-a}+\frac{B}{x-b}\]The constants \(A\) and \(B\) are found by multiplying through by the denominator and either substituting \(x=a\) and \(x=b\) in turn, or comparing coefficients. This is exactly the method met earlier when decomposing rational functions (Section 2.6); here the focus shifts to what happens once the decomposition is in hand.
Worked exampleDecompose \(\dfrac{x+1}{x^2+5x+6}\) into partial fractions.
The denominator factorises as \(x^2+5x+6=(x+2)(x+3)\), so write:
\[\frac{x+1}{(x+2)(x+3)} = \frac{A}{x+2}+\frac{B}{x+3} \implies x+1 = A(x+3)+B(x+2)\]Setting \(x=-3\): \(-2 = B(-1)\), so \(B=2\). Setting \(x=-2\): \(-1=A(1)\), so \(A=-1\):
\[\boxed{\frac{x+1}{x^2+5x+6} = \frac{-1}{x+2}+\frac{2}{x+3}}\]

Integrating each partial fraction term

Once a rational function has been split into terms of the form \(\frac{k}{x-a}\), each term integrates directly using the standard logarithmic rule:
\[\int \frac{k}{x-a}\,dx = k\ln|x-a|+C\]since the derivative of \(\ln|x-a|\) is \(\frac{1}{x-a}\) by the chain rule. The whole point of decomposing first is that a sum of fractions like this is far easier to integrate term by term than the original combined fraction.
Worked exampleEvaluate \(\displaystyle\int \frac{x+1}{x^2+5x+6}\,dx\), using the decomposition found above.
Substituting \(\frac{-1}{x+2}+\frac{2}{x+3}\) for the integrand:
\[\int \frac{x+1}{x^2+5x+6}\,dx = \int \left(\frac{-1}{x+2}+\frac{2}{x+3}\right)dx\]\[\boxed{\int \frac{x+1}{x^2+5x+6}\,dx = -\ln|x+2|+2\ln|x+3|+C}\]

A full worked example: distinct linear factors

To integrate a rational function with two distinct linear factors in the denominator: (1) decompose into partial fractions, solving for the unknown constants; (2) integrate each resulting term using the logarithmic rule; (3) combine the results, remembering the single constant of integration \(C\) at the end.
Worked exampleEvaluate \(\displaystyle\int \frac{3x+5}{(x+1)(x+2)}\,dx\).
Decompose: \(\frac{3x+5}{(x+1)(x+2)} = \frac{A}{x+1}+\frac{B}{x+2}\), so \(3x+5=A(x+2)+B(x+1)\).
Setting \(x=-1\): \(2=A(1)\), so \(A=2\). Setting \(x=-2\): \(-1=B(-1)\), so \(B=1\):
\[\frac{3x+5}{(x+1)(x+2)} = \frac{2}{x+1}+\frac{1}{x+2}\]Integrating term by term:
\[\boxed{\int \frac{3x+5}{(x+1)(x+2)}\,dx = 2\ln|x+1|+\ln|x+2|+C}\]

Repeated linear factors

When the denominator is a repeated linear factor \((x-a)^2\), a single term \(\frac{A}{x-a}\) is not general enough; an extra term with the squared factor in the denominator is required:
\[\frac{P(x)}{(x-a)^2} = \frac{A}{x-a}+\frac{B}{(x-a)^2}\]The second term integrates using the power rule rather than the logarithmic rule, since \((x-a)^{-2}\) is a power, not a reciprocal:
\[\int \frac{B}{(x-a)^2}\,dx = -\frac{B}{x-a}+C\]
Worked exampleEvaluate \(\displaystyle\int \frac{5x+3}{(x+1)^2}\,dx\).
Decompose: \(\frac{5x+3}{(x+1)^2} = \frac{A}{x+1}+\frac{B}{(x+1)^2}\), so \(5x+3=A(x+1)+B\).
Expanding the right side: \(Ax+(A+B)=5x+3\), giving \(A=5\) and \(A+B=3\), so \(B=-2\):
\[\frac{5x+3}{(x+1)^2} = \frac{5}{x+1}-\frac{2}{(x+1)^2}\]Integrating each term (the second using the power rule on \((x+1)^{-2}\)):
\[\boxed{\int \frac{5x+3}{(x+1)^2}\,dx = 5\ln|x+1|+\frac{2}{x+1}+C}\]

Improper rational functions: divide before decomposing

Partial fractions only apply to a proper fraction, where the numerator's degree is strictly less than the denominator's. If the numerator's degree is equal to or greater than the denominator's, perform polynomial long division first, writing the integrand as a polynomial plus a proper remainder fraction, and only then decompose the remainder:
\[\frac{N(x)}{D(x)} = Q(x) + \frac{R(x)}{D(x)}, \qquad \deg R < \deg D\]
Worked exampleEvaluate \(\displaystyle\int \frac{x^2-x-3}{(x-1)(x+2)}\,dx\).
The denominator expands to \(x^2+x-2\), and since the numerator also has degree 2, the fraction is improper. Dividing:
\[x^2-x-3 = 1\cdot(x^2+x-2) + (-2x-1)\]so \(\dfrac{x^2-x-3}{(x-1)(x+2)} = 1 - \dfrac{2x+1}{(x-1)(x+2)}\). Decomposing the remainder, \(\dfrac{2x+1}{(x-1)(x+2)}=\dfrac{A}{x-1}+\dfrac{B}{x+2}\) gives \(2x+1=A(x+2)+B(x-1)\); setting \(x=1\) gives \(A=1\), and setting \(x=-2\) gives \(B=1\):
\[\frac{x^2-x-3}{(x-1)(x+2)} = 1-\frac{1}{x-1}-\frac{1}{x+2}\]Integrating term by term:
\[\boxed{\int \frac{x^2-x-3}{(x-1)(x+2)}\,dx = x-\ln|x-1|-\ln|x+2|+C}\]

Writing the final answer as a single logarithm

The laws of logarithms, \(n\ln|A| = \ln|A|^n\) and \(\ln|A|+\ln|B|=\ln|AB|\), can be used to write a sum of logarithmic terms as a single logarithm. This is not required, but it is a useful way to present or simplify a final answer and to check equivalence between two differently-written results.
Worked exampleWrite the result \(\displaystyle\int \frac{3x+5}{(x+1)(x+2)}\,dx = 2\ln|x+1|+\ln|x+2|+C\) as a single logarithm.
Using \(2\ln|x+1| = \ln|x+1|^2 = \ln\big((x+1)^2\big)\) and then combining with \(\ln|x+2|\):
\[\boxed{\int \frac{3x+5}{(x+1)(x+2)}\,dx = \ln\!\big((x+1)^2|x+2|\big)+C}\]
