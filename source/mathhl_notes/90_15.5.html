Finding an unknown standard deviation

If \(\mu\) is known but \(\sigma\) is unknown, a given probability for a specific value of \(X\) can be used to form an equation in \(\sigma\) via the standardization formula \(z = \dfrac{x-\mu}{\sigma}\), then solved for \(\sigma\).
Worked example\(X \sim N(100, \sigma^2)\) and it is known that \(P(X>115) = 0.10\). Find \(\sigma\).
\[P(X<115) = 1-0.10 = 0.90\]From a GDC, the \(z\)-value for \(p=0.90\) is \(z=1.282\). Using the standardization formula:
\[1.282 = \dfrac{115-100}{\sigma} = \dfrac{15}{\sigma}\]\[\sigma = \dfrac{15}{1.282}\]\[\boxed{\sigma = 11.7 \text{ (3 s.f.)}}\]

Finding an unknown mean

If \(\sigma\) is known but \(\mu\) is unknown, the same strategy applies: find the required \(z\)-value from the given probability, then solve \(z = \dfrac{x-\mu}{\sigma}\) for \(\mu\).
Worked example\(X \sim N(\mu, 36)\) and it is known that \(P(X<40) = 0.25\). Find \(\mu\).
Here \(\sigma=6\). Since \(0.25\) is a lower-tail probability below \(0.5\), the corresponding \(z\)-value is negative. From a GDC, the \(z\)-value for \(p=0.25\) is \(z=-0.6745\):
\[-0.6745 = \dfrac{40-\mu}{6}\]\[40-\mu = -4.047\]\[\mu = 40+4.047\]\[\boxed{\mu = 44.0 \text{ (3 s.f.)}}\]
