Solving exponential equations using logarithms

To solve an equation with the variable in the exponent, first isolate the exponential expression, then take the logarithm of both sides and use \(\log_{b}(M^{k}) = k\log_{b}M\) to bring the exponent down:
\[a^{x} = k \implies \log(a^{x}) = \log k \implies x\log a = \log k \implies x = \frac{\log k}{\log a}\]
Worked exampleSolve \(5^{2x-1} = 70\) for \(x\), giving the answer to 3 significant figures.
\[\log(5^{2x-1}) = \log 70\]\[(2x-1)\log 5 = \log 70\]\[2x - 1 = \frac{\log 70}{\log 5}\]\[2x - 1 \approx 2.641\]\[2x \approx 3.641\]\[\boxed{x \approx 1.82}\]

Exponential equations in quadratic form

An equation such as \(a^{2x} - c \cdot a^{x} - d = 0\) can be solved by substituting \(u = a^{x}\), since \(a^{2x} = (a^{x})^{2}\). The resulting quadratic in \(u\) is solved first, and any negative value of \(u\) is rejected, since \(a^{x} > 0\) for all \(x\).
Worked exampleSolve \(9^{x} - 8(3^{x}) - 9 = 0\) for \(x\).
\[(3^{x})^{2} - 8(3^{x}) - 9 = 0\]Let \(u = 3^{x}\):
\[u^{2} - 8u - 9 = 0\]\[(u-9)(u+1) = 0\]\[u = 9 \text{ or } u = -1\]Since \(3^{x} > 0\), reject \(u = -1\):
\[3^{x} = 9 = 3^{2}\]\[\boxed{x = 2}\]

Solving logarithmic equations using the definition

A logarithmic equation can be solved directly by rewriting it in exponential form using \(y = \log_{b}x \iff x = b^{y}\). Because the logarithmic function is one-to-one, if two logarithms with the same base are equal then their arguments must be equal:
\[\log_{b}M = \log_{b}N \implies M = N\]provided \(M > 0\) and \(N > 0\).
Worked example(a) Solve \(\log_{4}(3x+1) = 3\) for \(x\).
\[3x + 1 = 4^{3}\]\[3x + 1 = 64\]\[3x = 63\]\[\boxed{x = 21}\]
(b) Solve \(\log(5x-3) = \log(2x+9)\) for \(x\).
\[5x - 3 = 2x + 9\]\[3x = 12\]\[\boxed{x = 4}\]Checking the domain: \(5(4)-3 = 17 > 0\) and \(2(4)+9 = 17 > 0\), so \(x=4\) is valid.

Solving logarithmic equations using the laws of logarithms

When a logarithmic equation contains a sum or difference of logarithms, combine them into a single logarithm first using the laws of logarithms, and then convert to exponential form.
Worked exampleSolve \(\log_{3}x + \log_{3}(x+6) = 3\) for \(x\).
\[\log_{3}[x(x+6)] = 3\]\[x(x+6) = 3^{3}\]\[x^{2} + 6x - 27 = 0\]\[(x-3)(x+9) = 0\]\[x = 3 \text{ or } x = -9\]Since \(x > 0\) and \(x + 6 > 0\) are both required, reject \(x = -9\):
\[\boxed{x = 3}\]

Extraneous solutions of logarithmic equations

Because the domain of \(\log_{b}x\) is \(x > 0\), every solution of a logarithmic equation must be checked in the original equation. A value that satisfies the simplified exponential equation but makes an argument of a logarithm non-positive is an extraneous solution and must be rejected.
Worked exampleSolve \(\log_{5}(x-1) + \log_{5}(x+1) = \log_{5}(2x+3)\) for \(x\).
\[\log_{5}[(x-1)(x+1)] = \log_{5}(2x+3)\]\[x^{2} - 1 = 2x + 3\]\[x^{2} - 2x - 4 = 0\]\[x = \frac{2 \pm \sqrt{20}}{2}\]\[x = 1 \pm \sqrt{5}\]Since \(x - 1 > 0\) requires \(x > 1\), and \(1 - \sqrt{5} < 0\), reject \(x = 1 - \sqrt{5}\):
\[\boxed{x = 1 + \sqrt{5}}\]

Exponential and logarithmic inequalities

The methods for solving exponential and logarithmic equations extend to inequalities, but the domain of any logarithm in the inequality must still be respected, and any solution set must be checked against this domain.
Worked example(a) Solve \(2\log_{3}x - 1 < 0\).
\[2\log_{3}x < 1\]\[\log_{3}x < \frac{1}{2}\]\[x < 3^{\frac{1}{2}}\]Since the domain requires \(x>0\):
\[\boxed{0 < x < \sqrt{3}}\]
(b) Solve \((e^{x}-2)(e^{x}+6) < 3e^{x}\).
\[e^{2x} + 4e^{x} - 12 < 3e^{x}\]\[e^{2x} + e^{x} - 12 < 0\]Let \(u = e^{x}\):
\[(u+4)(u-3) < 0\]\[-4 < u < 3\]Since \(u = e^{x} > 0\) for all \(x\), combine with \(u<3\):
\[e^{x} < 3\]\[\boxed{x < \ln 3}\]
