The mean

The mean (or arithmetic mean) of a set of \(n\) raw data values \(x_1, x_2, \ldots, x_n\) is:
\[\bar{x} = \frac{\sum x}{n} = \frac{x_1+x_2+\cdots+x_n}{n}\]When the same data is organised into a discrete frequency table, with each value \(x_i\) occurring with frequency \(f_i\), the mean is instead calculated as:
\[\bar{x} = \frac{\sum fx}{\sum f}\]where \(\sum f\) is the total frequency (the sample size \(n\)).
Worked exampleThe number of siblings of \(20\) students is recorded below.
Number of siblings \(x\): \(0, 1, 2, 3, 4\)
Frequency \(f\): \(3, 7, 6, 3, 1\)
Find the mean number of siblings.
\[\sum fx = (0\times3)+(1\times7)+(2\times6)+(3\times3)+(4\times1)\]\[\sum fx = 0+7+12+9+4=32\]\[\bar{x}=\frac{\sum fx}{\sum f} = \frac{32}{20}\]\[\boxed{\bar{x}=1.6 \text{ siblings}}\]

The median and the mode

The median of \(n\) ordered data values is the value in position \(\frac{n+1}{2}\) once the data is sorted in ascending order; if \(\frac{n+1}{2}\) is not a whole number, the median is the average of the two values on either side of it. The mode is the data value that occurs most frequently; a data set can have one mode, more than one mode, or no mode at all if every value occurs equally often.
Worked exampleThe number of pets owned by \(7\) households, sorted in ascending order, is: \(0, 1, 1, 2, 2, 2, 5\). Find the median and the mode, and compare the median with the mean.
Since \(n=7\), the median is in position \(\frac{7+1}{2}=4\), so the median is the \(4\)th value.
\[\boxed{\text{median}=2}\]The most frequently occurring value is \(2\), which appears \(3\) times.
\[\boxed{\text{mode}=2}\]The mean is \(\bar{x}=\frac{0+1+1+2+2+2+5}{7}=\frac{13}{7}\approx1.86\), which is pulled upward, away from the median, by the single large value \(5\).

The range

The range of a data set is the difference between its largest and smallest values:
\[\text{range} = \max(x) - \min(x)\]The range is easy to calculate, but it is a crude measure of spread, since it depends only on the two extreme values and ignores how the rest of the data is distributed.
Worked exampleThe maximum daily temperatures, in \(^\circ\text{C}\), recorded over \(10\) days are: \(18, 21, 19, 25, 20, 17, 23, 22, 19, 16\). Find the range.
The maximum value is \(25\) and the minimum value is \(16\).
\[\text{range} = 25-16\]\[\boxed{\text{range}=9^\circ\text{C}}\]

Variance and standard deviation

The variance of a set of \(n\) data values with mean \(\bar{x}\) is the mean of the squared deviations from the mean:
\[\sigma^2 = \frac{\sum(x-\bar{x})^2}{n}\]The standard deviation is the (positive) square root of the variance:
\[\sigma = \sqrt{\frac{\sum(x-\bar{x})^2}{n}}\]Both measure how spread out the data is around the mean: a small standard deviation means the data is tightly clustered around the mean, while a large standard deviation means the data is widely spread.
Worked exampleFind the variance and standard deviation of the data set \(4, 6, 7, 8, 10\).
\[\bar{x}=\frac{4+6+7+8+10}{5}=\frac{35}{5}=7\]Deviations from the mean: \(-3, -1, 0, 1, 3\). Squared deviations: \(9, 1, 0, 1, 9\).
\[\sigma^2=\frac{9+1+0+1+9}{5}=\frac{20}{5}\]\[\boxed{\sigma^2=4}\]\[\sigma=\sqrt{4}\]\[\boxed{\sigma=2}\]

Estimating the mean and standard deviation for grouped data

For grouped (continuous) data organised into classes with midpoints \(m_i\) and frequencies \(f_i\), the mean and variance are estimated by treating every value in a class as if it were equal to the midpoint of that class:
\[\bar{x} \approx \frac{\sum fm}{\sum f}, \qquad \sigma^2 \approx \frac{\sum fm^2}{\sum f} - \bar{x}^2\]These are only estimates, since the individual raw values within each class are unknown; the true mean and standard deviation of the original data may differ slightly.
Worked exampleUsing the bus-stop waiting time data (midpoints \(2.5, 7.5, 12.5, 17.5, 22.5\) with frequencies \(4, 9, 14, 8, 5\)), estimate the mean and standard deviation of the waiting times.
\[\sum fm = 4(2.5)+9(7.5)+14(12.5)+8(17.5)+5(22.5)\]\[\sum fm = 10+67.5+175+140+112.5=505\]\[\bar{x}\approx\frac{505}{40}\]\[\boxed{\bar{x}\approx12.6 \text{ minutes}}\]\[\sum fm^2 = 4(2.5)^2+9(7.5)^2+14(12.5)^2+8(17.5)^2+5(22.5)^2\]\[\sum fm^2 = 25+506.25+2187.5+2450+2531.25=7700\]\[\sigma^2\approx\frac{7700}{40}-(12.625)^2\]\[\sigma^2\approx192.5-159.390625\]\[\boxed{\sigma^2\approx33.1}\]\[\sigma\approx\sqrt{33.1}\]\[\boxed{\sigma\approx5.75 \text{ minutes}}\]

Comparing distributions using mean and standard deviation

Two data sets can have the same mean but very different standard deviations. The data set with the larger standard deviation is more spread out (more variable) around the common mean, even though both sets are centred at the same typical value. This makes the standard deviation essential alongside the mean when comparing distributions.
Worked exampleTwo classes of \(5\) students each sit the same quiz, out of \(10\) marks.
Class A: \(6, 7, 7, 8, 7\)
Class B: \(3, 7, 7, 11, 7\)
Show that both classes have the same mean, and compare their standard deviations.
\[\bar{x}_A=\frac{6+7+7+8+7}{5}=\frac{35}{5}=7, \qquad \bar{x}_B=\frac{3+7+7+11+7}{5}=\frac{35}{5}=7\]Deviations for Class A: \(-1, 0, 0, 1, 0\), squared: \(1, 0, 0, 1, 0\).
\[\sigma_A^2=\frac{1+0+0+1+0}{5}=\frac{2}{5}=0.4, \qquad \sigma_A=\sqrt{0.4}\approx0.63\]Deviations for Class B: \(-4, 0, 0, 4, 0\), squared: \(16, 0, 0, 16, 0\).
\[\sigma_B^2=\frac{16+0+0+16+0}{5}=\frac{32}{5}=6.4, \qquad \sigma_B=\sqrt{6.4}\approx2.53\]\[\boxed{\text{Both classes have mean } 7, \text{ but Class B is far more spread out } (\sigma_B\approx4\sigma_A)}\]
