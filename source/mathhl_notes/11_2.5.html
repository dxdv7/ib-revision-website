Equations involving a radical

To solve an equation containing a square root, isolate one radical term on one side of the equation, then square both sides to eliminate it (repeating the process if a second radical remains). Squaring both sides can introduce an extraneous solution, so every candidate must be checked in the original, unsquared equation.
Worked exampleSolve for \(x\) in the equation \(\sqrt{3x+6} = 2x+1\).
Square both sides:
\[3x + 6 = (2x+1)^2\]\[3x + 6 = 4x^2 + 4x + 1\]\[4x^2 + x - 5 = 0\]\[(4x+5)(x-1) = 0\]\[x = -\frac{5}{4} \text{ or } x = 1\]Check \(x = -\dfrac{5}{4}\): left side \(\sqrt{3\left(-\frac{5}{4}\right)+6} = \sqrt{\frac{9}{4}} = \frac{3}{2}\), right side \(2\left(-\frac{5}{4}\right)+1 = -\frac{3}{2}\); these do not match, so \(x = -\dfrac{5}{4}\) is extraneous.
Check \(x = 1\): \(\sqrt{3(1)+6} = \sqrt{9} = 3\), and \(2(1)+1 = 3\); this matches.
\[\boxed{x = 1}\]

Equations involving fractions

To solve an equation containing algebraic fractions, multiply every term by the least common denominator (LCD) to clear the fractions, then solve the resulting polynomial equation. Any value that makes an original denominator zero cannot be a solution and must be rejected even if it satisfies the cleared equation.
Worked exampleFind all real solutions of \(\dfrac{3}{x-2} - \dfrac{1}{x+2} = \dfrac{8}{x^2-4}\).
The LCD is \((x-2)(x+2) = x^2-4\). Multiply every term by the LCD:
\[3(x+2) - 1(x-2) = 8\]\[3x + 6 - x + 2 = 8\]\[2x + 8 = 8\]\[2x = 0\]\[x = 0\]Since \(x = 0\) does not make any original denominator zero, it is valid.
\[\boxed{x = 0}\]

Equations in quadratic form

An equation of the form \(at^2 + bt + c = 0\), where \(t\) is an algebraic expression in \(x\), is said to be in quadratic form. Substitute a single variable for the repeated expression, solve the resulting quadratic, then substitute back and solve for \(x\). Every candidate value of \(t\) must be checked for whether it yields real values of \(x\).
Worked exampleFind all real solutions of \(2x^4 - 5x^2 + 2 = 0\).
Let \(t = x^2\), so the equation becomes:
\[2t^2 - 5t + 2 = 0\]\[(2t-1)(t-2) = 0\]\[t = \frac{1}{2} \text{ or } t = 2\]Substitute \(x^2\) back in for \(t\):
\[x^2 = \frac{1}{2} \implies x = \pm\frac{\sqrt{2}}{2}\]\[x^2 = 2 \implies x = \pm\sqrt{2}\]\[\boxed{x = \frac{\sqrt{2}}{2},\ -\frac{\sqrt{2}}{2},\ \sqrt{2},\ -\sqrt{2}}\]

Equations involving absolute value

The expression inside an absolute value symbol must equal either the positive or the negative of the quantity on the other side. To solve \(|A| = c\) with \(c \geq 0\), solve the two equations \(A = c\) and \(A = -c\); to solve \(|A| = |B|\), solve \(A = B\) and \(A = -B\).
Worked exampleSolve the equation \(|2x+7| = 13\).
The quantity \(2x+7\) equals \(13\) or \(-13\):
\[2x + 7 = 13 \qquad \text{or} \qquad 2x + 7 = -13\]\[2x = 6 \qquad \qquad\qquad 2x = -20\]\[x = 3 \qquad \qquad\qquad x = -10\]\[\boxed{x = 3 \text{ or } x = -10}\]

Absolute value inequalities

For a real number \(c > 0\):
\[|A| < c \iff -c < A < c\]\[|A| > c \iff A < -c \text{ or } A > c\]The same equivalences apply with \(\leq\) and \(\geq\).
Worked exampleSolve for \(x\) in the inequality \(|3x - 7| \geq 8\).
Apply the second property:
\[3x - 7 \leq -8 \qquad \text{or} \qquad 3x - 7 \geq 8\]\[3x \leq -1 \qquad\qquad\qquad 3x \geq 15\]\[x \leq -\frac{1}{3} \qquad\qquad\qquad x \geq 5\]\[\boxed{x \leq -\frac{1}{3} \text{ or } x \geq 5}\]

Solving rational inequalities

To solve an inequality containing a rational expression, rearrange so that zero is on one side and combine the terms into a single fraction. Find the critical values (the zeros of the numerator and denominator), then use a sign chart to test the sign of the combined fraction in each interval determined by those critical values. Any value that makes the denominator zero must be excluded from the solution set even if the sign chart suggests it.
Worked exampleSolve the inequality \(\dfrac{1}{x-1} < \dfrac{2}{x+2}\).
Rearrange with zero on one side and combine:
\[\frac{1}{x-1} - \frac{2}{x+2} < 0\]\[\frac{(x+2) - 2(x-1)}{(x-1)(x+2)} < 0\]\[\frac{-x+4}{(x-1)(x+2)} < 0\]The critical values are \(x = 4\), \(x = 1\) and \(x = -2\). Testing a value in each interval shows the expression is positive for \(x < -2\), negative for \(-2 < x < 1\), positive for \(1 < x < 4\), and negative for \(x > 4\).
\[\boxed{-2 < x < 1 \text{ or } x > 4}\]
