Definition of a function and the vertical line test

A function \(f\) is a rule that assigns to each value \(x\) in its domain exactly one value \(y = f(x)\) in its range. Graphically, a curve represents a function if and only if no vertical line intersects it more than once (the vertical line test), since each \(x\)-value must correspond to a single \(y\)-value.
Worked exampleDetermine whether the equation \(x^2 + y^2 = 1\) defines \(y\) as a function of \(x\).
\[y^2 = 1 - x^2\]\[y = \pm\sqrt{1-x^2}\]For every \(x\) with \(-1 < x < 1\), this gives two different values of \(y\) (opposites), so one input corresponds to two outputs.
\[\boxed{\text{Not a function (fails the vertical line test)}}\]

Function notation and evaluating a function

The notation \(y = f(x)\) (read "y equals f of x") names the function \(f\) and denotes the unique output value \(y\) produced by the input \(x\). Mapping notation \(f: x \mapsto f(x)\) expresses the same rule. To evaluate \(f\) at a value or expression, substitute it for every \(x\) in the formula for \(f(x)\).
Worked exampleGiven \(f(x) = x^2 - 2x\), find \(f(3)\), \(f(-1)\) and \(f(a+1)\).
\[f(3) = (3)^2 - 2(3) = 9 - 6\]\[\boxed{f(3) = 3}\]\[f(-1) = (-1)^2 - 2(-1) = 1 + 2\]\[\boxed{f(-1) = 3}\]\[f(a+1) = (a+1)^2 - 2(a+1) = a^2+2a+1-2a-2\]\[\boxed{f(a+1) = a^2 - 1}\]

Domain of a function: algebraic restrictions

Unless stated otherwise, the domain of a function is the set of all real \(x\) for which the formula produces a real number. Two common restrictions apply: the expression under an even root must be greater than or equal to zero, and any denominator must not equal zero.
Worked exampleFind the domain of \(f(x) = \dfrac{\sqrt{5-2x}}{x+3}\).
\[5 - 2x \ge 0 \Rightarrow x \le \frac{5}{2}\]\[x + 3 \ne 0 \Rightarrow x \ne -3\]\[\boxed{\text{Domain: } x \le \frac{5}{2} \text{ and } x \ne -3}\]

Range of a function using completing the square

For a quadratic function, completing the square to write it in vertex form \(f(x) = a(x-h)^2+k\) reveals the minimum value \(k\) (if \(a>0\)) or the maximum value \(k\) (if \(a<0\)), which determines the range.
Worked exampleFind the range of \(f(x) = x^2 - 4x + 1\).
\[f(x) = (x^2-4x+4) + 1 - 4\]\[f(x) = (x-2)^2 - 3\]Since \(a = 1 > 0\), the minimum value is \(-3\), occurring at \(x = 2\).
\[\boxed{\text{Range: } y \ge -3}\]

Domain and range of rational functions: vertical and horizontal asymptotes

For a function of the form \(f(x) = \dfrac{a}{x-p}+q\), the domain excludes \(x = p\), a vertical asymptote, since division by zero is undefined there. The range excludes \(y = q\), a horizontal asymptote, since \(\dfrac{a}{x-p}\) can never equal zero.
Worked exampleFind the domain and range of \(f(x) = \dfrac{3}{x-2}+1\).
\[x - 2 \ne 0 \Rightarrow x \ne 2\]\[\boxed{\text{Domain: } x \in \mathbb{R}, x \ne 2}\]Since \(\dfrac{3}{x-2}\) is never zero, \(f(x)\) never equals \(1\).
\[\boxed{\text{Range: } y \in \mathbb{R}, y \ne 1}\]

Domain and range of square root functions

For a function of the form \(f(x) = \sqrt{g(x)} + k\), the domain is the set of \(x\)-values for which \(g(x) \ge 0\), and since the principal square root is never negative, the range is \(y \ge k\).
Worked exampleFind the domain and range of \(f(x) = \sqrt{x+4} - 2\).
\[x + 4 \ge 0 \Rightarrow x \ge -4\]\[\boxed{\text{Domain: } x \ge -4}\]Since \(\sqrt{x+4} \ge 0\) for all \(x\) in the domain, \(f(x) \ge 0 - 2\).
\[\boxed{\text{Range: } y \ge -2}\]
