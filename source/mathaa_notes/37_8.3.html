Conditional probability

For two events \(A\) and \(B\) with \(P(B) \ne 0\), the conditional probability of \(A\) given \(B\) is the probability that \(A\) occurs once it is known that \(B\) has occurred:
\[P(A|B) = \frac{P(A \cap B)}{P(B)}\]Knowing that \(B\) has occurred restricts attention to the outcomes in \(B\), which becomes the new (reduced) sample space.
Worked exampleA fair six-sided die is rolled once. Let \(A\) = "the number is even" \(= \{2, 4, 6\}\) and \(B\) = "the number is greater than \(2\)" \(= \{3, 4, 5, 6\}\). Find \(P(A|B)\).
\[P(B) = \frac{4}{6} = \frac{2}{3}\]\[A \cap B = \{4, 6\}, \quad P(A \cap B) = \frac{2}{6} = \frac{1}{3}\]\[P(A|B) = \frac{1/3}{2/3}\]\[\boxed{P(A|B) = \frac{1}{2}}\]

The general multiplication rule

Rearranging the conditional probability formula gives the general multiplication rule, which holds for any two events \(A\) and \(B\):
\[P(A \cap B) = P(A|B) \times P(B)\]This allows the probability of two events both occurring to be built up from a conditional probability and an unconditional probability, which is especially useful when events happen in sequence.
Worked exampleA bag contains \(5\) red and \(3\) blue balls. Two balls are drawn at random, one after another, without replacement. Find the probability that both balls are red.
\[P(R_1) = \frac{5}{8}\]\[P(R_2|R_1) = \frac{4}{7}\]\[P(R_1 \cap R_2) = \frac{5}{8} \times \frac{4}{7}\]\[P(R_1 \cap R_2) = \frac{20}{56}\]\[\boxed{P(R_1 \cap R_2) = \frac{5}{14}}\]

Testing for independence using the multiplication rule

Two events \(A\) and \(B\) are independent if knowing that one has occurred does not change the probability of the other. This can be tested using the multiplication rule: \(A\) and \(B\) are independent if and only if
\[P(A \cap B) = P(A) \times P(B)\]If this equation does not hold, the events are dependent.
Worked exampleFor events \(A\) and \(B\), \(P(A) = 0.3\), \(P(B) = 0.6\) and \(P(A \cap B) = 0.18\). Determine whether \(A\) and \(B\) are independent.
\[P(A) \times P(B) = 0.3 \times 0.6\]\[P(A) \times P(B) = 0.18\]Since \(P(A \cap B) = 0.18 = P(A) \times P(B)\):
\[\boxed{A \text{ and } B \text{ are independent}}\]

Testing for independence using conditional probability

An equivalent way to test independence is to compare \(P(A|B)\) with \(P(A)\):
\[A \text{ and } B \text{ are independent} \iff P(A|B) = P(A)\]If \(P(A|B) \ne P(A)\), then learning that \(B\) occurred does change the probability of \(A\), so the events are dependent.
Worked exampleA fair six-sided die is rolled once. Let \(A\) = "the number is even" and \(B\) = "the number is \(1\), \(2\) or \(3\)". Are \(A\) and \(B\) independent?
\[P(A) = \frac{3}{6} = \frac{1}{2}\]\[P(B) = \frac{3}{6} = \frac{1}{2}\]\[A \cap B = \{2\}, \quad P(A \cap B) = \frac{1}{6}\]\[P(A|B) = \frac{1/6}{1/2} = \frac{1}{3}\]Since \(P(A|B) = \dfrac{1}{3} \ne P(A) = \dfrac{1}{2}\):
\[\boxed{A \text{ and } B \text{ are not independent}}\]

The multiplication rule for independent events

If \(A\) and \(B\) are independent, the general multiplication rule simplifies, since \(P(A|B) = P(A)\):
\[P(A \cap B) = P(A) \times P(B)\]This extends to any number of independent events \(A_1, A_2, \dots, A_n\):
\[P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \times P(A_2) \times \cdots \times P(A_n)\]
Worked exampleA system has three components that fail independently of one another, each with probability \(0.1\) of failing. Find the probability that all three components fail.
\[P(\text{all fail}) = 0.1 \times 0.1 \times 0.1\]\[\boxed{P(\text{all fail}) = 0.001}\]

Independent events versus mutually exclusive events

Independence and mutual exclusivity are different ideas. Events are mutually exclusive if they cannot occur together, \(P(A \cap B) = 0\); events are independent if occurrence of one does not affect the probability of the other. Two mutually exclusive events with nonzero probabilities can never be independent, since knowing one occurred tells you the other definitely did not.
Worked exampleA fair coin is tossed twice. Let \(A\) = "heads on the first toss" and \(B\) = "heads on the second toss". Explain why \(A\) and \(B\) are independent but not mutually exclusive.
Both tosses can land heads at the same time, so \(A \cap B \ne \emptyset\): the events are not mutually exclusive.
\[P(A) = \frac{1}{2}, \quad P(B) = \frac{1}{2}, \quad P(A \cap B) = \frac{1}{4}\]\[P(A) \times P(B) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4} = P(A \cap B)\]\[\boxed{A \text{ and } B \text{ are independent}}\]
