Solving polynomial equations using the factor theorem

If substituting \(x = k\) into a polynomial \(p(x)\) gives \(p(k) = 0\), then \(x = k\) is a root of the equation \(p(x) = 0\) and \((x-k)\) is a factor of \(p(x)\). For a cubic or higher-degree polynomial equation, a root can often be found by testing small integer factors of the constant term; dividing by the resulting factor reduces the equation to a lower degree, which can then be solved by further factorising.
Worked exampleSolve \(x^3 - 6x^2 + 11x - 6 = 0\).
Testing \(x = 1\):
\[1^3 - 6(1)^2 + 11(1) - 6 = 1 - 6 + 11 - 6 = 0\]So \((x-1)\) is a factor. Dividing gives:
\[x^3 - 6x^2 + 11x - 6 = (x-1)(x^2 - 5x + 6)\]Factorising the remaining quadratic factor:
\[x^2 - 5x + 6 = (x-2)(x-3)\]\[\boxed{x = 1, \ x = 2, \text{ or } x = 3}\]

Solving equations with quadratic structure by substitution

An equation that is not itself quadratic can sometimes be rewritten as \(at^2 + bt + c = 0\) by substituting \(t\) for a repeated algebraic expression, such as letting \(t = x^2\) in a quartic equation of the form \(ax^4 + bx^2 + c = 0\). Once the equation is solved for \(t\), substitute back to find \(x\), checking whether each value of \(t\) produces real values of \(x\) (a negative value of \(t = x^2\) gives no real solutions for \(x\)).
Worked exampleFind all real solutions of \(x^4 - 5x^2 + 4 = 0\).
Let \(t = x^2\):
\[t^2 - 5t + 4 = 0\]\[(t-1)(t-4) = 0\]\[t = 1 \text{ or } t = 4\]Substituting back \(x^2 = t\):
\[x^2 = 1 \implies x = \pm 1\]\[x^2 = 4 \implies x = \pm 2\]\[\boxed{x = -2, \ -1, \ 1, \text{ or } 2}\]

Solving equations graphically: the intersection method

To solve an equation \(f(x) = g(x)\) graphically rather than algebraically (analytically), graph \(y = f(x)\) and \(y = g(x)\) on the same axes using technology and read off the \(x\)-coordinate(s) of their point(s) of intersection; this is equivalent to graphing \(y = f(x) - g(x)\) and finding its \(x\)-intercept(s). A graphical method locates the same solutions as an exact analytic method, and is especially useful when an equation is difficult to solve algebraically, though an analytic method, when it is available, gives an exact rather than an approximate answer.
Worked exampleSolve \(x^3 = 2x + 4\) by finding the point of intersection of \(y = x^3\) and \(y = 2x + 4\).
Rearranging so that one side is zero:
\[x^3 - 2x - 4 = 0\]Testing \(x = 2\):
\[2^3 - 2(2) - 4 = 8 - 4 - 4 = 0\]So \((x-2)\) is a factor:
\[x^3 - 2x - 4 = (x-2)(x^2 + 2x + 2)\]The remaining factor can be written as a completed square:
\[x^2 + 2x + 2 = (x+1)^2 + 1\]Since \((x+1)^2 + 1 \ge 1 > 0\) for every real \(x\), this factor is never zero.
\[\boxed{x = 2 \text{ is the only real solution}}\]

Solving equations graphically: approximate solutions

When an equation cannot be solved exactly by algebraic methods, technology can be used to graph the equation (rearranged so that one side is zero) and find the \(x\)-intercept(s) of the graph correct to a given number of significant figures. This graphical approach gives an approximate numerical solution rather than an exact analytic one, and is checked by confirming the sign of the function changes on either side of the approximate root.
Worked exampleUse technology to find, correct to three significant figures, the real solution of \(x^3 - x - 3 = 0\).
Graphing \(y = x^3 - x - 3\) shows a single \(x\)-intercept between \(x = 1\) and \(x = 2\). Testing values close to this intercept:
\[f(1.67) = 1.67^3 - 1.67 - 3 \approx -0.0125\]\[f(1.68) = 1.68^3 - 1.68 - 3 \approx 0.0616\]Since \(f(x)\) changes sign between \(x = 1.67\) and \(x = 1.68\), the root lies between them.
\[\boxed{x \approx 1.67}\]
