Classifying data

Data is either quantitative (numerical) or qualitative (categorical). Quantitative data is discrete if it can only take particular, separate values (usually counts), and continuous if it can take any value within a range, limited only by the accuracy of measurement. Qualitative data describes a quality or category, such as a colour or a type, rather than a number.
Worked exampleClassify each variable as discrete quantitative, continuous quantitative, or qualitative.
(a) The number of pets owned by a family.
(b) The time taken for a student to run \(100\text{ m}\).
(c) The eye colour of each student in a class.
(a) Discrete quantitative, since the number of pets can only be a whole number.
(b) Continuous quantitative, since time can take any value within a range.
(c) Qualitative, since eye colour is a category, not a number.

Frequency distributions

A frequency distribution is a table that organises raw data into classes (or groups) in one column, with the frequency, the number of observations falling into each class, in the other column. Class intervals should be of equal width, must cover the full range of the data, and must not overlap, so that every observation belongs to exactly one class.
Worked exampleThe following \(10\) test scores were recorded: \(14, 18, 15, 20, 17, 19, 16, 14, 18, 15\). Construct a frequency table using the distinct scores as classes.
Score \(14\): frequency \(2\).
Score \(15\): frequency \(2\).
Score \(16\): frequency \(1\).
Score \(17\): frequency \(1\).
Score \(18\): frequency \(2\).
Score \(19\): frequency \(1\).
Score \(20\): frequency \(1\).
The frequencies add up to \(2+2+1+1+2+1+1 = 10\), which matches the total number of scores.

Pie charts

A pie chart displays categorical data as a circle divided into sectors, where the angle of each sector is proportional to the frequency of that category. If a category has frequency \(f\) out of a total of \(\sum f\) observations, its sector angle is:
\[\text{angle} = \frac{f}{\sum f} \times 360^{\circ}\]The angles of all sectors must add up to \(360^{\circ}\).
Worked exampleA survey of \(180\) students' favourite subject gave: Mathematics \(45\), Science \(60\), Art \(30\), History \(45\). Find the angle of each sector in a pie chart of this data.
\[\text{Mathematics: } \frac{45}{180} \times 360^{\circ}\]\[\boxed{90^{\circ}}\]\[\text{Science: } \frac{60}{180} \times 360^{\circ}\]\[\boxed{120^{\circ}}\]\[\text{Art: } \frac{30}{180} \times 360^{\circ}\]\[\boxed{60^{\circ}}\]\[\text{History: } \frac{45}{180} \times 360^{\circ}\]\[\boxed{90^{\circ}}\]As a check: \(90^{\circ}+120^{\circ}+60^{\circ}+90^{\circ} = 360^{\circ}\).

Bar charts

A bar chart represents categorical or discrete data using separate rectangular bars of equal width, one for each category, with the height (or length) of each bar proportional to its frequency. Unlike a histogram, the bars in a bar chart are separated by gaps, since the categories are distinct and not continuous.
Worked exampleA bar chart shows the number of cars sold at a dealership each day of one week: Mon \(8\), Tue \(5\), Wed \(6\), Thu \(7\), Fri \(10\), Sat \(14\), Sun \(0\) (closed). Find the total weekly sales and the percentage of weekly sales that occurred on Saturday.
\[\text{Total} = 8+5+6+7+10+14+0\]\[\boxed{\text{Total} = 50 \text{ cars}}\]\[\text{Percentage on Saturday} = \frac{14}{50} \times 100\%\]\[\boxed{28\%}\]

Stem-and-leaf diagrams

A stem-and-leaf diagram displays numerical data by splitting each value into a stem (the leading digit or digits) and a leaf (the final digit). The stems are listed in order in one column, and the leaves for each stem are listed in increasing order beside it. A key must be given to show how to read the values, and the diagram keeps every original data value visible, unlike a frequency table with grouped classes.
Worked exampleTwelve students' test marks were: \(62, 67, 71, 74, 74, 78, 81, 83, 83, 89, 92, 95\). Construct a stem-and-leaf diagram, and use it to find how many students scored at least \(80\) marks.
Stem \(6\): leaves \(2, 7\) (that is, \(62, 67\)).
Stem \(7\): leaves \(1, 4, 4, 8\) (that is, \(71, 74, 74, 78\)).
Stem \(8\): leaves \(1, 3, 3, 9\) (that is, \(81, 83, 83, 89\)).
Stem \(9\): leaves \(2, 5\) (that is, \(92, 95\)).
The stems \(8\) and \(9\) together have \(4 + 2 = 6\) leaves.
\[\boxed{6 \text{ students scored at least } 80 \text{ marks}}\]

Outliers

An outlier is a data value that lies an abnormal distance from the rest of the data. There is no single, universal rule for exactly how far is "abnormal," but outliers can often be identified simply by inspecting a frequency table, bar chart, or stem-and-leaf diagram, and noticing a value that is isolated from the main cluster of data.
Worked exampleThe weekly takings (in dollars) at a small bakery over \(8\) weeks were: \(420, 445, 410, 430, 460, 415, 440, 890\). Identify any outlier, and suggest a possible reason for it.
Seven of the values lie between \(410\) and \(460\), but the eighth value, \(890\), is far higher than the rest.
\[\boxed{890 \text{ is an outlier}}\]A possible reason is an unusually busy week, such as a holiday or local event, or a data-recording error.
