Average velocity

If an object moves along a straight line with displacement function \(s(t)\), its average velocity over the time interval from \(t_1\) to \(t_2\) is the change in displacement divided by the change in time:
\[v_{avg} = \frac{s(t_2) - s(t_1)}{t_2 - t_1}\]This is the gradient of the chord joining the two points on the displacement-time graph, as opposed to the instantaneous velocity, which is the gradient of the tangent.
Worked exampleAn object moves along a straight line so that its displacement, in metres, at time \(t\) seconds is \(s(t) = t^2 + 3t\). Find the average velocity of the object over the interval \(1 \le t \le 4\).
\[s(1) = (1)^2 + 3(1) = 4\]\[s(4) = (4)^2 + 3(4) = 28\]\[v_{avg} = \frac{s(4) - s(1)}{4 - 1} = \frac{28 - 4}{3}\]\[\boxed{v_{avg} = 8 \text{ ms}^{-1}}\]

Velocity and acceleration from displacement

If an object moves in a straight line so that its displacement at time \(t\) is \(s(t)\), its instantaneous velocity is the first derivative of displacement with respect to time, and its acceleration is the first derivative of velocity, which is the second derivative of displacement:
\[v(t) = \frac{ds}{dt} = s'(t)\]\[a(t) = \frac{dv}{dt} = \frac{d^2s}{dt^2} = s''(t)\]
Worked exampleAn object moves along a straight line so that its displacement, in metres, after \(t\) seconds is \(s(t) = t^3 - 6t^2 + 9t\). Find expressions for the velocity and acceleration at time \(t\), and find the initial velocity and initial acceleration.
\[v(t) = \frac{ds}{dt} = 3t^2 - 12t + 9\]\[a(t) = \frac{dv}{dt} = 6t - 12\]\[v(0) = 3(0)^2 - 12(0) + 9\]\[\boxed{v(0) = 9 \text{ ms}^{-1}}\]\[a(0) = 6(0) - 12\]\[\boxed{a(0) = -12 \text{ ms}^{-2}}\]

At rest and direction of motion

An object is at rest at an instant when its velocity is zero. If \(v(t) > 0\) the object is moving in the positive direction, and if \(v(t) < 0\) the object is moving in the negative direction:
\[v(t) = 0 \implies \text{object at rest}\]\[v(t) > 0 \implies \text{moving in the positive direction}\]\[v(t) < 0 \implies \text{moving in the negative direction}\]
Worked exampleUsing \(v(t) = 3t^2 - 12t + 9\) from the previous example, find the times at which the object is at rest, and describe its direction of motion for \(t \ge 0\).
\[v(t) = 3t^2 - 12t + 9 = 3(t - 1)(t - 3)\]\[v(t) = 0 \implies t = 1 \text{ or } t = 3\]\[v(0) = 9 > 0, \quad v(2) = -3 < 0, \quad v(4) = 9 > 0\]\[\boxed{\text{forward for } 0 < t < 1 \text{, backward for } 1 < t < 3 \text{, forward for } t > 3}\]

Speeding up and slowing down

An object is speeding up when its velocity and acceleration have the same sign, since the acceleration is acting in the direction of travel. It is slowing down when its velocity and acceleration have opposite signs, since the acceleration is then acting against the direction of travel:
\[v(t) \text{ and } a(t) \text{ same sign} \implies \text{speeding up}\]\[v(t) \text{ and } a(t) \text{ opposite signs} \implies \text{slowing down}\]
Worked exampleUsing \(v(t) = 3t^2 - 12t + 9\) and \(a(t) = 6t - 12\) from before, determine whether the object is speeding up or slowing down at \(t = 0.5\) and at \(t = 4\).
\[v(0.5) = 3(0.5)^2 - 12(0.5) + 9 = 3.75\]\[a(0.5) = 6(0.5) - 12 = -9\]\[\boxed{\text{opposite signs: slowing down at } t = 0.5}\]\[v(4) = 3(4)^2 - 12(4) + 9 = 9\]\[a(4) = 6(4) - 12 = 12\]\[\boxed{\text{same sign: speeding up at } t = 4}\]

Speed and distance

Displacement can be positive, negative, or zero, and velocity can likewise be positive, negative, or zero depending on the direction of motion. Speed is the absolute value of velocity, and distance travelled over an interval is found from the absolute value of displacement:
\[\text{speed} = |v(t)|\]
Worked exampleUsing \(v(t) = 3t^2 - 12t + 9\), find the speed of the object at \(t = 2\) seconds.
\[v(2) = 3(2)^2 - 12(2) + 9 = -3\]\[\text{speed} = |v(2)| = |-3|\]\[\boxed{\text{speed} = 3 \text{ ms}^{-1}}\]
