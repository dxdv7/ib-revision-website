General strategy for solving optimisation problems

Many problems ask for the maximum or minimum value of a quantity subject to a constraint. A general strategy:
Step 1: Draw a diagram and assign variables to the unknown quantities.
Step 2: Use the constraint to express the quantity to be optimised as a function of a single variable, and state the domain of that function.
Step 3: Differentiate the function and find the value(s) of the variable where the derivative is zero (the critical values), together with any domain endpoints.
Step 4: Use the first or second derivative test, together with the domain restrictions, to determine whether each critical value gives a maximum, a minimum, or neither, and answer the question that was asked.
Worked exampleA rectangular field is to be enclosed by 40 m of fencing on all four sides. Find the dimensions that maximise the enclosed area.
\[x = \text{width}, \quad y = \text{length}\]\[2x + 2y = 40 \implies y = 20 - x\]\[A(x) = xy = x(20 - x) = 20x - x^2, \quad 0 < x < 20\]\[\frac{dA}{dx} = 20 - 2x\]\[\frac{dA}{dx} = 0 \implies x = 10, \quad y = 10\]\[\frac{d^2A}{dx^2} = -2 < 0 \implies \text{maximum}\]\[\boxed{\text{Maximum area} = 100 \text{ m}^2 \text{ when } x = y = 10 \text{ m}}\]

Setting up an objective function using a constraint

When a problem involves two unknowns related by a fixed constraint, solve the constraint for one variable and substitute it into the expression for the quantity being optimised. This converts the objective into a function of a single variable, ready to be differentiated.
Worked exampleAn open rectangular box with a square base is to have a volume of \(256 \text{ cm}^3\). Find the dimensions that minimise the surface area of the box.
\[x = \text{side of square base}, \quad h = \text{height}\]\[x^2h = 256 \implies h = \frac{256}{x^2}\]\[S(x) = x^2 + 4xh = x^2 + 4x\left(\frac{256}{x^2}\right) = x^2 + \frac{1024}{x}, \quad x > 0\]\[\frac{dS}{dx} = 2x - \frac{1024}{x^2}\]\[\frac{dS}{dx} = 0 \implies 2x^3 = 1024 \implies x^3 = 512 \implies x = 8\]\[h = \frac{256}{64} = 4\]\[\frac{d^2S}{dx^2} = 2 + \frac{2048}{x^3} > 0 \text{ for } x > 0 \implies \text{minimum}\]\[S(8) = 64 + 128 = 192\]\[\boxed{\text{Minimum surface area} = 192 \text{ cm}^2 \text{ when } x = 8 \text{ cm}, h = 4 \text{ cm}}\]

The first derivative test

Suppose \(f'(c) = 0\). If \(f'(x)\) changes sign from positive to negative as \(x\) increases through \(x = c\), then \(f\) has a local maximum at \(x = c\). If \(f'(x)\) changes sign from negative to positive as \(x\) increases through \(x = c\), then \(f\) has a local minimum at \(x = c\). If \(f'(x)\) does not change sign at \(x = c\), then \(x = c\) is neither a local maximum nor a local minimum.
Worked exampleThe cost of producing \(x\) units of a product is modelled by \(C(x) = x^2 - 12x + 40\), for \(x > 0\). Find the production level that minimises the cost.
\[C'(x) = 2x - 12\]\[C'(x) = 0 \implies x = 6\]\[C'(5) = -2 < 0, \quad C'(7) = 2 > 0\]Since \(C'(x)\) changes from negative to positive at \(x = 6\), this is a local minimum.\[C(6) = 36 - 72 + 40 = 4\]\[\boxed{\text{Minimum cost} = 4 \text{ when } x = 6}\]

The second derivative test

Suppose \(f'(c) = 0\). If \(f''(c) > 0\), then \(f\) has a local minimum at \(x = c\). If \(f''(c) < 0\), then \(f\) has a local maximum at \(x = c\). If \(f''(c) = 0\), the test is inconclusive and the first derivative test should be used instead.
Worked exampleFind the minimum value of \(f(x) = x + \dfrac{1}{x}\), for \(x > 0\).
\[f'(x) = 1 - \frac{1}{x^2}\]\[f'(x) = 0 \implies x^2 = 1 \implies x = 1 \quad (\text{since } x > 0)\]\[f''(x) = \frac{2}{x^3}\]\[f''(1) = 2 > 0 \implies \text{minimum}\]\[f(1) = 1 + 1 = 2\]\[\boxed{\text{Minimum value} = 2 \text{ when } x = 1}\]

Checking domain restrictions and endpoint behaviour

The domain of the objective function, determined by the physical constraints of the problem, must always be checked. The behaviour of the function at the endpoints of the domain should be examined, since an extreme value may occur at an endpoint rather than where the derivative is zero, and checking the endpoints confirms whether an interior critical value gives an absolute maximum or minimum.
Worked exampleA rectangular pen is to be built against an existing straight wall, using 60 m of fencing for the other three sides. Find the dimensions that maximise the enclosed area.
\[x = \text{width (perpendicular to the wall)}, \quad y = \text{length (parallel to the wall)}\]\[2x + y = 60 \implies y = 60 - 2x\]\[A(x) = xy = x(60 - 2x) = 60x - 2x^2, \quad 0 < x < 30\]\[\frac{dA}{dx} = 60 - 4x\]\[\frac{dA}{dx} = 0 \implies x = 15, \quad y = 30\]\[\frac{d^2A}{dx^2} = -4 < 0 \implies \text{maximum}\]As \(x \to 0^+\) or \(x \to 30^-\), \(A(x) \to 0\), confirming \(x = 15\) gives the absolute maximum.\[A(15) = 15 \times 30 = 450\]\[\boxed{\text{Maximum area} = 450 \text{ m}^2 \text{ when } x = 15 \text{ m}, y = 30 \text{ m}}\]
