The normal distribution

A continuous random variable \(X\) is normally distributed with mean \(\mu\) and standard deviation \(\sigma\) if its probability density function produces a symmetric, bell-shaped curve centred at \(\mu\). This is written
\[X \sim N(\mu, \sigma^2)\]The curve is symmetric about \(x=\mu\), the total area under the curve equals \(1\), and the area to the left of \(\mu\) and the area to the right of \(\mu\) are both \(0.5\). The spread of the curve is controlled by \(\sigma\): a larger \(\sigma\) produces a flatter, more spread-out curve, while a smaller \(\sigma\) produces a taller, narrower curve.
Worked exampleThe heights, in cm, of adult males in a population are modelled by \(X \sim N(175, 36)\). Write down the mean and the standard deviation of \(X\).
\[\mu = 175\]\[\sigma = \sqrt{36}\]\[\boxed{\sigma = 6}\]

The empirical rule

For a normal distribution \(X \sim N(\mu,\sigma^2)\), approximately
\[P(\mu - \sigma < X < \mu + \sigma) \approx 0.68\]\[P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 0.95\]\[P(\mu - 3\sigma < X < \mu + 3\sigma) \approx 0.997\]These are known as the 68 percent, 95 percent, and 99.7 percent rules.
Worked exampleA machine fills bottles with volumes, in ml, modelled by \(X \sim N(500, 4)\). Use the empirical rule to find the interval in which the middle 95 percent of bottle volumes lie.
\[\sigma = \sqrt{4} = 2\]\[\mu - 2\sigma = 500 - 2(2) = 496\]\[\mu + 2\sigma = 500 + 2(2) = 504\]\[\boxed{496 < X < 504}\]

Standardizing a normal variable

Any normal variable \(X \sim N(\mu,\sigma^2)\) can be converted into the standard normal variable \(Z\), which has mean \(0\) and standard deviation \(1\), that is \(Z \sim N(0,1)\), using
\[Z = \frac{X-\mu}{\sigma}\]The value of \(Z\), called the z-score, measures how many standard deviations a value of \(X\) lies above or below the mean.
Worked exampleThe time, \(X\) minutes, taken to complete a puzzle is modelled by \(X \sim N(70, 100)\). Find the z-score corresponding to \(x = 85\) minutes.
\[\sigma = \sqrt{100} = 10\]\[z = \frac{85 - 70}{10}\]\[\boxed{z = 1.5}\]

Normal probability calculations

Probabilities for a normal variable are found directly using a calculator or software, without needing to use printed tables. If \(X \sim N(\mu,\sigma^2)\), then
\[P(X < k), \qquad P(X > k) = 1 - P(X < k), \qquad P(a < X < b) = P(X < b) - P(X < a)\]can all be computed once \(\mu\), \(\sigma\), and the relevant boundary value or values are entered.
Worked exampleUsing the model \(X \sim N(70, 100)\) for the time taken to complete the puzzle, find \(P(X < 85)\), \(P(X > 85)\), and \(P(60 < X < 80)\), using a calculator or software.
\[P(X < 85) = P\left(Z < \frac{85-70}{10}\right) = P(Z < 1.5)\]\[\boxed{P(X < 85) = 0.9332}\]\[P(X > 85) = 1 - P(X < 85)\]\[\boxed{P(X > 85) = 0.0668}\]\[P(60 < X < 80) = P(X < 80) - P(X < 60)\]\[\boxed{P(60 < X < 80) = 0.6827}\]

Inverse normal calculations

Given a probability, the corresponding boundary value \(k\) can be found using the inverse normal function on a calculator or software. If \(P(X < k) = p\) is given directly, \(k\) is found from \(p\), \(\mu\), and \(\sigma\). If instead an upper-tail probability \(P(X > k) = p\) is given, it must first be rewritten as
\[P(X < k) = 1 - p\]before the inverse normal function is used.
Worked exampleFor the model \(X \sim N(70, 100)\), find the value of \(k\) such that (a) \(P(X < k) = 0.90\) and (b) \(P(X > k) = 0.20\), using a calculator or software.
(a)
\[\boxed{k = 82.8}\]
(b)
\[P(X < k) = 1 - 0.20 = 0.80\]\[\boxed{k = 78.4}\]
