Increasing and decreasing functions

The sign of the first derivative \(f'(x)\) tells us whether the graph of \(f\) is rising or falling as \(x\) increases:
\[\text{if } f'(x) > 0 \text{ for all } x \text{ in } (a, b), \text{ then } f \text{ is increasing on } (a, b)\]\[\text{if } f'(x) < 0 \text{ for all } x \text{ in } (a, b), \text{ then } f \text{ is decreasing on } (a, b)\]
Worked exampleFor \(f(x) = x^2 - 4x + 3\), determine whether \(f\) is increasing or decreasing at \(x = 1\) and at \(x = 5\).
\[f'(x) = 2x - 4\]\[f'(1) = 2(1) - 4 = -2 < 0\]\[\boxed{f \text{ is decreasing at } x = 1}\]\[f'(5) = 2(5) - 4 = 6 > 0\]\[\boxed{f \text{ is increasing at } x = 5}\]

Finding critical values

A critical value of \(f\) is a value \(x = c\) in the domain for which \(f'(c) = 0\). Since \(f'(x)\) can only change sign at a critical value, these values divide the domain into intervals on which \(f\) is entirely increasing or entirely decreasing.
Worked exampleFind the critical values of \(f(x) = x^3 - 12x + 1\).
\[f'(x) = 3x^2 - 12\]\[3x^2 - 12 = 0\]\[x^2 = 4\]\[\boxed{x = -2 \text{ or } x = 2}\]

Determining intervals of increase and decrease

To find the intervals on which a function is increasing or decreasing: find \(f'(x)\); solve \(f'(x) = 0\) to locate the critical values; use the critical values to divide the domain into intervals; then test the sign of \(f'(x)\) at one point inside each interval.
Worked exampleFind the intervals of increase and decrease of \(f(x) = x^3 - 3x + 2\).
\[f'(x) = 3x^2 - 3 = 3(x-1)(x+1)\]Critical values: \(x = -1\) and \(x = 1\).
\[f'(-2) = 3(4) - 3 = 9 > 0\]\[f'(0) = 3(0) - 3 = -3 < 0\]\[f'(2) = 3(4) - 3 = 9 > 0\]\[\boxed{f \text{ is increasing on } (-\infty, -1) \text{ and } (1, \infty); \text{ decreasing on } (-1, 1)}\]

Increasing and decreasing behaviour of trigonometric functions

The same sign test applies to any differentiable function, including those built from \(\sin x\) and \(\cos x\): find \(f'(x)\), solve \(f'(x) = 0\) for the critical values in the given domain, and test the sign of \(f'(x)\) in each resulting interval.
Worked exampleFind the intervals of increase and decrease of \(f(x) = x + 2\cos x\) on the domain \(0 < x < 2\pi\).
\[f'(x) = 1 - 2\sin x\]\[1 - 2\sin x = 0 \implies \sin x = \frac{1}{2}\]\[x = \frac{\pi}{6} \text{ or } x = \frac{5\pi}{6}\]\[f'(0.3) = 1 - 2\sin(0.3) \approx 0.41 > 0\]\[f'\left(\frac{\pi}{2}\right) = 1 - 2(1) = -1 < 0\]\[f'\left(\frac{3\pi}{2}\right) = 1 - 2(-1) = 3 > 0\]\[\boxed{f \text{ is increasing on } \left(0, \frac{\pi}{6}\right) \text{ and } \left(\frac{5\pi}{6}, 2\pi\right); \text{ decreasing on } \left(\frac{\pi}{6}, \frac{5\pi}{6}\right)}\]

Increasing through an isolated stationary point

If \(f'(x) \geq 0\) throughout an interval and \(f'(x) = 0\) at only an isolated value within it, the function is still classified as increasing on the whole interval, since the gradient is never negative there.
Worked exampleShow that \(f(x) = x^3\) is increasing for all real \(x\).
\[f'(x) = 3x^2\]\[f'(x) \geq 0 \text{ for all } x, \text{ with } f'(x) = 0 \text{ only at } x = 0\]\[\boxed{f \text{ is increasing for all } x \in \mathbb{R}}\]
