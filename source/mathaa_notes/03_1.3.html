Function notation and evaluating f(x)

For a function \(f\), the notation \(y = f(x)\) means that \(x\), an element of the domain (the input), is mapped by \(f\) to \(y\), an element of the range (the output). To evaluate \(f\) at a particular input, substitute that value for \(x\) everywhere it appears in the formula for \(f\).
Worked exampleGiven \(f(x) = x^2 - 4x + 7\), find \(f(5)\).
\[f(5) = (5)^2 - 4(5) + 7\]\[f(5) = 25 - 20 + 7\]\[\boxed{f(5) = 12}\]

Classifying a relation as a function

A relation is a set of ordered pairs \((x, y)\). A relation is a function if every element of the domain is mapped to exactly one element of the range. A relation can be one-to-one, many-to-one, one-to-many, or many-to-many; only one-to-one and many-to-one relations are functions.
Worked exampleClassify the relation \(\{(2, 5), (3, 5), (2, 9)\}\).
The input \(2\) is mapped to two different outputs, \(5\) and \(9\).
This is a one-to-many relation.
Since the input \(2\) does not map to exactly one output, this relation is NOT a function.

Domain and range of a function

The domain of a function is the set of all possible input (\(x\)) values. The range of a function is the set of all possible output (\(y\)) values produced by the function on that domain.
Worked exampleA function is defined by \(f(x) = 3x - 2\), for \(0 \le x \le 4\). Find its domain and range.
Domain is given directly:
\[0 \le x \le 4\]\[f(0) = 3(0) - 2 = -2\]\[f(4) = 3(4) - 2 = 10\]Since the function is increasing:
\[\boxed{-2 \le y \le 10}\]

The vertical line test

If every vertical line drawn on the graph of a relation cuts the graph at most once, the relation is a function. If any vertical line cuts the graph more than once, the relation is not a function, because that input would then have more than one output.
Worked exampleDoes the relation \(x = y^2\) pass the vertical line test at \(x = 4\)?
Substitute \(x = 4\):
\[y^2 = 4\]\[y = 2 \text{ or } y = -2\]Since \(x = 4\) gives two outputs, the vertical line \(x = 4\) cuts the graph twice.
This relation FAILS the vertical line test, so it is NOT a function.

Domain restrictions for algebraic functions

For a function defined by a formula, the largest possible domain excludes any \(x\)-value that makes the formula undefined. Common restrictions: the denominator of a fraction cannot equal zero, and the expression under a square root cannot be negative.
Worked exampleFind the largest possible domain of \(f(x) = \dfrac{1}{x + 6}\).
The denominator cannot equal zero:
\[x + 6 \neq 0\]\[\boxed{x \neq -6}\]
