Stationary points

A stationary point of \(f\) occurs at any value \(x = c\) where \(f'(c) = 0\): the tangent to the graph is horizontal there. To find the stationary points of a function, solve \(f'(x) = 0\) and substitute each solution back into \(f(x)\) to find the corresponding \(y\)-coordinate.
Worked exampleFind the stationary points of \(f(x) = x^3 - 3x^2 - 9x + 5\).
\[f'(x) = 3x^2 - 6x - 9 = 3(x-3)(x+1)\]\[f'(x) = 0 \implies x = 3 \text{ or } x = -1\]\[f(3) = 27 - 27 - 27 + 5 = -22\]\[f(-1) = -1 - 3 + 9 + 5 = 10\]\[\boxed{(3, -22) \text{ and } (-1, 10)}\]

The first derivative test

At a stationary point \(x = c\):
\[\text{if } f'(x) \text{ changes from } + \text{ to } - \text{ as } x \text{ increases through } c, \ f \text{ has a local maximum at } c\]\[\text{if } f'(x) \text{ changes from } - \text{ to } + \text{ as } x \text{ increases through } c, \ f \text{ has a local minimum at } c\]\[\text{if } f'(x) \text{ does not change sign at } c, \ f \text{ has neither a maximum nor a minimum at } c\]
Worked exampleUse the first derivative test to classify the stationary points of \(f(x) = x^3 - 3x^2 - 9x + 5\), given \(f'(x) = 3(x-3)(x+1)\).
\[f'(-2) = 3(-5)(-1) = 15 > 0\]\[f'(0) = 3(-3)(1) = -9 < 0\]\[f'(4) = 3(1)(5) = 15 > 0\]\[\boxed{(-1, 10) \text{ is a local maximum; } (3, -22) \text{ is a local minimum}}\]

The second derivative test

At a stationary point \(x = c\) (where \(f'(c) = 0\)):
\[\text{if } f''(c) < 0, \ f \text{ has a local maximum at } c\]\[\text{if } f''(c) > 0, \ f \text{ has a local minimum at } c\]\[\text{if } f''(c) = 0, \text{ the test fails and the first derivative test must be used instead}\]
Worked exampleUse the second derivative test to classify the stationary points of \(f(x) = x^3 - 3x^2 - 9x + 5\).
\[f'(x) = 3x^2 - 6x - 9, \quad f''(x) = 6x - 6\]\[f''(-1) = -6 - 6 = -12 < 0\]\[f''(3) = 18 - 6 = 12 > 0\]\[\boxed{(-1, 10) \text{ is a local maximum; } (3, -22) \text{ is a local minimum}}\]

Horizontal points of inflection

A stationary point at which \(f'(x)\) does not change sign is called a horizontal point of inflection. The graph momentarily flattens but continues increasing (or continues decreasing) on both sides, so the point is neither a local maximum nor a local minimum.
Worked exampleShow that \(f(x) = x^3\) has a horizontal point of inflection at \(x = 0\).
\[f'(x) = 3x^2\]\[f'(x) = 0 \text{ only at } x = 0\]\[f'(-1) = 3 > 0, \quad f'(1) = 3 > 0\]Since \(f'(x)\) is positive on both sides of \(x = 0\), it does not change sign.
\[\boxed{(0, 0) \text{ is a horizontal point of inflection}}\]

Describing the behaviour of a graph near a stationary point

Near a local maximum, the graph rises then falls. Near a local minimum, the graph falls then rises. Near a horizontal point of inflection, the graph continues in the same direction on both sides, flattening only for an instant as it passes through the point.
Worked exampleDescribe the shape of the graph of \(f(x) = x^3 - 3x^2 - 9x + 5\) near its stationary points at \(x = -1\) and \(x = 3\).
Near \(x = -1\): \(f\) is increasing for \(x < -1\) and decreasing for \(-1 < x < 3\), so the graph rises to the point \((-1, 10)\) and then falls.
\[\boxed{(-1, 10) \text{ is a peak: a local maximum}}\]Near \(x = 3\): \(f\) is decreasing for \(-1 < x < 3\) and increasing for \(x > 3\), so the graph falls to the point \((3, -22)\) and then rises.
\[\boxed{(3, -22) \text{ is a trough: a local minimum}}\]

Classifying stationary points of a quartic function

The second derivative test applies to a polynomial of any degree: find \(f'(x)\) and solve \(f'(x) = 0\) for every stationary point, then evaluate \(f''(x)\) at each one.
Worked exampleFind and classify the stationary points of \(f(x) = x^4 - 8x^2 + 3\).
\[f'(x) = 4x^3 - 16x = 4x(x-2)(x+2)\]\[f'(x) = 0 \implies x = -2, \ x = 0, \text{ or } x = 2\]\[f''(x) = 12x^2 - 16\]\[f''(-2) = 48 - 16 = 32 > 0 \implies \text{local minimum}\]\[f''(0) = -16 < 0 \implies \text{local maximum}\]\[f''(2) = 48 - 16 = 32 > 0 \implies \text{local minimum}\]\[f(-2) = 16 - 32 + 3 = -13, \quad f(0) = 3, \quad f(2) = 16 - 32 + 3 = -13\]\[\boxed{(-2, -13) \text{ and } (2, -13) \text{ are local minima; } (0, 3) \text{ is a local maximum}}\]
