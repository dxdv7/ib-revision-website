The product rule

If \(y\) is the product of two differentiable functions, \(y = f(x)g(x)\), then \(y\) can be differentiated using the product rule:
\[\frac{d}{dx}[f(x)g(x)] = f'(x)g(x) + f(x)g'(x)\]Equivalently, writing \(u\) and \(v\) as functions of \(x\) with \(y = uv\):
\[\frac{dy}{dx} = \frac{du}{dx} \cdot v + u \cdot \frac{dv}{dx}\]
Worked exampleDifferentiate \(y = (x^2 + 2x)(3x - 1)\) using the product rule.
\[u = x^2 + 2x, \quad v = 3x - 1\]\[\frac{du}{dx} = 2x + 2, \quad \frac{dv}{dx} = 3\]\[\frac{dy}{dx} = \frac{du}{dx} \cdot v + u \cdot \frac{dv}{dx}\]\[\frac{dy}{dx} = (2x + 2)(3x - 1) + (x^2 + 2x)(3)\]\[\frac{dy}{dx} = (6x^2 + 4x - 2) + (3x^2 + 6x)\]\[\boxed{\frac{dy}{dx} = 9x^2 + 10x - 2}\]

Applying the product rule to a function with an exponential factor

When one factor of a product is an exponential function, differentiate each factor and combine using the product rule. Recall that \(\dfrac{d}{dx}(e^x) = e^x\).
Worked exampleDifferentiate \(y = x^3 e^x\).
\[u = x^3, \quad v = e^x\]\[\frac{du}{dx} = 3x^2, \quad \frac{dv}{dx} = e^x\]\[\frac{dy}{dx} = 3x^2 e^x + x^3 e^x\]\[\boxed{\frac{dy}{dx} = x^2 e^x (x + 3)}\]

Applying the product rule to a function with a trigonometric factor

When one factor of a product is a trigonometric function, differentiate each factor and combine using the product rule. Recall that \(\dfrac{d}{dx}(\cos x) = -\sin x\) and \(\dfrac{d}{dx}(\sin x) = \cos x\).
Worked exampleDifferentiate \(y = x^2 \cos x\).
\[u = x^2, \quad v = \cos x\]\[\frac{du}{dx} = 2x, \quad \frac{dv}{dx} = -\sin x\]\[\frac{dy}{dx} = 2x \cos x + x^2(-\sin x)\]\[\boxed{\frac{dy}{dx} = 2x\cos x - x^2 \sin x}\]

The quotient rule

If \(y\) is the quotient of two differentiable functions, \(y = \dfrac{f(x)}{g(x)}\), with \(g(x) \neq 0\), then \(y\) can be differentiated using the quotient rule:
\[\frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}\]Equivalently, writing \(y = \dfrac{u}{v}\):
\[\frac{dy}{dx} = \frac{v\dfrac{du}{dx} - u\dfrac{dv}{dx}}{v^2}\]
Worked exampleDifferentiate \(y = \dfrac{x^2 + 1}{x - 2}\) using the quotient rule.
\[u = x^2 + 1, \quad v = x - 2\]\[\frac{du}{dx} = 2x, \quad \frac{dv}{dx} = 1\]\[\frac{dy}{dx} = \frac{2x(x - 2) - (x^2 + 1)(1)}{(x - 2)^2}\]\[\frac{dy}{dx} = \frac{(2x^2 - 4x) - (x^2 + 1)}{(x - 2)^2}\]\[\boxed{\frac{dy}{dx} = \frac{x^2 - 4x - 1}{(x - 2)^2}}\]

Applying the quotient rule to a function with a trigonometric numerator

When applying the quotient rule, keep the order of subtraction in the numerator correct, since \(f'(x)g(x) - f(x)g'(x)\) is not the same as \(f(x)g'(x) - f'(x)g(x)\). Recall that \(\dfrac{d}{dx}(\sin x) = \cos x\).
Worked exampleDifferentiate \(y = \dfrac{\sin x}{x}\), for \(x \neq 0\).
\[u = \sin x, \quad v = x\]\[\frac{du}{dx} = \cos x, \quad \frac{dv}{dx} = 1\]\[\frac{dy}{dx} = \frac{(\cos x)(x) - (\sin x)(1)}{x^2}\]\[\boxed{\frac{dy}{dx} = \frac{x\cos x - \sin x}{x^2}}\]

Finding and classifying a stationary point using the product rule

Stationary points of \(y = f(x)\) occur where \(\dfrac{dy}{dx} = 0\). Once a stationary point is located, the second derivative test can confirm its nature: if \(\dfrac{d^2y}{dx^2} < 0\) at that point it is a maximum, and if \(\dfrac{d^2y}{dx^2} > 0\) it is a minimum.
Worked exampleFind the exact coordinates of the stationary point of \(y = xe^{-x}\), and classify it.
\[\frac{dy}{dx} = (1)e^{-x} + x(-e^{-x}) = e^{-x}(1 - x)\]\[\frac{dy}{dx} = 0 \implies e^{-x}(1 - x) = 0\]Since \(e^{-x} \neq 0\) for all \(x\), this gives \(1 - x = 0\), so \(x = 1\).\[y(1) = (1)e^{-1} = \frac{1}{e}\]\[\frac{d^2y}{dx^2} = -e^{-x}(1 - x) + e^{-x}(-1) = e^{-x}(x - 2)\]\[\text{At } x = 1: \quad \frac{d^2y}{dx^2} = e^{-1}(1 - 2) = -\frac{1}{e} < 0\]\[\boxed{\text{Maximum point at } \left(1, \frac{1}{e}\right)}\]
