Velocity from acceleration

Given an acceleration function \(a(t)\), the velocity function \(v(t)\) is an antiderivative of \(a(t)\):
\[v(t) = \int a(t)\,dt\]The constant of integration is found using a known initial condition, such as the velocity \(v(t_0)\) at a given time \(t_0\).
Worked exampleThe acceleration of a particle is \(a(t) = 6t - 4\), and its initial velocity is \(v(0) = 5\). Find \(v(t)\).
\[v(t) = \int (6t - 4)\,dt\]\[v(t) = 3t^2 - 4t + C\]\[v(0) = 3(0)^2 - 4(0) + C = 5\]\[C = 5\]\[\boxed{v(t) = 3t^2 - 4t + 5}\]

Displacement from velocity

Given a velocity function \(v(t)\), the displacement function \(s(t)\) is an antiderivative of \(v(t)\):
\[s(t) = \int v(t)\,dt\]The constant of integration is found using a known initial position \(s(t_0)\).
Worked exampleA particle moves with velocity \(v(t) = 4t - 3\), and its initial position is \(s(0) = 1\). Find \(s(t)\).
\[s(t) = \int (4t - 3)\,dt\]\[s(t) = 2t^2 - 3t + C\]\[s(0) = 2(0)^2 - 3(0) + C = 1\]\[C = 1\]\[\boxed{s(t) = 2t^2 - 3t + 1}\]

Net displacement over a time interval

The net displacement of a particle between \(t = a\) and \(t = b\) is the definite integral of its velocity function:
\[\text{displacement} = \int_a^b v(t)\,dt\]This value can be positive, negative, or zero, since it measures the net change in position, and contributions from motion in opposite directions can cancel each other out.
Worked exampleA particle has velocity \(v(t) = 2t - 6\). Find its net displacement over \(0 \le t \le 5\).
\[\text{displacement} = \int_0^5 (2t - 6)\,dt\]\[= \Big[t^2 - 6t\Big]_0^5\]\[= (25 - 30) - (0 - 0)\]\[\boxed{\text{displacement} = -5}\]

Total distance travelled

The total distance travelled between \(t = a\) and \(t = b\) is the definite integral of the speed, \(|v(t)|\):
\[\text{distance} = \int_a^b |v(t)|\,dt\]Since \(v(t)\) may change sign, the interval must be split at each value of \(t\) where \(v(t) = 0\), replacing \(v(t)\) with \(-v(t)\) on any sub-interval where it is negative. This always gives a non-negative result, unlike net displacement.
Worked exampleUsing the same velocity \(v(t) = 2t - 6\), find the total distance travelled over \(0 \le t \le 5\).
\(v(t) = 0\) when \(t = 3\), with \(v(t) < 0\) on \([0, 3]\) and \(v(t) > 0\) on \([3, 5]\).
\[\text{distance} = \int_0^3 -(2t - 6)\,dt + \int_3^5 (2t - 6)\,dt\]\[= \Big[6t - t^2\Big]_0^3 + \Big[t^2 - 6t\Big]_3^5\]\[= (18 - 9) + \big[(25 - 30) - (9 - 18)\big]\]\[= 9 + 4\]\[\boxed{\text{distance} = 13}\]

Motion under constant acceleration

If a particle moves with constant acceleration \(a\), initial velocity \(v_0 = v(0)\), and initial position \(s_0 = s(0)\), integrating twice gives:
\[v(t) = v_0 + at\]\[s(t) = s_0 + v_0 t + \frac{1}{2}at^2\]
Worked exampleA ball is thrown upward with initial velocity \(20 \text{ m s}^{-1}\) from a height of \(1.5\) m, with acceleration \(a = -9.8 \text{ m s}^{-2}\). Find the maximum height reached.
\[v(t) = -9.8t + 20\]The ball reaches its highest point when \(v(t) = 0\):
\[0 = -9.8t + 20\]\[t = \frac{20}{9.8} \approx 2.041 \text{ s}\]\[s(t) = -4.9t^2 + 20t + 1.5\]\[s(2.041) = -4.9(2.041)^2 + 20(2.041) + 1.5\]\[\boxed{s \approx 21.91 \text{ m}}\]
