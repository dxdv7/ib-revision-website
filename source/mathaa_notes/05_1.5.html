Vertical translation

The graph of \(y = f(x) + k\) is obtained by translating the graph of \(y = f(x)\) vertically by \(k\) units: up if \(k > 0\), down if \(k < 0\). Every point \((x, y)\) on \(y = f(x)\) maps to the point \((x, y + k)\).
Worked exampleThe point \((3, 9)\) lies on \(f(x) = x^2\). Find the image of this point on \(g(x) = f(x) - 4\), and describe the transformation.
\[g(x) = x^2 - 4\]\[y\text{-coordinate: } 9 - 4 = 5\]\[\boxed{(3, 5), \text{ a translation 4 units down}}\]

Horizontal translation

The graph of \(y = f(x - h)\) is obtained by translating the graph of \(y = f(x)\) horizontally by \(h\) units: right if \(h > 0\), left if \(h < 0\). Every point \((x, y)\) on \(y = f(x)\) maps to the point \((x + h, y)\).
Worked exampleThe point \((3, 9)\) lies on \(f(x) = x^2\). Find the image of this point on \(g(x) = f(x + 2)\), and describe the transformation.
\[g(x) = (x+2)^2, \text{ so } h = -2\]\[x\text{-coordinate: } 3 + (-2) = 1\]\[\boxed{(1, 9), \text{ a translation 2 units left}}\]

Vertical stretch

The graph of \(y = a \cdot f(x)\) is obtained from \(y = f(x)\) by a vertical stretch of scale factor \(a\): if \(a > 1\) the graph stretches away from the x-axis, and if \(0 < a < 1\) the graph shrinks toward the x-axis. Every point \((x, y)\) maps to \((x, ay)\).
Worked exampleThe point \((3, 9)\) lies on \(f(x) = x^2\). Find the image of this point on \(g(x) = \dfrac{1}{2}f(x)\), and describe the transformation.
\[g(x) = \frac{1}{2}x^2\]\[y\text{-coordinate: } \frac{1}{2}(9) = 4.5\]\[\boxed{(3, 4.5), \text{ a vertical shrink of scale factor } \frac{1}{2}}\]

Horizontal stretch

The graph of \(y = f(bx)\) is obtained from \(y = f(x)\) by a horizontal stretch of scale factor \(\dfrac{1}{b}\): if \(b > 1\) the graph shrinks toward the y-axis, and if \(0 < b < 1\) the graph stretches away from the y-axis. Every point \((x, y)\) maps to \(\left(\dfrac{x}{b}, y\right)\).
Worked exampleThe point \((3, 9)\) lies on \(f(x) = x^2\). Find the image of this point on \(g(x) = f(3x)\), and describe the transformation.
\[g(x) = (3x)^2 = 9x^2\]\[x\text{-coordinate: } \frac{3}{3} = 1\]\[\boxed{(1, 9), \text{ a horizontal shrink of scale factor } \frac{1}{3}}\]

Reflection in the x-axis

The graph of \(y = -f(x)\) is obtained by reflecting the graph of \(y = f(x)\) in the x-axis. Every point \((x, y)\) maps to \((x, -y)\).
Worked exampleThe point \((3, 9)\) lies on \(f(x) = x^2\). Find the image of this point on \(g(x) = -f(x)\).
\[g(x) = -x^2\]\[y\text{-coordinate: } -9\]\[\boxed{(3, -9)}\]

Reflection in the y-axis

The graph of \(y = f(-x)\) is obtained by reflecting the graph of \(y = f(x)\) in the y-axis. Every point \((x, y)\) on \(y = f(x)\) maps to the point \((-x, y)\) on \(y = f(-x)\).
Worked exampleThe point \((3, 9)\) lies on \(f(x) = x^2\). Find the corresponding point on \(g(x) = f(-x)\).
\[g(x) = (-x)^2 = x^2\]\[x\text{-coordinate of the image: } -3\]\[\boxed{(-3, 9)}\]
