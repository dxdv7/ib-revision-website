Derivative of the exponential function

The exponential function \(e^x\) is its own derivative:
\[\frac{d}{dx}(e^x) = e^x\]This means the gradient of the curve \(y = e^x\) at any point is equal to the \(y\)-coordinate of that point.
Worked exampleDifferentiate \(y = 5e^x + x^3\).
\[\frac{dy}{dx} = 5\frac{d}{dx}(e^x) + \frac{d}{dx}(x^3)\]\[\boxed{\frac{dy}{dx} = 5e^x + 3x^2}\]

Derivative of a general exponential function

For a positive base \(a\), with \(a > 0\) and \(a \neq 1\):
\[\frac{d}{dx}(a^x) = a^x \ln a\]When \(a = e\), \(\ln e = 1\) and this rule reduces to \(\dfrac{d}{dx}(e^x) = e^x\).
Worked exampleDifferentiate \(y = 4(3^x)\).
\[\frac{dy}{dx} = 4\frac{d}{dx}(3^x)\]\[\boxed{\frac{dy}{dx} = 4(3^x)\ln 3}\]

Derivative of the natural logarithm function

For \(x > 0\):
\[\frac{d}{dx}(\ln x) = \frac{1}{x}\]
Worked exampleDifferentiate \(y = 4\ln x - x\).
\[\frac{dy}{dx} = 4\frac{d}{dx}(\ln x) - \frac{d}{dx}(x)\]\[\boxed{\frac{dy}{dx} = \frac{4}{x} - 1}\]

Derivative of a general logarithmic function

For a positive base \(a\), with \(a > 0\), \(a \neq 1\), and \(x > 0\):
\[\frac{d}{dx}(\log_a x) = \frac{1}{x \ln a}\]
Worked exampleDifferentiate \(y = 5\log_3 x\).
\[\frac{dy}{dx} = 5\frac{d}{dx}(\log_3 x)\]\[\boxed{\frac{dy}{dx} = \frac{5}{x\ln 3}}\]

Combining the derivative of ln x with the product rule

When a product contains a logarithmic factor, differentiate each factor separately and combine using the product rule:
\[\frac{d}{dx}(uv) = \frac{du}{dx} \cdot v + u \cdot \frac{dv}{dx}\]
Worked exampleDifferentiate \(y = x\ln x\), for \(x > 0\).
\[u = x, \quad v = \ln x\]\[\frac{du}{dx} = 1, \quad \frac{dv}{dx} = \frac{1}{x}\]\[\frac{dy}{dx} = (1)(\ln x) + (x)\left(\frac{1}{x}\right)\]\[\boxed{\frac{dy}{dx} = \ln x + 1}\]

Combining the derivative of ln x with the quotient rule

When a quotient contains a logarithmic term, differentiate the numerator and denominator separately and combine using the quotient rule:
\[\frac{dy}{dx} = \frac{v\dfrac{du}{dx} - u\dfrac{dv}{dx}}{v^2}\]
Worked exampleDifferentiate \(y = \dfrac{\ln x}{x}\), for \(x > 0\).
\[u = \ln x, \quad v = x\]\[\frac{du}{dx} = \frac{1}{x}, \quad \frac{dv}{dx} = 1\]\[\frac{dy}{dx} = \frac{\left(\dfrac{1}{x}\right)(x) - (\ln x)(1)}{x^2}\]\[\boxed{\frac{dy}{dx} = \frac{1 - \ln x}{x^2}}\]
