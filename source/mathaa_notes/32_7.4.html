The mean of discrete data

The arithmetic mean of a set of \(n\) raw values is:
\[\bar{x} = \frac{\sum x}{n}\]If the data is instead given as a frequency table, with each value \(x\) occurring \(f\) times, the mean is:
\[\bar{x} = \frac{\sum fx}{\sum f}\]
Worked exampleEight students score out of 10 on a quiz: 6, 7, 5, 8, 9, 6, 7, 8. Find the mean score.
\[\sum x = 6 + 7 + 5 + 8 + 9 + 6 + 7 + 8\]\[\sum x = 56\]\[\bar{x} = \frac{56}{8}\]\[\boxed{\bar{x} = 7}\]The same data can be written as a frequency table, with \(x\) taking values 5, 6, 7, 8, 9 with frequencies 1, 2, 2, 2, 1.
\[\sum fx = 5(1) + 6(2) + 7(2) + 8(2) + 9(1)\]\[\sum fx = 5 + 12 + 14 + 16 + 9 = 56\]\[\bar{x} = \frac{\sum fx}{\sum f} = \frac{56}{8}\]\[\boxed{\bar{x} = 7}\]

Median and mode of discrete data

For data sorted in ascending order, the position of the median is:
\[\text{median position} = \frac{n+1}{2}\]If \(n\) is odd, this position is a whole number and gives the middle value directly. If \(n\) is even, the median is the mean of the two values on either side of this position. The mode is the value that occurs with the greatest frequency.
Worked exampleNine students' test marks, sorted in ascending order, are: 54, 58, 58, 58, 60, 61, 65, 70, 72. Find the median and the mode.
\[\text{median position} = \frac{9+1}{2} = 5\]The 5th value is 60.
\[\boxed{\text{median} = 60}\]The value 58 occurs three times, more often than any other value.
\[\boxed{\text{mode} = 58}\]Six students' test marks, sorted in ascending order, are: 45, 52, 63, 71, 78, 85. Find the median.
\[\text{median position} = \frac{6+1}{2} = 3.5\]Since this is not a whole number, the median is the mean of the 3rd and 4th values:
\[\text{median} = \frac{63 + 71}{2}\]\[\boxed{\text{median} = 67}\]

Range

The range measures the total spread of a data set:
\[\text{range} = \text{maximum value} - \text{minimum value}\]The range is quick to calculate but, unlike the interquartile range, it is heavily affected by extreme values (outliers).
Worked exampleThe daily maximum temperatures, in degrees Celsius, over 7 days are: 18, 21, 19, 25, 17, 23, 20. Find the range.
\[\text{range} = 25 - 17\]\[\boxed{\text{range} = 8}\]

Quartiles and the interquartile range

For data sorted in ascending order, the lower quartile \(Q_1\) and upper quartile \(Q_3\) are located at:
\[Q_1 \text{ position} = \frac{n+1}{4}, \qquad Q_3 \text{ position} = \frac{3(n+1)}{4}\]The interquartile range measures the spread of the middle 50% of the data, and is not affected by extreme values:
\[IQR = Q_3 - Q_1\]For data grouped into class intervals, \(Q_1\) and \(Q_3\) are instead estimated from a cumulative frequency table using linear interpolation, as shown in the next section.
Worked exampleEleven exam scores, sorted in ascending order, are: 42, 48, 51, 55, 58, 60, 63, 67, 70, 74, 79. Find \(Q_1\), \(Q_3\), and the IQR.
\[Q_1 \text{ position} = \frac{11+1}{4} = 3\]\[Q_3 \text{ position} = \frac{3(11+1)}{4} = 9\]The 3rd value is 51 and the 9th value is 70.
\[Q_1 = 51, \qquad Q_3 = 70\]\[IQR = 70 - 51\]\[\boxed{IQR = 19}\]

Variance and standard deviation: the defining formula

The variance is the mean of the squared deviations of each value from the mean:
\[\sigma^2 = \frac{\sum f(x - \bar{x})^2}{\sum f}\]The standard deviation is the positive square root of the variance, and is measured in the same units as the original data:
\[\sigma = \sqrt{\sigma^2}\]
Worked exampleUsing the quiz score frequency table (\(x\): 5, 6, 7, 8, 9 with \(f\): 1, 2, 2, 2, 1, and \(\bar{x} = 7\)), find the variance and standard deviation.
\[\sum f(x-\bar{x})^2 = 1(5-7)^2 + 2(6-7)^2 + 2(7-7)^2 + 2(8-7)^2 + 1(9-7)^2\]\[\sum f(x-\bar{x})^2 = 1(4) + 2(1) + 2(0) + 2(1) + 1(4)\]\[\sum f(x-\bar{x})^2 = 4 + 2 + 0 + 2 + 4 = 12\]\[\sigma^2 = \frac{12}{8}\]\[\boxed{\sigma^2 = 1.5}\]\[\sigma = \sqrt{1.5}\]\[\boxed{\sigma \approx 1.22}\]

Variance and standard deviation: the computational formula

Variance can also be found using the computationally faster shortcut formula, which always gives the same value as the defining formula:
\[\sigma^2 = \frac{\sum fx^2}{\sum f} - \bar{x}^2\]
Worked exampleUse the shortcut formula to find the variance of the quiz score data (\(x\): 5, 6, 7, 8, 9 with \(f\): 1, 2, 2, 2, 1, and \(\bar{x} = 7\)).
\[\sum fx^2 = 1(5)^2 + 2(6)^2 + 2(7)^2 + 2(8)^2 + 1(9)^2\]\[\sum fx^2 = 25 + 72 + 98 + 128 + 81 = 404\]\[\sigma^2 = \frac{404}{8} - 7^2\]\[\sigma^2 = 50.5 - 49\]\[\boxed{\sigma^2 = 1.5}\]This matches the value found using the defining formula.
