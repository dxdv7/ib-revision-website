The Pythagorean identity

For every real number \(\theta\):
\[\sin^2\theta + \cos^2\theta = 1\]Rearranged to isolate either squared term:
\[\sin^2\theta = 1 - \cos^2\theta \qquad \cos^2\theta = 1 - \sin^2\theta\]
Worked exampleGiven that \(\cos\theta = \dfrac{2}{3}\) and that \(\dfrac{3\pi}{2} < \theta < 2\pi\), find the exact value of \(\sin\theta\).
\[\sin^2\theta = 1 - \cos^2\theta\]\[\sin^2\theta = 1 - \frac{4}{9} = \frac{5}{9}\]\[\sin\theta = \pm\frac{\sqrt{5}}{3}\]Since \(\theta\) is in quadrant IV, \(\sin\theta < 0\).
\[\boxed{\sin\theta = -\frac{\sqrt{5}}{3}}\]

Double angle identity for sine

For every real number \(\theta\):
\[\sin 2\theta = 2\sin\theta\cos\theta\]
Worked exampleGiven that \(\sin\theta = \dfrac{3}{5}\) and \(\cos\theta = \dfrac{4}{5}\), find the exact value of \(\sin 2\theta\).
\[\sin 2\theta = 2\sin\theta\cos\theta\]\[\sin 2\theta = 2\left(\frac{3}{5}\right)\left(\frac{4}{5}\right)\]\[\boxed{\sin 2\theta = \frac{24}{25}}\]

Double angle identities for cosine

For every real number \(\theta\), there are three equivalent forms:
\[\cos 2\theta = \cos^2\theta - \sin^2\theta\]\[\cos 2\theta = 2\cos^2\theta - 1\]\[\cos 2\theta = 1 - 2\sin^2\theta\]The second and third forms follow from the first by substituting the Pythagorean identity \(\sin^2\theta + \cos^2\theta = 1\).
Worked exampleGiven that \(\sin\theta = \dfrac{3}{5}\) and \(\cos\theta = \dfrac{4}{5}\), find the exact value of \(\cos 2\theta\) using each of the three forms.
\[\cos 2\theta = \left(\frac{4}{5}\right)^2 - \left(\frac{3}{5}\right)^2 = \frac{16}{25} - \frac{9}{25} = \frac{7}{25}\]\[\cos 2\theta = 2\left(\frac{4}{5}\right)^2 - 1 = \frac{32}{25} - 1 = \frac{7}{25}\]\[\cos 2\theta = 1 - 2\left(\frac{3}{5}\right)^2 = 1 - \frac{18}{25} = \frac{7}{25}\]\[\boxed{\cos 2\theta = \frac{7}{25}}\]

Choosing a form of the double angle identity for cosine

When only one of \(\sin\theta\) or \(\cos\theta\) is known, choosing the form of \(\cos 2\theta\) written entirely in that function avoids first having to find the other ratio:
\[\cos 2\theta = 2\cos^2\theta - 1 \quad \text{(when } \cos\theta \text{ is known)}\]\[\cos 2\theta = 1 - 2\sin^2\theta \quad \text{(when } \sin\theta \text{ is known)}\]
Worked exampleGiven that \(\cos x = \dfrac{1}{3}\) and \(0 < x < \dfrac{\pi}{2}\), find the exact value of \(\cos 2x\) without first finding \(\sin x\).
\[\cos 2x = 2\cos^2 x - 1\]\[\cos 2x = 2\left(\frac{1}{3}\right)^2 - 1\]\[\cos 2x = \frac{2}{9} - 1\]\[\boxed{\cos 2x = -\frac{7}{9}}\]

Simplifying trigonometric expressions with the Pythagorean identity

Substituting \(\sin^2\theta = 1 - \cos^2\theta\) or \(\cos^2\theta = 1 - \sin^2\theta\) rewrites an expression containing both squared functions in terms of a single trigonometric function.
Worked exampleExpress \(2\cos^2 x + \sin x\) in terms of \(\sin x\) only.
\[2\cos^2 x + \sin x = 2(1 - \sin^2 x) + \sin x\]\[\boxed{= 2 - 2\sin^2 x + \sin x}\]

Combining identities to find exact values

Given one trigonometric ratio and the quadrant in which an angle lies, the Pythagorean identity gives the other ratio (with the correct sign), and the double angle identities then give \(\sin 2\theta\) and \(\cos 2\theta\) exactly.
Worked exampleGiven that \(\cos x = \dfrac{1}{3}\) and \(0 < x < \dfrac{\pi}{2}\), find the exact values of (a) \(\sin x\) and (b) \(\sin 2x\).
(a)
\[\sin^2 x = 1 - \cos^2 x = 1 - \frac{1}{9} = \frac{8}{9}\]\[\sin x = \sqrt{\frac{8}{9}} = \frac{2\sqrt{2}}{3}\]\[\boxed{\sin x = \frac{2\sqrt{2}}{3}}\]
(b)
\[\sin 2x = 2\sin x \cos x\]\[\sin 2x = 2\left(\frac{2\sqrt{2}}{3}\right)\left(\frac{1}{3}\right)\]\[\boxed{\sin 2x = \frac{4\sqrt{2}}{9}}\]
