Integration by inspection: linear inner function

If the integrand has the form \(f(ax+b)\), where the inner function \(ax+b\) is linear, the integral can be found directly by reversing the chain rule:
\[\int f(ax+b)\,dx = \frac{1}{a}F(ax+b) + C\]where \(F\) is an antiderivative of \(f\). The factor \(\dfrac{1}{a}\) compensates for the constant derivative \(a\) of the inner function.
Worked exampleEvaluate \(\int \cos(2x)\,dx\) by inspection.
The inner function \(2x\) has derivative \(2\), so:
\[\int \cos(2x)\,dx = \frac{1}{2}\sin(2x) + C\]Checking: \(\dfrac{d}{dx}\Big[\dfrac{1}{2}\sin(2x)\Big] = \dfrac{1}{2}\cos(2x) \cdot 2 = \cos(2x)\), which matches the integrand.
\[\boxed{\int \cos(2x)\,dx = \frac{1}{2}\sin(2x) + C}\]

Integration by inspection: recognizing a composite derivative

More generally, if the integrand is exactly \(g'(x) \cdot f'(g(x))\) -- the derivative of an inner function \(g(x)\) multiplied by the outer derivative evaluated at \(g(x)\) -- then reversing the chain rule gives:
\[\int g'(x)\,f'(g(x))\,dx = f(g(x)) + C\]This is recognized "by inspection" whenever the derivative of the inner function appears as a factor, exactly or up to a constant multiple.
Worked exampleEvaluate \(\int 2x\cos(x^2)\,dx\) by inspection.
The inner function \(x^2\) has derivative \(2x\), which appears exactly as a factor:
\[\frac{d}{dx}\Big[\sin(x^2)\Big] = \cos(x^2) \cdot 2x\]This matches the integrand exactly, so:
\[\boxed{\int 2x\cos(x^2)\,dx = \sin(x^2) + C}\]

Formal substitution: the method

When the correct pattern is not immediately obvious, substitute \(u = g(x)\), so that \(du = g'(x)\,dx\):
\[\int f(g(x))\,g'(x)\,dx = \int f(u)\,du\]Integrate in terms of \(u\), then substitute \(u = g(x)\) back at the end to return to the original variable.
Worked exampleEvaluate \(\int 2x(x^2+1)^5\,dx\) using substitution.
Let \(u = x^2 + 1\), so \(du = 2x\,dx\).
\[\int 2x(x^2+1)^5\,dx = \int u^5\,du\]\[= \frac{u^6}{6} + C\]\[\boxed{\int 2x(x^2+1)^5\,dx = \frac{(x^2+1)^6}{6} + C}\]

Substitution leading to a natural logarithm

When the integrand has the form \(\dfrac{g'(x)}{g(x)}\), the substitution \(u = g(x)\) gives \(du = g'(x)\,dx\), so:
\[\int \frac{g'(x)}{g(x)}\,dx = \int \frac{du}{u} = \ln|u| + C = \ln|g(x)| + C\]
Worked exampleEvaluate \(\int \frac{2x}{x^2+1}\,dx\).
Let \(u = x^2 + 1\), so \(du = 2x\,dx\).
\[\int \frac{2x}{x^2+1}\,dx = \int \frac{du}{u}\]\[= \ln|u| + C\]Since \(x^2 + 1 > 0\) for all \(x\), the absolute value is not needed:
\[\boxed{\int \frac{2x}{x^2+1}\,dx = \ln(x^2+1) + C}\]

Substitution with a definite integral

When evaluating a definite integral by substitution \(u = g(x)\), the limits of integration must also be converted, from values of \(x\) to the corresponding values of \(u\):
\[\int_a^b f(g(x))\,g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du\]The result is evaluated directly in terms of \(u\) -- there is no need to substitute back to \(x\) at the end.
Worked exampleEvaluate \(\int_0^2 x(x^2+1)^3\,dx\).
Let \(u = x^2 + 1\), so \(du = 2x\,dx\), giving \(x\,dx = \dfrac{1}{2}du\).
When \(x = 0\), \(u = 1\). When \(x = 2\), \(u = 5\).
\[\int_0^2 x(x^2+1)^3\,dx = \int_1^5 u^3 \cdot \frac{1}{2}\,du\]\[= \frac{1}{2}\left[\frac{u^4}{4}\right]_1^5\]\[= \frac{1}{8}\big(5^4 - 1^4\big)\]\[= \frac{1}{8}(625 - 1)\]\[\boxed{\int_0^2 x(x^2+1)^3\,dx = 78}\]
