General form and the y-intercept

A quadratic function can be written in general form as
\[y = ax^2 + bx + c\]where \(a\), \(b\), \(c\) are real constants and \(a \neq 0\). The y-intercept is found by setting \(x = 0\), giving the point \((0, c)\). If \(a > 0\) the parabola opens upward (concave up) and has a minimum point; if \(a < 0\) it opens downward (concave down) and has a maximum point.
Worked exampleFor \(y = 2x^2 - 8x + 5\), state the y-intercept and whether the vertex is a minimum or a maximum.
\[y\text{-intercept: } (0, 5)\]Since \(a = 2 > 0\):
\[\boxed{\text{y-intercept } (0,5); \text{ the graph has a minimum point}}\]

The vertex formula

For a quadratic in general form \(y = ax^2 + bx + c\), the axis of symmetry is the vertical line
\[x = -\frac{b}{2a}\]which passes through the vertex. The y-coordinate of the vertex is found by substituting this x-value back into the function.
Worked exampleFind the vertex of \(y = 2x^2 - 8x + 5\).
\[x = -\frac{-8}{2(2)} = \frac{8}{4} = 2\]\[y = 2(2)^2 - 8(2) + 5 = 8 - 16 + 5\]\[\boxed{\text{Vertex} = (2, -3)}\]

Vertex form

A quadratic function can also be written in vertex form
\[y = a(x - h)^2 + k\]where the vertex is at \((h, k)\) and the axis of symmetry is \(x = h\). The constant \(a\) is the same leading coefficient as in general form.
Worked exampleState the vertex and axis of symmetry of \(y = 3(x + 2)^2 - 7\).
\[y = 3(x - (-2))^2 + (-7)\]\[\boxed{\text{Vertex} = (-2, -7); \text{ axis of symmetry: } x = -2}\]

Completing the square when a = 1

When \(a = 1\), convert \(y = x^2 + bx + c\) to vertex form by halving the coefficient of \(x\), squaring it, then adding and subtracting that value:
\[y = x^2 + bx + c = \left(x + \frac{b}{2}\right)^2 - \left(\frac{b}{2}\right)^2 + c\]
Worked exampleConvert \(y = x^2 - 8x + 18\) to vertex form and state the vertex.
\[y = x^2 - 8x + 18\]\[y = (x^2 - 8x + 16) + 18 - 16\]\[\boxed{y = (x-4)^2 + 2, \text{ vertex } (4, 2)}\]

Completing the square when a is not 1

When \(a \neq 1\), factor \(a\) out of the first two terms before completing the square inside the brackets:
\[y = ax^2 + bx + c = a\left(x^2 + \frac{b}{a}x\right) + c\]then complete the square inside the brackets, and multiply the correction term by \(a\) when removing the brackets.
Worked exampleConvert \(g(x) = -2x^2 - 12x + 7\) to vertex form and state the vertex.
\[g(x) = -2(x^2 + 6x) + 7\]\[g(x) = -2[(x+3)^2 - 9] + 7\]\[g(x) = -2(x+3)^2 + 18 + 7\]\[\boxed{g(x) = -2(x+3)^2 + 25, \text{ vertex } (-3, 25)}\]

Finding x-intercepts by factoring

The x-intercepts of a quadratic function occur where \(y = 0\). When the expression factors easily into two linear factors,
\[ax^2 + bx + c = a(x - p)(x - q)\]the x-intercepts are \(x = p\) and \(x = q\), found using the zero product property. (When a quadratic does not factor easily, the quadratic formula is used instead.)
Worked exampleFind the x-intercepts of \(y = x^2 - 5x + 6\).
\[x^2 - 5x + 6 = 0\]\[(x-2)(x-3) = 0\]\[\boxed{x = 2 \text{ or } x = 3}\]
