Area when a curve lies below the x-axis

If \(f(x) \le 0\) for every \(x\) in \([a, b]\), then \(\int_a^b f(x)\,dx\) is negative, since it measures signed area. The actual (physical) area of the region, which must be non-negative, is the absolute value of this integral:
\[\text{Area} = \left|\int_a^b f(x)\,dx\right| = -\int_a^b f(x)\,dx \quad \text{when } f(x) \le 0 \text{ on } [a, b]\]
Worked exampleFind the area between the curve \(f(x) = x^2 - 4\) and the \(x\)-axis on the interval \([0, 2]\).
\[\int_0^2 (x^2 - 4)\,dx = \Big[\frac{x^3}{3} - 4x\Big]_0^2\]\[= \left(\frac{8}{3} - 8\right) - (0)\]\[= -\frac{16}{3}\]\[\boxed{\text{Area} = \frac{16}{3}}\]

Splitting the integral when the curve crosses the x-axis

When \(f(x)\) changes sign on \([a, b]\), a single integral from \(a\) to \(b\) would let positive and negative regions cancel. To find the total area, first solve \(f(x) = 0\) to locate every \(x\)-intercept in \([a, b]\), splitting the interval into pieces where \(f(x)\) keeps a constant sign, then take the absolute value of the integral over each piece and add the results:
\[\text{Area} = \left|\int_a^c f(x)\,dx\right| + \left|\int_c^b f(x)\,dx\right| + \ldots\]
Worked exampleFind the area between the curve \(f(x) = x^2 - 1\) and the \(x\)-axis on the interval \([-2, 2]\).
\(f(x) = 0\) when \(x = -1\) or \(x = 1\), with \(f(x) \ge 0\) on \([-2,-1]\) and \([1,2]\), and \(f(x) \le 0\) on \([-1,1]\).
\[\int_{-2}^{-1}(x^2-1)\,dx = \Big[\frac{x^3}{3}-x\Big]_{-2}^{-1} = \left(-\frac{1}{3}+1\right)-\left(-\frac{8}{3}+2\right) = \frac{2}{3}-\left(-\frac{2}{3}\right) = \frac{4}{3}\]\[\int_{-1}^{1}(x^2-1)\,dx = \Big[\frac{x^3}{3}-x\Big]_{-1}^{1} = \left(\frac{1}{3}-1\right)-\left(-\frac{1}{3}+1\right) = -\frac{2}{3}-\frac{2}{3} = -\frac{4}{3}\]\[\int_{1}^{2}(x^2-1)\,dx = \Big[\frac{x^3}{3}-x\Big]_{1}^{2} = \left(\frac{8}{3}-2\right)-\left(\frac{1}{3}-1\right) = \frac{2}{3}-\left(-\frac{2}{3}\right) = \frac{4}{3}\]\[\text{Area} = \frac{4}{3} + \left|-\frac{4}{3}\right| + \frac{4}{3}\]\[\boxed{\text{Area} = 4}\]

Finding limits of integration from intersection points

Before an area between a curve and the \(x\)-axis, or between two curves, can be calculated, the limits of integration must usually be found. These bounds are the \(x\)-values at which the boundaries meet: solve \(f(x) = 0\) for a curve and the \(x\)-axis, or solve \(f(x) = g(x)\) for two curves \(y = f(x)\) and \(y = g(x)\).
Worked exampleFind the \(x\)-values at which the curves \(y = x^2\) and \(y = x + 2\) intersect.
\[x^2 = x + 2\]\[x^2 - x - 2 = 0\]\[(x-2)(x+1) = 0\]\[\boxed{x = -1 \text{ or } x = 2}\]

The area between two curves

If \(f(x) \ge g(x)\) for every \(x\) in \([a, b]\), then the area of the region enclosed between the curves \(y = f(x)\) and \(y = g(x)\) is given by subtracting the lower curve from the upper curve before integrating:
\[\text{Area} = \int_a^b \big[f(x) - g(x)\big]\,dx\]
Worked exampleFind the area of the region bounded by \(y = x + 2\) and \(y = x^2\), which intersect at \(x = -1\) and \(x = 2\) (see previous example).
Testing \(x = 0\) shows \(x + 2 = 2\) lies above \(x^2 = 0\), so \(x+2\) is the upper curve.
\[\text{Area} = \int_{-1}^{2}\big[(x+2) - x^2\big]\,dx = \Big[\frac{x^2}{2} + 2x - \frac{x^3}{3}\Big]_{-1}^{2}\]\[= \left(2 + 4 - \frac{8}{3}\right) - \left(\frac{1}{2} - 2 + \frac{1}{3}\right)\]\[= \frac{10}{3} - \left(-\frac{7}{6}\right)\]\[\boxed{\text{Area} = \frac{9}{2}}\]

Areas between curves that intersect more than once

When two curves intersect at more than two points, \(f(x) - g(x)\) may change sign between consecutive intersection points, so the curve that is "on top" can switch. The interval must be split at every intersection point, using whichever function is on top on each piece, and the resulting areas are added together.
Worked exampleFind the area enclosed between the curves \(y = x^3\) and \(y = x\).
\[x^3 = x \implies x^3 - x = 0 \implies x(x-1)(x+1) = 0 \implies x = -1, 0, 1\]On \([-1, 0]\), \(x^3 \ge x\); on \([0, 1]\), \(x \ge x^3\).
\[\int_{-1}^{0}(x^3 - x)\,dx = \Big[\frac{x^4}{4}-\frac{x^2}{2}\Big]_{-1}^{0} = (0) - \left(\frac{1}{4}-\frac{1}{2}\right) = \frac{1}{4}\]\[\int_{0}^{1}(x - x^3)\,dx = \Big[\frac{x^2}{2}-\frac{x^4}{4}\Big]_{0}^{1} = \left(\frac{1}{2}-\frac{1}{4}\right) - (0) = \frac{1}{4}\]\[\text{Area} = \frac{1}{4} + \frac{1}{4}\]\[\boxed{\text{Area} = \frac{1}{2}}\]
