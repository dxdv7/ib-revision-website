The quadratic formula

For a quadratic equation \(ax^2 + bx + c = 0\) with \(a \ne 0\), the two solutions for \(x\) are given by the quadratic formula:
\[x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]where \(a\), \(b\), and \(c\) are the coefficients of \(x^2\), \(x\), and the constant term respectively, and the symbol \(\pm\) means that there are generally two solutions, one using \(+\) and one using \(-\).
Worked exampleSolve \(2x^2 + 5x - 3 = 0\) using the quadratic formula.
\[x = \frac{-5 \pm \sqrt{5^2 - 4(2)(-3)}}{2(2)}\]\[x = \frac{-5 \pm \sqrt{25 + 24}}{4}\]\[x = \frac{-5 \pm \sqrt{49}}{4}\]\[x = \frac{-5 \pm 7}{4}\]\[\boxed{x = \frac{1}{2} \text{ or } x = -3}\]

The discriminant and the nature of the roots

The discriminant of the quadratic equation \(ax^2 + bx + c = 0\) is the expression under the square root sign in the quadratic formula:
\[\Delta = b^2 - 4ac\]The sign of \(\Delta\) tells you how many real roots the equation has, without needing to solve it: if \(\Delta > 0\) there are two distinct real roots; if \(\Delta = 0\) there is exactly one repeated real root; if \(\Delta < 0\) there are no real roots.
Worked exampleUse the discriminant to determine the number of real roots of \(4x^2 - 12x + 9 = 0\), then solve the equation.
\[\Delta = (-12)^2 - 4(4)(9)\]\[\Delta = 144 - 144\]\[\Delta = 0\]Since \(\Delta = 0\), the equation has exactly one repeated real root, given by \(x = \dfrac{-b}{2a}\):
\[x = \frac{-(-12)}{2(4)}\]\[x = \frac{12}{8}\]\[\boxed{x = \frac{3}{2}}\]

Solving quadratic inequalities by sign analysis

To solve a quadratic inequality such as \(ax^2 + bx + c > 0\), first solve the corresponding equation \(ax^2 + bx + c = 0\) to find its roots; these are the critical values that divide the number line into intervals. Then use the shape of the graph of \(y = ax^2 + bx + c\) (an upward parabola when \(a > 0\), a downward parabola when \(a < 0\)) to decide which intervals make the expression satisfy the inequality.
Worked exampleSolve the inequality \(x^2 - 5x + 6 > 0\).
\[(x-2)(x-3) > 0\]The critical values are \(x = 2\) and \(x = 3\). Since the coefficient of \(x^2\) is \(a = 1 > 0\), the graph of \(y = (x-2)(x-3)\) is an upward parabola, which is positive outside its roots and negative between them.
\[\boxed{x < 2 \text{ or } x > 3}\]

Using the discriminant with an unknown parameter

When a quadratic equation contains an unknown constant, often called a parameter, the condition that it has two distinct real roots (\(\Delta > 0\)), one repeated real root (\(\Delta = 0\)), or no real roots (\(\Delta < 0\)) becomes an inequality or equation in that parameter, which can then be solved using the same algebraic methods used for any quadratic inequality or equation.
Worked exampleFind the values of \(k\) for which the equation \(x^2 - kx + (k + 3) = 0\) has two equal real roots.
\[\Delta = (-k)^2 - 4(1)(k+3)\]\[\Delta = k^2 - 4k - 12\]Two equal real roots requires \(\Delta = 0\):
\[k^2 - 4k - 12 = 0\]\[(k-6)(k+2) = 0\]\[\boxed{k = 6 \text{ or } k = -2}\]
