Rational functions and their domain

A rational function in this course has the form \[y = \frac{ax+b}{cx+d}\]where \(a\), \(b\), \(c\), and \(d\) are constants with \(c \ne 0\). Because division by zero is undefined, the domain of this function excludes any value of \(x\) that makes the denominator \(cx+d\) equal to zero.
Worked exampleState the domain of \(y = \dfrac{2x-3}{x+3}\).
The denominator is zero when:
\[x + 3 = 0\]\[x = -3\]\[\boxed{x \in \mathbb{R}, x \ne -3}\]

Vertical asymptotes

A vertical asymptote of a rational function occurs at each value of \(x\) that makes the denominator equal to zero (provided the numerator is not also zero there). For \(y = \dfrac{ax+b}{cx+d}\), the vertical asymptote is the line \(x = -\dfrac{d}{c}\), found by setting the denominator \(cx+d\) equal to zero and solving for \(x\).
Worked exampleFind the vertical asymptote of \(y = \dfrac{2x-3}{x+3}\).
Set the denominator equal to zero:
\[x + 3 = 0\]\[\boxed{x = -3}\]

Horizontal asymptotes

A horizontal asymptote describes the value that \(y\) approaches as \(x \to \pm\infty\). For \(y = \dfrac{ax+b}{cx+d}\), dividing every term in the numerator and denominator by \(x\) gives \[y = \frac{a + \frac{b}{x}}{c + \frac{d}{x}}\]and as \(x \to \pm\infty\), the terms \(\dfrac{b}{x}\) and \(\dfrac{d}{x}\) both approach zero, so \(y \to \dfrac{a}{c}\). The horizontal asymptote is therefore the line \(y = \dfrac{a}{c}\), the ratio of the coefficients of \(x\) in the numerator and denominator.
Worked exampleFind the horizontal asymptote of \(y = \dfrac{2x-3}{x+3}\).
The coefficients of \(x\) in the numerator and denominator are \(2\) and \(1\):
\[y = \frac{2}{1}\]\[\boxed{y = 2}\]

Intercepts of a rational function

A fraction equals zero only when its numerator is zero, so the \(x\)-intercept of \(y = \dfrac{ax+b}{cx+d}\) is found by setting the numerator \(ax+b\) equal to zero and solving for \(x\) (provided this value does not also make the denominator zero). The \(y\)-intercept is found by evaluating the function at \(x = 0\), giving \(y = \dfrac{b}{d}\) provided \(d \ne 0\).
Worked exampleFind the \(x\)-intercept and \(y\)-intercept of \(y = \dfrac{2x-3}{x+3}\).
For the \(x\)-intercept, set the numerator equal to zero:
\[2x - 3 = 0\]\[\boxed{x = \frac{3}{2}}\]For the \(y\)-intercept, substitute \(x = 0\):
\[y = \frac{2(0)-3}{0+3}\]\[y = \frac{-3}{3}\]\[\boxed{y = -1}\]

Domain and range of a rational function

For a rational function \(y = \dfrac{ax+b}{cx+d}\) whose numerator and denominator have no common factor, the domain is all real \(x\) except the value at the vertical asymptote, and the range is all real \(y\) except the value at the horizontal asymptote, since the graph approaches but never reaches that horizontal line.
Worked exampleState the domain and range of \(y = \dfrac{2x-3}{x+3}\).
The vertical asymptote is \(x = -3\) and the horizontal asymptote is \(y = 2\):
\[\boxed{x \in \mathbb{R}, x \ne -3 \text{ and } y \in \mathbb{R}, y \ne 2}\]
