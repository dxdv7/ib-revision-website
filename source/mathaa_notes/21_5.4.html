The graph of y = sin x

The graph of \(y = \sin x\) has:
\[\text{domain: all real } x \qquad \text{range: } -1 \leq y \leq 1\]\[\text{period: } 2\pi \qquad \text{amplitude: } 1 \qquad \text{midline: } y = 0\]Over one period \(0 \leq x \leq 2\pi\): zeros at \(x = 0, \pi, 2\pi\); maximum value \(1\) at \(x = \dfrac{\pi}{2}\); minimum value \(-1\) at \(x = \dfrac{3\pi}{2}\).
Worked exampleFind all values of \(x\) in the interval \([0, 4\pi]\) at which \(y = \sin x\) attains its maximum value.
The maximum value of \(1\) occurs at \(x = \dfrac{\pi}{2} + k \cdot 2\pi\), where \(k\) is an integer.
\[\boxed{x = \frac{\pi}{2} \text{ and } x = \frac{5\pi}{2}}\]

The graph of y = cos x

The graph of \(y = \cos x\) has:
\[\text{domain: all real } x \qquad \text{range: } -1 \leq y \leq 1\]\[\text{period: } 2\pi \qquad \text{amplitude: } 1 \qquad \text{midline: } y = 0\]Over one period \(0 \leq x \leq 2\pi\): maximum value \(1\) at \(x = 0\) and \(x = 2\pi\); minimum value \(-1\) at \(x = \pi\); zeros at \(x = \dfrac{\pi}{2}\) and \(x = \dfrac{3\pi}{2}\).
Worked exampleFind all zeros of \(y = \cos x\) in the interval \([0, 4\pi]\).
The zeros occur at \(x = \dfrac{\pi}{2} + k\pi\), where \(k\) is an integer.
\[\boxed{x = \frac{\pi}{2}, \ \frac{3\pi}{2}, \ \frac{5\pi}{2}, \ \frac{7\pi}{2}}\]

Period and amplitude of a periodic function

A function \(f\) is periodic with period \(p\) if \(f(x) = f(x + p)\) for all \(x\) in its domain, where \(p\) is the smallest such positive number. For a periodic function that oscillates about a horizontal midline, the amplitude is half the difference between its maximum and minimum values:
\[\text{amplitude} = \frac{\text{maximum} - \text{minimum}}{2}\]
Worked exampleUse the maximum and minimum values of \(y = \sin x\) to confirm its amplitude.
\[\text{amplitude} = \frac{1 - (-1)}{2}\]\[\boxed{\text{amplitude} = 1}\]

The graph of y = tan x

The graph of \(y = \tan x\) has:
\[\text{domain: all real } x \text{ except } x = \frac{\pi}{2} + k\pi \qquad \text{range: all real } y\]\[\text{period: } \pi\]Vertical asymptotes occur at \(x = \dfrac{\pi}{2} + k\pi\), where \(k\) is an integer, since \(\tan x = \dfrac{\sin x}{\cos x}\) is undefined when \(\cos x = 0\). The tangent function has no amplitude, since it has no maximum or minimum value.
Worked exampleState the equations of the two vertical asymptotes of \(y = \tan x\) nearest to \(x = 0\).
The asymptotes occur at \(x = \dfrac{\pi}{2} + k\pi\). Taking \(k = -1\) and \(k = 0\):
\[\boxed{x = -\frac{\pi}{2} \text{ and } x = \frac{\pi}{2}}\]

Key features of one period of y = tan x

On the interval \(-\dfrac{\pi}{2} < x < \dfrac{\pi}{2}\) (one full period), \(y = \tan x\) passes through \((0, 0)\), increases without bound as \(x \to \dfrac{\pi}{2}^{-}\), and decreases without bound as \(x \to -\dfrac{\pi}{2}^{+}\). Since \(\tan(-x) = -\tan x\), the graph is symmetric about the origin.
Worked exampleState whether \(y = \tan x\) is increasing or decreasing on the interval \(\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)\), and find the value of \(\tan x\) at the midpoint of this interval, \(x = 0\).
\(\tan x\) is strictly increasing throughout \(\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)\).
\[\boxed{\tan 0 = 0}\]
