The general quadratic function

A quadratic function has the form \(y = ax^2 + bx + c\), where \(a\), \(b\) and \(c\) are constants and \(a \ne 0\). Here \(a\) is the coefficient of \(x^2\), \(b\) is the coefficient of \(x\), and \(c\) is the constant term (also the \(y\)-intercept, since \(y = c\) when \(x = 0\)). The graph of a quadratic function is a parabola.
Worked exampleA dolphin's jump is modelled by \(f(x) = -0.09375x^2 + 1.875x - 3.375\), where \(x\) is the horizontal distance travelled (m) and \(f(x)\) is the height above the water (m). State the values of \(a\), \(b\) and \(c\), then use the model to find the dolphin's height when \(x = 10\).
\[a = -0.09375, \quad b = 1.875, \quad c = -3.375\]\[f(10) = -0.09375(10)^2 + 1.875(10) - 3.375\]\[f(10) = -0.09375(100) + 18.75 - 3.375\]\[f(10) = -9.375 + 18.75 - 3.375\]\[\boxed{f(10) = 6}\]The model predicts the dolphin is 6 m above the water after travelling 10 m horizontally.

Fitting a quadratic model to data

Given a set of data points, technology (a GDC or graphing software) can perform quadratic regression to find the values of \(a\), \(b\) and \(c\) in \(y = ax^2 + bx + c\) that best model the data. Once found, the model can be used to interpolate or extrapolate values not in the original data.
Worked exampleA data set contains the points \((0, 5)\), \((1, 4)\), \((2, 7)\) and \((3, 14)\). Using quadratic regression on a GDC, the model obtained is \(y = 2x^2 - 3x + 5\). Use this model to predict the value of \(y\) when \(x = 5\).
Check the model against the data: at \(x = 0\), \(y = 2(0)^2 - 3(0) + 5 = 5\) — matches.
At \(x = 2\), \(y = 2(2)^2 - 3(2) + 5 = 8 - 6 + 5 = 7\) — matches.
At \(x = 5\):
\[y = 2(5)^2 - 3(5) + 5\]\[y = 50 - 15 + 5\]\[\boxed{y = 40}\]The model predicts \(y = 40\) when \(x = 5\).

Vertex form and completing the square

The vertex form of a quadratic function is \(y = a(x - h)^2 + k\), where \((h, k)\) is the vertex of the parabola. To convert from general form \(y = ax^2 + bx + c\) into vertex form, factor \(a\) out of the \(x^2\) and \(x\) terms, then complete the square inside the brackets.
Worked exampleConvert \(y = 2x^2 - 8x + 3\) into vertex form and state the vertex. Then convert \(y = 3(x + 1)^2 - 4\) into general form.
\[y = 2x^2 - 8x + 3 = 2(x^2 - 4x) + 3\]\[y = 2[(x - 2)^2 - 4] + 3, \text{ since } (x - 2)^2 = x^2 - 4x + 4\]\[y = 2(x - 2)^2 - 8 + 3 = 2(x - 2)^2 - 5\]\[\boxed{y = 2(x - 2)^2 - 5, \ \text{vertex } (2, -5)}\]Converting \(y = 3(x + 1)^2 - 4\) to general form: \((x + 1)^2 = x^2 + 2x + 1\)
\[y = 3(x^2 + 2x + 1) - 4\]\[y = 3x^2 + 6x + 3 - 4\]\[\boxed{y = 3x^2 + 6x - 1}\]
