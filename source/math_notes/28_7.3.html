The addition rule (general)

\[P(A \text{ or } B) = P(A) + P(B) - P(A \text{ and } B)\]where \(P(A \text{ and } B)\) is subtracted so outcomes belonging to both events are not counted twice.
Worked example\(P(A) = 0.55\), \(P(B) = 0.4\), \(P(A \text{ and } B) = 0.15\). Find \(P(A \text{ or } B)\).
\[P(A \text{ or } B) = 0.55 + 0.4 - 0.15 = \boxed{0.8}\]

The addition rule for mutually exclusive events

If \(A\) and \(B\) are mutually exclusive (they cannot both occur), then \(P(A \text{ and } B) = 0\), so
\[P(A \text{ or } B) = P(A) + P(B)\]
Worked exampleA fair six-sided die is rolled. \(A\) = "throw a 2", \(B\) = "throw a 5". \(A\) and \(B\) are mutually exclusive. Find \(P(A \text{ or } B)\).
\(P(A) = \dfrac{1}{6}\), \(P(B) = \dfrac{1}{6}\)
\[P(A \text{ or } B) = \frac{1}{6} + \frac{1}{6} = \frac{2}{6} = \boxed{0.333 \text{ (3 sf)}}\]

The multiplication rule for independent events

If \(A\) and \(B\) are independent (the occurrence of one does not affect the probability of the other), then
\[P(A \text{ and } B) = P(A) \times P(B)\]
Worked exampleAt a cafe, \(P(\text{a customer buys coffee}) = 0.6\) and, independently, \(P(\text{the same customer buys a pastry}) = 0.45\). Find \(P(\text{buys coffee and buys a pastry})\).
\[P(A \text{ and } B) = 0.6 \times 0.45 = \boxed{0.27}\]

General multiplication rule (rearranging conditional probability)

\[P(A \text{ and } B) = P(A \mid B) \times P(B)\]where \(P(A \mid B)\) is the probability of \(A\) given that \(B\) has occurred. This holds for any two events, not only independent ones.
Worked example\(P(A \mid B) = 0.8\) and \(P(B) = 0.25\). Find \(P(A \text{ and } B)\).
\[P(A \text{ and } B) = 0.8 \times 0.25 = \boxed{0.2}\]

Conditional probability

\[P(A \mid B) = \frac{P(A \text{ and } B)}{P(B)}\]the probability that \(A\) occurs given that \(B\) has already occurred (\(B\) becomes the new, reduced sample space).
Worked example\(P(A \text{ and } B) = 0.18\) and \(P(B) = 0.4\). Find \(P(A \mid B)\).
\[P(A \mid B) = \frac{0.18}{0.4} = \boxed{0.45}\]

Testing for independence

\(A\) and \(B\) are independent if and only if \(P(A \mid B) = P(A)\), or equivalently \(P(A \text{ and } B) = P(A) \times P(B)\). If neither equality holds, \(A\) and \(B\) are dependent.
Worked example\(P(A) = 0.3\), \(P(B) = 0.5\), \(P(A \text{ and } B) = 0.2\). Determine whether \(A\) and \(B\) are independent.
\[P(A) \times P(B) = 0.3 \times 0.5 = 0.15\]Since \(0.15 \ne 0.2 = P(A \text{ and } B)\), \(A\) and \(B\) are not independent (they are dependent).
