The vertex of a quadratic function

For \(f(x) = ax^2 + bx + c\), the vertex (turning point) has \(x\)-coordinate \(x = \dfrac{-b}{2a}\). Substitute this \(x\)-value back into \(f(x)\) to find the \(y\)-coordinate of the vertex. If \(a > 0\) the vertex is a minimum (parabola opens upward); if \(a < 0\) the vertex is a maximum (parabola opens downward).
Worked exampleA stone is thrown so that its height in metres after \(t\) seconds is \(h(t) = -5t^2 + 20t + 1\). Find the maximum height.
\[a = -5, \quad b = 20, \quad c = 1\]\[t = \frac{-b}{2a} = \frac{-20}{2 \times (-5)} = \frac{-20}{-10} = 2\]\[h(2) = -5(2)^2 + 20(2) + 1\]\[h(2) = -20 + 40 + 1\]\[\boxed{h(2) = 21}\]Since \(a = -5 < 0\), the vertex is a maximum: the stone reaches a maximum height of 21 m after 2 seconds.

Optimization word problems

To optimize a real-life quantity modelled by a quadratic: write the quantity as a function of one variable, find the vertex using \(x = \dfrac{-b}{2a}\), then substitute to find the optimal value.
Worked exampleA rectangular mirror has perimeter 260 cm. Its length is \(x\) cm. Find the value of \(x\) that gives the maximum area, and find that maximum area.
Let the height be \(y\) cm:
\[2x + 2y = 260\]\[y = 130 - x\]Area: \(A(x) = x(130 - x) = 130x - x^2\), so \(a = -1\), \(b = 130\)
\[x = \frac{-b}{2a} = \frac{-130}{2 \times (-1)} = \frac{-130}{-2}\]\[\boxed{x = 65}\]\[A(65) = 130(65) - 65^2\]\[A(65) = 8450 - 4225\]\[\boxed{A(65) = 4225}\]Since \(a = -1 < 0\), this is a maximum: the mirror has its greatest possible area, 4225 cm\(^2\), when \(x = 65\) cm.
