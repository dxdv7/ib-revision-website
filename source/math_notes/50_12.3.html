Finding stationary points

A stationary point of \(f(x)\) occurs where \(f'(x) = 0\). Solve this equation to find the \(x\)-coordinate(s), then substitute back into \(f(x)\) to find the corresponding \(y\)-coordinate(s).
Worked exampleFind the stationary points of \(f(x) = x^3 - 3x^2 - 9x + 5\).
\[f'(x) = 3x^2 - 6x - 9\]Set \(f'(x) = 0\): \[3x^2 - 6x - 9 = 0\]\[x^2 - 2x - 3 = 0\]\[(x - 3)(x + 1) = 0\]so \(x = 3\) or \(x = -1\)
\[f(3) = 27 - 27 - 27 + 5 = -22\]\[f(-1) = -1 - 3 + 9 + 5 = 10\]\[\boxed{(-1, 10) \text{ and } (3, -22)}\]

Classifying stationary points using the second derivative

At a stationary point \(x = c\): if \(f''(c) > 0\), it is a local minimum; if \(f''(c) < 0\), it is a local maximum; if \(f''(c) = 0\), the test is inconclusive and a sign table must be used instead.
Worked exampleClassify the stationary points of \(f(x) = x^3 - 3x^2 - 9x + 5\) found above, at \(x = -1\) and \(x = 3\).
\[f''(x) = 6x - 6\]\[f''(-1) = 6(-1) - 6 = -12 < 0\]so \((-1, 10)\) is a local maximum
\[f''(3) = 6(3) - 6 = 12 > 0\]so \((3, -22)\) is a local minimum

Classifying stationary points using a sign table

If the sign of \(f'(x)\) changes from negative to positive across \(x = c\), then \((c, f(c))\) is a local minimum. If it changes from positive to negative, it is a local maximum. If the sign does not change, the point is not a local extremum.
Worked exampleClassify the stationary point of \(f(x) = x^4\) at \(x = 0\), given that \(f''(0) = 0\).
\[f'(x) = 4x^3\]so \(f'(0) = 0\)
Just left of 0 (\(x = -1\)): \[f'(-1) = 4(-1)^3 = -4 \text{ (negative)}\]Just right of 0 (\(x = 1\)): \[f'(1) = 4(1)^3 = 4 \text{ (positive)}\]The sign changes from negative to positive, so \((0, 0)\) is a local minimum

Optimization problems

To optimize a quantity subject to a constraint: write the quantity to be optimized as a function of one variable using the constraint to eliminate the other variable(s), then solve \((\text{quantity})' = 0\) and classify the result.
Worked exampleA rectangular vegetable garden is enclosed by 100 m of fencing. Let the width be \(x\) metres. Find the dimensions that maximize the area, and state the maximum area.
Perimeter: \[2x + 2y = 100\]so \(y = 50 - x\)
Area: \[A = xy = x(50 - x) = 50x - x^2\]\[\frac{dA}{dx} = 50 - 2x\]Set \(\dfrac{dA}{dx} = 0\): \[50 - 2x = 0\]so \(x = 25\)
\[y = 50 - 25 = 25\]\[A = 25 \times 25 = 625 \text{ m}^2\]\[\frac{d^2A}{dx^2} = -2 < 0 \text{, confirming a maximum}\]\[\boxed{A_{\max} = 625 \text{ m}^2 \text{, when the garden is a 25 m by 25 m square}}\]
