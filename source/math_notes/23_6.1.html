Range and direction of Pearson’s correlation coefficient, r

Pearson’s product moment correlation coefficient, r, always satisfies −1 ≤ r ≤ 1. If r > 0 the correlation is positive (y tends to increase as x increases). If r < 0 the correlation is negative (y tends to decrease as x increases). If r = 0 there is no linear correlation. If r = 1 or r = −1 the correlation is a perfect linear correlation, with every point lying exactly on a straight line.
Worked exampleClassify the direction of the correlation for each of the following: hours of sunshine and ice-cream sales, r = 0.87; average speed and journey time over a fixed distance, r = −0.42; a person’s shoe size and their test score, r = 0.
r = 0.87 is greater than 0, so this is a positive correlation
r = −0.42 is less than 0, so this is a negative correlation
r = 0, so there is no linear correlation between shoe size and test score

Interpreting the strength of a correlation from |r|

The magnitude |r| can be used to describe the strength of a linear correlation: 0 ≤ |r| < 0.25 is very weak, 0.25 ≤ |r| < 0.5 is weak, 0.5 ≤ |r| < 0.75 is moderate, and 0.75 ≤ |r| ≤ 1 is strong.
Worked exampleClassify the strength of the correlation for r = 0.63, r = −0.91 and r = 0.12.
|0.63| = 0.63, and 0.5 ≤ 0.63 < 0.75, so this is a moderate correlation
|−0.91| = 0.91, and 0.75 ≤ 0.91 ≤ 1, so this is a strong correlation
|0.12| = 0.12, and 0 ≤ 0.12 < 0.25, so this is a very weak correlation

Combining direction and strength to describe a correlation

A correlation is fully described by stating both its direction (from the sign of r) and its strength (from |r| on the scale above), for example “moderate negative linear correlation”.
Worked exampleA study finds that the correlation coefficient between a car’s age (in years) and its resale value (in dollars) is r = −0.68. Describe the correlation and interpret it in context.
Sign: r = −0.68 is negative
Magnitude: |−0.68| = 0.68, and 0.5 ≤ 0.68 < 0.75, so the strength is moderate
This is a moderate negative linear correlation: as a car’s age increases, its resale value tends to decrease, although the relationship is not extremely strong, so other factors also affect resale value

Effect of outliers on the correlation coefficient

An outlier that does not follow the general linear trend of the rest of the data weakens the measured correlation, pulling |r| toward 0; removing such an outlier typically increases |r|. An outlier that does follow the general trend has little effect on r.
Worked exampleA data set of 10 points gives a correlation coefficient of r = 0.58. One point is identified as an outlier that does not follow the linear trend of the other 9 points. When this outlier is removed, the correlation coefficient for the remaining 9 points becomes r = 0.89. Describe the effect of removing the outlier.
Before removal: |0.58| = 0.58, a moderate correlation (0.5 ≤ 0.58 < 0.75)
After removal: |0.89| = 0.89, a strong correlation (0.75 ≤ 0.89 ≤ 1)
Change in r = 0.89 − 0.58 = 0.31
Removing the outlier increased r by 0.31, changing the correlation from moderate to strong, which confirms that the outlier was weakening the measured linear relationship
