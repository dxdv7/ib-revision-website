Theoretical probability

P(A) = n(A) / n(U), where n(A) is the number of outcomes that make event A happen and n(U) is the total number of outcomes in the sample space. For any event, 0 ≤ P(A) ≤ 1.
Worked exampleA fair twelve-sided die numbered 1 to 12 is thrown. Find the probability of throwing a prime number.
Prime faces in {1, ..., 12}: 2, 3, 5, 7, 11, so n(A) = 5
n(U) = 12
P(A) = 5/12 = 0.417 (3 sf)

Relative frequency (experimental probability)

Relative frequency of A = (frequency of occurrence of A in n trials) / n. This is also called the experimental probability of A, and it approaches the theoretical probability as the number of trials increases.
Worked exampleA drawing pin is tossed 200 times and lands point-up 134 times. Find the experimental probability that it lands point-up.
Relative frequency = 134 / 200
Relative frequency = 0.670

The complement rule

P(not A) = 1 − P(A), since an event either happens or does not happen, and these two possibilities account for the whole sample space.
Worked exampleThe probability that a school bus arrives late is 0.12. Find the probability that it does not arrive late.
P(not late) = 1 − P(late)
P(not late) = 1 − 0.12 = 0.88

Expected number of occurrences

Expected number of occurrences of A in n trials = n × P(A), obtained by rearranging the relative frequency formula and using theoretical probability to model long-run behaviour.
Worked exampleThe probability that a component is defective is 0.05. Find the expected number of defective components in a batch of 340.
Expected number = n × P(A)
Expected number = 340 × 0.05 = 17
