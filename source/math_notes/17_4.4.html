Condition for parallel lines

Two lines with gradients \(m_1\) and \(m_2\) are parallel if and only if \(m_1 = m_2\).
Worked exampleLine \(L_1\) passes through \((2, 4)\) and \((-1, -2)\). Line \(L_2\) passes through \((0, -4)\) and \((2, 0)\). Determine whether \(L_1\) and \(L_2\) are parallel.
\[\text{Gradient of } L_1 = \frac{-2 - 4}{-1 - 2} = \frac{-6}{-3} = 2\]\[\text{Gradient of } L_2 = \frac{0 - (-4)}{2 - 0} = \frac{4}{2} = 2\]Since the gradients are equal, \(\boxed{L_1 \text{ and } L_2 \text{ are parallel}}\).

Equation of a line parallel to a given line

To find the equation of a line parallel to a line with gradient \(m\), through a point \((x_1, y_1)\): use \(y - y_1 = m(x - x_1)\), since the new line has the same gradient \(m\).
Worked exampleFind the equation of the line parallel to \(y = 3x + 2\) that passes through \((4, 5)\).
Parallel lines have the same gradient, so \(m = 3\)
\[y - 5 = 3(x - 4)\]\[y = 3x - 12 + 5\]\[\boxed{y = 3x - 7}\]

Condition for perpendicular lines

Two lines with gradients \(m_1\) and \(m_2\) are perpendicular if and only if \(m_1 \times m_2 = -1\), that is, \(m_2 = -\frac{1}{m_1}\) (negative reciprocals).
Worked exampleRoof line \(L_1\) passes through \((-6, 2)\) and \((-1, 4)\). Bracket line \(L_2\) passes through \((3, 5)\) and \((5, 0)\). Determine whether the bracket is perpendicular to the roof line.
\[\text{Gradient of } L_1 = \frac{4 - 2}{-1 - (-6)} = \frac{2}{5}\]\[\text{Gradient of } L_2 = \frac{0 - 5}{5 - 3} = \frac{-5}{2}\]\[\left(\frac{2}{5}\right) \times \left(\frac{-5}{2}\right) = -1\]Since the product of the gradients is \(-1\), \(\boxed{L_1 \text{ and } L_2 \text{ are perpendicular}}\).

Equation of a line perpendicular to a given line

To find the equation of a line perpendicular to a line with gradient \(m\), through a point \((x_1, y_1)\): use \(y - y_1 = \left(-\frac{1}{m}\right)(x - x_1)\), since the new line has gradient \(-\frac{1}{m}\).
Worked exampleA street is built perpendicular to an existing street with equation \(y = 0.5x + 3\), passing through point \(B(-1, -0.2)\). Find the equation of the new street.
Gradient of existing street \(m = 0.5\), so perpendicular gradient \(= -\frac{1}{0.5} = -2\)
\[y - (-0.2) = -2(x - (-1))\]\[y + 0.2 = -2x - 2\]\[\boxed{y = -2x - 2.2}\]
