The quadratic formula

For ax2 + bx + c = 0 (with a, b, c constants and a ≠ 0), x = [−b ± √(b2 − 4ac)] / 2a.
Worked exampleSolve 2x2 + 5x − 3 = 0.
a = 2, b = 5, c = −3
x = [−5 ± √(52 − 4 × 2 × (−3))] / (2 × 2) = [−5 ± √(25 + 24)] / 4 = [−5 ± √49] / 4 = [−5 ± 7] / 4
x = 2 / 4 = 0.5 or x = −12 / 4 = −3

The discriminant

Discriminant = b2 − 4ac. If b2 − 4ac > 0, the equation has two distinct real roots. If b2 − 4ac = 0, it has exactly one (repeated) real root. If b2 − 4ac < 0, it has no real roots.
Worked exampleUse the discriminant to describe the roots of each equation.
x2 − 5x + 6 = 0: b2 − 4ac = 25 − 24 = 1, which is > 0, so there are two distinct real roots (x = 2 and x = 3).
x2 − 4x + 4 = 0: b2 − 4ac = 16 − 16 = 0, so there is exactly one repeated real root (x = 2).
x2 + 2x + 5 = 0: b2 − 4ac = 4 − 20 = −16, which is < 0, so there are no real roots.

Completing the square

For x2 + bx + c = 0, rewrite as (x + b/2)2 − (b/2)2 + c = 0, then solve for x. If the coefficient of x2 is not 1, divide the whole equation by that coefficient first.
Worked exampleSolve x2 + 6x + 5 = 0 by completing the square.
x2 + 6x + 5 = (x + 3)2 − 9 + 5 = (x + 3)2 − 4
So (x + 3)2 − 4 = 0, giving (x + 3)2 = 4
x + 3 = ±2, so x = −1 or x = −5
Check with a non-monic equation: 2x2 − 12x + 10 = 0. Dividing by 2 gives x2 − 6x + 5 = 0, which is (x − 3)2 − 4 = 0, so x = 5 or x = 1.
