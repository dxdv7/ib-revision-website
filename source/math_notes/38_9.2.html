The quadratic formula

For \(ax^2 + bx + c = 0\) (with \(a\), \(b\), \(c\) constants and \(a \ne 0\)), \(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\).
Worked exampleSolve \(2x^2 + 5x - 3 = 0\).
\[a = 2, \quad b = 5, \quad c = -3\]\[x = \frac{-5 \pm \sqrt{5^2 - 4 \times 2 \times (-3)}}{2 \times 2}\]\[x = \frac{-5 \pm \sqrt{25 + 24}}{4}\]\[x = \frac{-5 \pm \sqrt{49}}{4}\]\[x = \frac{-5 \pm 7}{4}\]\[x = \frac{2}{4} = 0.5 \ \text{ or } \ x = \frac{-12}{4} = -3\]\[\boxed{x = 0.5 \text{ or } x = -3}\]

The discriminant

Discriminant \(= b^2 - 4ac\). If \(b^2 - 4ac > 0\), the equation has two distinct real roots. If \(b^2 - 4ac = 0\), it has exactly one (repeated) real root. If \(b^2 - 4ac < 0\), it has no real roots.
Worked exampleUse the discriminant to describe the roots of each equation.
\(x^2 - 5x + 6 = 0\): \(b^2 - 4ac = 25 - 24 = 1\), which is \(> 0\), so there are two distinct real roots (\(x = 2\) and \(x = 3\)).
\(x^2 - 4x + 4 = 0\): \(b^2 - 4ac = 16 - 16 = 0\), so there is exactly one repeated real root (\(x = 2\)).
\(x^2 + 2x + 5 = 0\): \(b^2 - 4ac = 4 - 20 = -16\), which is \(< 0\), so there are no real roots.

Completing the square

For \(x^2 + bx + c = 0\), rewrite as \(\left(x + \frac{b}{2}\right)^2 - \left(\frac{b}{2}\right)^2 + c = 0\), then solve for \(x\). If the coefficient of \(x^2\) is not 1, divide the whole equation by that coefficient first.
Worked exampleSolve \(x^2 + 6x + 5 = 0\) by completing the square.
\[x^2 + 6x + 5 = (x + 3)^2 - 9 + 5\]\[x^2 + 6x + 5 = (x + 3)^2 - 4\]So \((x + 3)^2 - 4 = 0\), giving \((x + 3)^2 = 4\)
\[x + 3 = \pm 2\]\[\boxed{x = -1 \text{ or } x = -5}\]Check with a non-monic equation: \(2x^2 - 12x + 10 = 0\). Dividing by 2 gives \(x^2 - 6x + 5 = 0\), which is \((x - 3)^2 - 4 = 0\), so \[\boxed{x = 5 \text{ or } x = 1}\]
