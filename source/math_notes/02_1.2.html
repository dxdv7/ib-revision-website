Rounding to a given number of decimal places

To round to n decimal places (dp), look at the digit immediately after the nth decimal place. If it is 5 or more, round the nth digit up. If it is less than 5, leave the nth digit as it is. All digits after the nth decimal place are then removed.
Worked exampleRound 12.6457 to 3 dp.
The 3rd decimal digit is 5, and the next digit is 7, which is ≥ 5, so round up.
12.6457 → 12.646 (3 dp)

Round 5.1996 to 2 dp.
The 2nd decimal digit is 9, and the next digit is 9, which is ≥ 5, so round up.
Rounding up the 9 causes it to carry over: 5.1996 → 5.20 (2 dp)

Identifying significant figures

Significant figures (sf) are the digits in a number that carry meaning for its precision. Rules: non-zero digits are always significant; zeros between two significant digits are always significant; leading zeros (before the first non-zero digit) are never significant; trailing zeros after a decimal point are significant; trailing zeros in a whole number with no decimal point shown are ambiguous.
Worked exampleState the number of significant figures in each measurement.
21.35 → 4 sf (all non-zero digits)
1009 → 4 sf (the zeros lie between two significant digits)
0.00300 → 3 sf (leading zeros are not significant; the trailing zeros after the decimal point are significant)
0.002 → 1 sf (all the zeros are leading zeros)

Rounding to a given number of significant figures

To round to n significant figures, identify the nth significant digit. If the digit immediately after it is 5 or more, add 1 to the nth digit; if it is less than 5, leave the nth digit unchanged. Digits after the nth significant figure are removed if they lie to the right of the decimal point, or replaced with zeros (as placeholders) if they lie to the left of the decimal point.
Worked exampleRound each number to the stated number of significant figures.
0.1235 to 2 sf: the 2nd sf is 2, the next digit is 3 < 5, so keep it unchanged → 0.12
0.2965 to 2 sf: the 2nd sf is 9, the next digit is 6 ≥ 5, so round up (9 becomes 10, carrying over) → 0.30
415.25 to 3 sf: the 3rd sf is 5, the next digit is 2 < 5, so keep it unchanged → 415
3050 to 2 sf: the 2nd sf is 0, the next digit is 5 ≥ 5, so round up, and the removed digits to the left of the decimal point become placeholder zeros → 3100

Ambiguous trailing zeros and standard form

A whole number ending in one or more zeros (with no decimal point shown) has an ambiguous number of significant figures, since the trailing zeros might be exact or might just be placeholders. Writing the number in standard form a × 10n, with 1 ≤ a < 10, removes the ambiguity: only the digits shown in a are treated as significant.
Worked exampleThe number 4500 has an ambiguous number of significant figures (it could be 2, 3 or 4 sf).
Written as 4.5 × 103, it clearly has 2 sf.
Written as 4.50 × 103, it clearly has 3 sf.
Written as 4.500 × 103, it clearly has 4 sf.

Rounding a calculated result to an appropriate precision

When a calculation uses a formula, carry full precision through every step and only round the final answer, to the number of decimal places or significant figures specified in the question.
Worked exampleA circle has radius 12.4 cm. Find its circumference and area, each correct to 1 dp.
Circumference: C = 2πr = 2 × π × 12.4 = 77.9115...
C = 77.9 cm (1 dp)
Area: A = πr² = π × 12.4² = 483.051...
A = 483.1 cm² (1 dp)

Find the value of (12.35 + 21.14 + 1.075) / √(3.5 − 1), correct to 3 sf.
Numerator = 34.565
Denominator = √2.5 = 1.58114...
34.565 / 1.58114... = 21.8608...
Final answer = 21.9 (3 sf)
