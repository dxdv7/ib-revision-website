Ranking data and tied ranks

To rank a set of data, order the values from largest to smallest (or smallest to largest — the same direction must be used for both variables in each pair) and label them \(1, 2, 3, \ldots, n\). If two or more values are equal, each tied value is given the mean of the ranks it would have occupied if the values had been slightly different.
Worked exampleFive contestants score the following in event \(X\): \(A = 34\), \(B = 28\), \(C = 34\), \(D = 41\), \(E = 22\).
Ranking from largest (rank 1) to smallest: \(D = 41\) is the largest, so \(D\) gets rank 1.
\(A\) and \(C\) are both 34, tied for what would be ranks 2 and 3, so each is given rank \(\dfrac{2+3}{2} = 2.5\).
\(B = 28\) is rank 4.
\(E = 22\) is rank 5.
\[\boxed{A = 2.5, \ B = 4, \ C = 2.5, \ D = 1, \ E = 5}\]

Spearman's rank correlation coefficient formula

\(r_s = 1 - \dfrac{6 \sum d^2}{n(n^2-1)}\), where \(d\) is the difference between the two ranks of each pair of values, and \(n\) is the number of pairs of data. This is the IB notation for the product moment correlation coefficient (PMCC) applied to ranks rather than raw data.
Worked exampleThe same five contestants score the following in event \(Y\): \(A = 65\), \(B = 52\), \(C = 78\), \(D = 70\), \(E = 60\).
Ranking \(Y\) from largest (rank 1) to smallest: \(C = 1\), \(D = 2\), \(A = 3\), \(E = 4\), \(B = 5\).
Using the \(X\) ranks found above (\(A = 2.5\), \(B = 4\), \(C = 2.5\), \(D = 1\), \(E = 5\)):
\[A: \ \text{rank } X = 2.5, \ \text{rank } Y = 3, \ d = -0.5, \ d^2 = 0.25\]\[B: \ \text{rank } X = 4, \ \text{rank } Y = 5, \ d = -1, \ d^2 = 1\]\[C: \ \text{rank } X = 2.5, \ \text{rank } Y = 1, \ d = 1.5, \ d^2 = 2.25\]\[D: \ \text{rank } X = 1, \ \text{rank } Y = 2, \ d = -1, \ d^2 = 1\]\[E: \ \text{rank } X = 5, \ \text{rank } Y = 4, \ d = 1, \ d^2 = 1\]\[\sum d^2 = 0.25 + 1 + 2.25 + 1 + 1 = 5.5, \quad n = 5\]\[\boxed{r_s = 1 - \frac{6 \times 5.5}{5(5^2-1)} = 1 - \frac{33}{120} = 1 - 0.275 = 0.725}\]This shows a strong, positive correlation between the two sets of scores.

Interpreting rs

\(r_s\) takes values from \(-1\) to \(1\) and is interpreted using the same scale of direction and strength as Pearson's product moment correlation coefficient: values close to \(1\) or \(-1\) show a strong monotonic relationship (consistently increasing or consistently decreasing), and values close to \(0\) show a weak or no monotonic relationship.
Worked exampleTwo examiners rank 6 essays from 1 (best) to 6 (worst).
Examiner A's ranks: \(1, 2, 3, 4, 5, 6\)
Examiner B's ranks for the same essays: \(1, 3, 2, 4, 6, 5\)
\[d \text{ values}: \ 0, -1, 1, 0, -1, 1 \quad \Rightarrow \quad d^2 \text{ values}: \ 0, 1, 1, 0, 1, 1\]\[\sum d^2 = 4, \quad n = 6\]\[\boxed{r_s = 1 - \frac{6 \times 4}{6(6^2-1)} = 1 - \frac{24}{210} = 1 - 0.114 = 0.886}\]This is a strong, positive correlation — the two examiners ranked the essays very similarly.
