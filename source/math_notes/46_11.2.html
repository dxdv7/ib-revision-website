Amplitude and principal axis of a sinusoidal function

For f(x) = a sin(bx) + d or g(x) = a cos(bx) + d with range min ≤ y ≤ max, the amplitude is |a| (the vertical distance from the principal axis to a maximum or minimum), and the principal axis is the horizontal line y = d.
Worked exampleState the amplitude and the equation of the principal axis of h(x) = 3sin(2x) − 2.
Amplitude = |a| = |3| = 3
Principal axis: y = d = −2

Effect of the parameter a: vertical stretch and reflection

In f(x) = a sin(bx) + d, increasing |a| stretches the graph vertically away from the principal axis (increasing the amplitude), while decreasing |a| compresses it. If a is negative, the graph is reflected in the principal axis compared with the same function with positive a, but the amplitude itself, |a|, is unchanged.
Worked exampleCompare y = −20cos(3x) with y = 20cos(3x). State the amplitude of y = −20cos(3x) and describe the transformation.
Amplitude = |−20| = 20
Since a = −20 is negative, the graph of y = −20cos(3x) is a reflection of y = 20cos(3x) in the principal axis (the x-axis here); the amplitude, 20, is the same for both

Effect of the parameter b: horizontal stretch and period

In f(x) = a sin(bx) + d (with x in degrees), the period is 360° / b. Increasing b compresses the graph horizontally (shorter period, more cycles in the same interval), while decreasing b (with b > 0) stretches the graph horizontally (longer period).
Worked exampleFind the period of y = −20cos(3x), and compare it with the period of y = cos(x).
Period of y = −20cos(3x) = 360° / 3 = 120°
Period of y = cos(x) = 360° / 1 = 360°
Since b = 3 > 1, the graph of y = −20cos(3x) is compressed horizontally compared with y = cos(x), completing a full cycle in 120° instead of 360°

Effect of the parameter d: vertical translation

In f(x) = a sin(bx) + d, changing d translates the entire graph vertically by d units, without affecting the amplitude or the period. The principal axis moves from y = 0 to y = d.
Worked exampleCompare y = 2sin(3x) and y = 2sin(3x) + 1. Describe the transformation and state the new principal axis.
Adding 1 translates the graph of y = 2sin(3x) vertically upward by 1 unit
Principal axis moves from y = 0 to y = 1
Amplitude remains 2 and period remains 360° / 3 = 120° for both

Identifying amplitude, period and principal axis together from a, b and d

For f(x) = a sin(bx) + d or g(x) = a cos(bx) + d, amplitude = |a|, period = 360° / b, and principal axis y = d, are three independent properties, each controlled by a different parameter.
Worked exampleState the amplitude, period and principal axis of y = 3.7sin(2x) − 2.
Amplitude = |3.7| = 3.7
Period = 360° / 2 = 180°
Principal axis: y = −2
Worked exampleState the amplitude, period and principal axis of y = −1.6cos(0.25x) + 5.
Amplitude = |−1.6| = 1.6
Period = 360° / 0.25 = 1440°
Principal axis: y = 5

Finding unknown parameters from a described transformation

Given a sinusoidal function y = a cos(bx) + d (or a sin(bx) + d) and its maximum and minimum values with the locations of turning points, use amplitude = (max − min) / 2 for |a|, principal axis d = (max + min) / 2, and the horizontal distance between consecutive maximum and minimum points equal to half the period to find b.
Worked exampleA function of the form y = a cos(bx) + d has a maximum of 4 at x = 0 and a minimum of −2 at x = 90°. Find a, b and d.
d = (4 + (−2)) / 2 = 2 / 2 = 1
|a| = (4 − (−2)) / 2 = 6 / 2 = 3, and since y = a cos(bx) + d starts at a maximum when x = 0, a = 3
Half the period = 90° − 0° = 90°, so period = 180°
b = 360° / 180° = 2

Comparing multiple sinusoidal functions using radians

The same sinusoidal function can be written with x measured in radians instead of degrees. For f(x) = a sin(bx) + d with x in radians, the period is 2π / b (instead of 360° / b), while the amplitude |a| and principal axis y = d are unchanged.
Worked exampleFind the period of y = 5sin(4x) when x is measured in radians, and compare it with the period of y = 5sin(x).
Period of y = 5sin(4x) = 2π / 4 = π / 2 ≈ 1.57 radians
Period of y = 5sin(x) = 2π / 1 = 2π ≈ 6.28 radians
The graph of y = 5sin(4x) completes a cycle four times faster than y = 5sin(x), consistent with b = 4
