Amplitude and principal axis of a sinusoidal function

For \(f(x) = a \sin(bx) + d\) or \(g(x) = a \cos(bx) + d\) with range \(\min \le y \le \max\), the amplitude is \(|a|\) (the vertical distance from the principal axis to a maximum or minimum), and the principal axis is the horizontal line \(y = d\).
Worked exampleState the amplitude and the equation of the principal axis of \(h(x) = 3\sin(2x) - 2\).
\[\text{Amplitude} = |a| = |3| = \boxed{3}\]\[\text{Principal axis: } \boxed{y = -2}\]

Effect of the parameter a: vertical stretch and reflection

In \(f(x) = a \sin(bx) + d\), increasing \(|a|\) stretches the graph vertically away from the principal axis (increasing the amplitude), while decreasing \(|a|\) compresses it. If \(a\) is negative, the graph is reflected in the principal axis compared with the same function with positive \(a\), but the amplitude itself, \(|a|\), is unchanged.
Worked exampleCompare \(y = -20\cos(3x)\) with \(y = 20\cos(3x)\). State the amplitude of \(y = -20\cos(3x)\) and describe the transformation.
\[\text{Amplitude} = |-20| = \boxed{20}\]Since \(a = -20\) is negative, the graph of \(y = -20\cos(3x)\) is a reflection of \(y = 20\cos(3x)\) in the principal axis (the x-axis here); the amplitude, 20, is the same for both

Effect of the parameter b: horizontal stretch and period

In \(f(x) = a \sin(bx) + d\) (with \(x\) in degrees), the period is \(\dfrac{360^{\circ}}{b}\). Increasing \(b\) compresses the graph horizontally (shorter period, more cycles in the same interval), while decreasing \(b\) (with \(b > 0\)) stretches the graph horizontally (longer period).
Worked exampleFind the period of \(y = -20\cos(3x)\), and compare it with the period of \(y = \cos(x)\).
\[\text{Period of } y = -20\cos(3x) = \frac{360^{\circ}}{3} = \boxed{120^{\circ}}\]\[\text{Period of } y = \cos(x) = \frac{360^{\circ}}{1} = 360^{\circ}\]Since \(b = 3 > 1\), the graph of \(y = -20\cos(3x)\) is compressed horizontally compared with \(y = \cos(x)\), completing a full cycle in \(120^{\circ}\) instead of \(360^{\circ}\)

Effect of the parameter d: vertical translation

In \(f(x) = a \sin(bx) + d\), changing \(d\) translates the entire graph vertically by \(d\) units, without affecting the amplitude or the period. The principal axis moves from \(y = 0\) to \(y = d\).
Worked exampleCompare \(y = 2\sin(3x)\) and \(y = 2\sin(3x) + 1\). Describe the transformation and state the new principal axis.
Adding 1 translates the graph of \(y = 2\sin(3x)\) vertically upward by 1 unit
\[\text{Principal axis moves from } y = 0 \text{ to } \boxed{y = 1}\]Amplitude remains 2 and period remains \(\dfrac{360^{\circ}}{3} = 120^{\circ}\) for both

Identifying amplitude, period and principal axis together from a, b and d

For \(f(x) = a \sin(bx) + d\) or \(g(x) = a \cos(bx) + d\), amplitude \(= |a|\), period \(= \dfrac{360^{\circ}}{b}\), and principal axis \(y = d\), are three independent properties, each controlled by a different parameter.
Worked exampleState the amplitude, period and principal axis of \(y = 3.7\sin(2x) - 2\).
\[\text{Amplitude} = |3.7| = \boxed{3.7}\]\[\text{Period} = \frac{360^{\circ}}{2} = \boxed{180^{\circ}}\]\[\text{Principal axis: } \boxed{y = -2}\]
Worked exampleState the amplitude, period and principal axis of \(y = -1.6\cos(0.25x) + 5\).
\[\text{Amplitude} = |-1.6| = \boxed{1.6}\]\[\text{Period} = \frac{360^{\circ}}{0.25} = \boxed{1440^{\circ}}\]\[\text{Principal axis: } \boxed{y = 5}\]

Finding unknown parameters from a described transformation

Given a sinusoidal function \(y = a \cos(bx) + d\) (or \(a \sin(bx) + d\)) and its maximum and minimum values with the locations of turning points, use \(\text{amplitude} = \dfrac{\max - \min}{2}\) for \(|a|\), principal axis \(d = \dfrac{\max + \min}{2}\), and the horizontal distance between consecutive maximum and minimum points equal to half the period to find \(b\).
Worked exampleA function of the form \(y = a \cos(bx) + d\) has a maximum of 4 at \(x = 0\) and a minimum of \(-2\) at \(x = 90^{\circ}\). Find \(a\), \(b\) and \(d\).
\[d = \frac{4 + (-2)}{2} = \frac{2}{2} = 1\]\[|a| = \frac{4 - (-2)}{2} = \frac{6}{2} = 3, \text{ and since } y = a \cos(bx) + d \text{ starts at a maximum when } x = 0, a = 3\]\[\text{Half the period} = 90^{\circ} - 0^{\circ} = 90^{\circ}, \text{ so period} = 180^{\circ}\]\[b = \frac{360^{\circ}}{180^{\circ}} = 2\]Final answer: \(\boxed{a = 3, \ b = 2, \ d = 1}\)

Comparing multiple sinusoidal functions using radians

The same sinusoidal function can be written with \(x\) measured in radians instead of degrees. For \(f(x) = a \sin(bx) + d\) with \(x\) in radians, the period is \(\dfrac{2\pi}{b}\) (instead of \(\dfrac{360^{\circ}}{b}\)), while the amplitude \(|a|\) and principal axis \(y = d\) are unchanged.
Worked exampleFind the period of \(y = 5\sin(4x)\) when \(x\) is measured in radians, and compare it with the period of \(y = 5\sin(x)\).
\[\text{Period of } y = 5\sin(4x) = \frac{2\pi}{4} = \frac{\pi}{2} \approx 1.57 \text{ radians}\]\[\text{Period of } y = 5\sin(x) = \frac{2\pi}{1} = 2\pi \approx 6.28 \text{ radians}\]The graph of \(y = 5\sin(4x)\) completes a cycle four times faster than \(y = 5\sin(x)\), consistent with \(b = 4\)
