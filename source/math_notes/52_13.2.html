Power rule for integration

∫ axn dx = (axn+1) / (n+1) + C, where a and n are constants, a ≠ 0, n ≠ −1, and C is the constant of integration.
Worked examplea Find ∫ 6x2 dx.
∫ 6x2 dx = 6x3/3 + C = 2x3 + C
b Find ∫ 4x−3 dx.
∫ 4x−3 dx = 4x−2/(−2) + C = −2x−2 + C = −2/x2 + C

Integrating a sum of terms

∫ [f(x) + g(x)] dx = ∫ f(x) dx + ∫ g(x) dx. Integrate each term separately using the power rule, then add a single constant of integration, C.
Worked exampleFind ∫ (3x2 − 4x + 5) dx.
∫ 3x2 dx = x3
∫ −4x dx = −2x2
∫ 5 dx = 5x
∫ (3x2 − 4x + 5) dx = x3 − 2x2 + 5x + C

Evaluating a definite integral

∫ab f(x) dx = F(b) − F(a), where F is any antiderivative of f, i.e. F′(x) = f(x).
Worked exampleEvaluate ∫13 (2x + 1) dx.
An antiderivative is F(x) = x2 + x
F(3) = 32 + 3 = 12
F(1) = 12 + 1 = 2
∫13 (2x + 1) dx = F(3) − F(1) = 12 − 2 = 10

Area under a curve using integration

If f(x) ≥ 0 for a ≤ x ≤ b, the area enclosed between the curve y = f(x), the x-axis, and the vertical lines x = a and x = b is given by Area = ∫ab f(x) dx.
Worked exampleFind the area enclosed between the curve y = x2 + 1, the x-axis, and the vertical lines x = 1 and x = 3.
Area = ∫13 (x2 + 1) dx
An antiderivative is F(x) = x3/3 + x
F(3) = 27/3 + 3 = 9 + 3 = 12
F(1) = 1/3 + 1 = 4/3
Area = F(3) − F(1) = 12 − 4/3 = 32/3 = 10.67 units2 (2 dp)
