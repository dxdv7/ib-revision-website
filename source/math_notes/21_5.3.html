Common difference of an arithmetic sequence

A sequence is arithmetic if the difference between each term and the previous term is constant. This constant is called the common difference, d, and is found using d = un+1 − un for any n.
Worked exampleAn arithmetic sequence begins 8, 5, 2, −1, ...
d = 5 − 8 = −3 (checking: 2 − 5 = −3 and −1 − 2 = −3, so the common difference is −3)

The nth term of an arithmetic sequence

un = u1 + (n − 1)d, where u1 is the first term, d is the common difference, and n is the term number (n ∈ Z+).
Worked exampleAn arithmetic sequence has first term u1 = 4 and common difference d = 6.
Find the 15th term: u15 = 4 + (15 − 1)(6) = 4 + 84 = 88
Determine whether 172 is a term of the sequence: solve 4 + (n − 1)(6) = 172, giving (n − 1) = 28, so n = 29. Since n = 29 is a positive integer, 172 is the 29th term of the sequence.

Sum of the first n terms of an arithmetic sequence

Sn = (n / 2)(2u1 + (n − 1)d), which is equivalent to Sn = (n / 2)(u1 + un), where u1 is the first term, un is the nth term, d is the common difference, and n is the number of terms.
Worked exampleFind the sum of the first 20 terms of the arithmetic sequence with first term 4 and common difference 6.
S20 = (20 / 2)(2(4) + (20 − 1)(6)) = 10(8 + 114) = 10(122) = 1220
Check using the second form: u20 = 4 + (19)(6) = 118, so S20 = (20 / 2)(4 + 118) = 10(122) = 1220

Sigma notation for a series

The sum of the first n terms of a sequence can be written using sigma notation as Sn = the sum, from i = 1 to i = n, of ui (written u1 + u2 + u3 + ... + un), where the Greek letter used for "sum" indicates each term ui is added as i runs from 1 to n.
Worked exampleEvaluate the sum, from i = 1 to i = 5, of (3i + 2).
Substituting i = 1, 2, 3, 4, 5 gives the terms 5, 8, 11, 14, 17 (an arithmetic sequence with u1 = 5 and d = 3).
Sum = 5 + 8 + 11 + 14 + 17 = 55
Check using the series formula: S5 = (5 / 2)(2(5) + (5 − 1)(3)) = 2.5(10 + 12) = 2.5(22) = 55
