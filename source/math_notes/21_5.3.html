Common difference of an arithmetic sequence

A sequence is arithmetic if the difference between each term and the previous term is constant. This constant is called the common difference, \(d\), and is found using
\[d = u_{n+1} - u_n\]for any \(n\).
Worked exampleAn arithmetic sequence begins \(8, 5, 2, -1, \ldots\)
\[d = 5 - 8 = -3\]Checking: \(2-5=-3\) and \(-1-2=-3\), so
\[\boxed{d = -3}\]

The nth term of an arithmetic sequence

\[u_n = u_1 + (n-1)d\]where \(u_1\) is the first term, \(d\) is the common difference, and \(n\) is the term number (\(n \in \mathbb{Z}^+\)).
Worked exampleAn arithmetic sequence has first term \(u_1 = 4\) and common difference \(d = 6\).
Find the 15th term:
\[u_{15} = 4 + (15-1)(6) = 4 + 84 = \boxed{88}\]Determine whether 172 is a term of the sequence: solve
\[4 + (n-1)(6) = 172\]\[n - 1 = 28\]\[\boxed{n = 29}\]Since \(n = 29\) is a positive integer, 172 is the 29th term of the sequence.

Sum of the first n terms of an arithmetic sequence

\[S_n = \frac{n}{2}\big(2u_1 + (n-1)d\big)\]which is equivalent to
\[S_n = \frac{n}{2}(u_1 + u_n)\]where \(u_1\) is the first term, \(u_n\) is the \(n\)th term, \(d\) is the common difference, and \(n\) is the number of terms.
Worked exampleFind the sum of the first 20 terms of the arithmetic sequence with first term 4 and common difference 6.
\[S_{20} = \frac{20}{2}\big(2(4) + (20-1)(6)\big) = 10(8+114) = \boxed{1220}\]Check using the second form:
\[u_{20} = 4 + (19)(6) = 118\]\[S_{20} = \frac{20}{2}(4+118) = 10(122) = 1220\]

Sigma notation for a series

The sum of the first \(n\) terms of a sequence can be written using sigma notation as
\[S_n = \sum_{i=1}^{n} u_i\]written out, this is \(u_1 + u_2 + u_3 + \cdots + u_n\): each term \(u_i\) is added as \(i\) runs from 1 to \(n\).
Worked exampleEvaluate
\[\sum_{i=1}^{5}(3i+2)\]Substituting \(i = 1, 2, 3, 4, 5\) gives the terms 5, 8, 11, 14, 17 (an arithmetic sequence with \(u_1 = 5\) and \(d = 3\)).
\[5+8+11+14+17 = \boxed{55}\]Check using the series formula:
\[S_5 = \frac{5}{2}\big(2(5)+(5-1)(3)\big) = 2.5(10+12) = 55\]
