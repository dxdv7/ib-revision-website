Function notation and evaluating f(x)

For a function \(f\), the notation \(y = f(x)\) means that \(x\) (an element of the domain, the input) is mapped by \(f\) to \(y\) (an element of the range, the output). To evaluate \(f\) at a given input, substitute that value for \(x\) everywhere it appears in the formula.
Worked exampleGiven \(f(x) = 2x^2 - 3x + 1\), find \(f(4)\).
\[f(4) = 2(4)^2 - 3(4) + 1\]\[f(4) = 2(16) - 12 + 1\]\[\boxed{f(4) = 21}\]

Classifying a relation as a function

A relation is a set of ordered pairs. A function is a relation in which every element of the domain (input) is mapped onto exactly one element of the range (output). A relation can be one-to-one, many-to-one, one-to-many, or many-to-many; only one-to-one and many-to-one relations are functions.
Worked exampleClassify the relation \(\{(1,2), (2,3), (1,4)\}\).
The input 1 is mapped to two different outputs, 2 and 4.
This is a one-to-many relation.
Since input 1 does not map to exactly one output, this relation is NOT a function.

Domain and range of a function

The domain of a function is the set of all possible input (\(x\)) values. The range of a function is the set of all possible output (\(y\)) values produced by the function on that domain.
Worked exampleA function is defined by \(y = 2x - 1\), for \(-3 \le x \le 2\). Find its domain and range.
Domain is given directly: \(-3 \le x \le 2\)
\[f(-3) = 2(-3) - 1 = -7\]\[f(2) = 2(2) - 1 = 3\]Since the function is increasing:
\[\boxed{-7 \le y \le 3}\]

The vertical line test

If every vertical line drawn on the graph of a relation cuts the graph at most once, the relation is a function. If any vertical line cuts the graph more than once, the relation is not a function, because that input would have more than one output.
Worked exampleDoes the relation \(x^2 + y^2 = 25\) pass the vertical line test at \(x = 3\)?
Substitute \(x = 3\):
\[y^2 = 25 - 9 = 16\]\[y = 4 \text{ or } y = -4\]Since \(x = 3\) gives two outputs, the vertical line \(x = 3\) cuts the graph twice.
This relation FAILS the vertical line test, so it is NOT a function.

Domain restrictions for algebraic functions

For a function defined by a formula, the largest possible domain excludes any \(x\)-value that makes the formula undefined. Common restrictions: the denominator of a fraction cannot equal zero, and the expression under a square root cannot be negative.
Worked exampleFind the largest possible domain of \(f(x) = \sqrt{x - 5}\).
The expression under the square root cannot be negative:
\[x - 5 \ge 0\]\[\boxed{x \ge 5}\]

Finding the inverse of a function algebraically

To find the inverse \(f^{-1}\) of a function \(f\): write \(y = f(x)\), swap \(x\) and \(y\), then solve the resulting equation for \(y\). The result is \(y = f^{-1}(x)\). The domain of \(f\) becomes the range of \(f^{-1}\), and the range of \(f\) becomes the domain of \(f^{-1}\).
Worked exampleFind the inverse of \(f(x) = 3x - 4\).
\[y = 3x - 4\]\[x = 3y - 4\]\[x + 4 = 3y\]\[\boxed{f^{-1}(x) = \frac{x+4}{3}}\]Check:
\[f(f^{-1}(x)) = 3\left(\frac{x+4}{3}\right) - 4 = (x+4) - 4 = x \checkmark\]
