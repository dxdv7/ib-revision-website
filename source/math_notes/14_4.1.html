Distance between two points in 2D

\[d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]the distance between points \(A(x_1, y_1)\) and \(B(x_2, y_2)\).
Worked exampleFind the distance between \(A(4, -3)\) and \(B(-1.5, 5)\).
\[d = \sqrt{(-1.5 - 4)^2 + (5 - (-3))^2}\]\[d = \sqrt{(-5.5)^2 + (8)^2}\]\[d = \sqrt{30.25 + 64}\]\[d = \sqrt{94.25}\]\[\boxed{d = 9.71 \text{ (3 sf)}}\]

Midpoint of two points in 2D

\[M = \left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)\]the midpoint of the segment joining \(A(x_1, y_1)\) and \(B(x_2, y_2)\).
Worked examplePoints \(A(-3, 5)\) and \(B(0, 7)\) lie on the diameter of a circle. Find the coordinates of the centre.
The centre is the midpoint \(M\) of \([AB]\).
\[M = \left(\frac{-3 + 0}{2}, \frac{5 + 7}{2}\right)\]\[\boxed{M = (-1.5, 6)}\]

Finding an unknown coordinate using the midpoint formula

If \(M(x_M, y_M)\) is the midpoint of \(A(x_1, y_1)\) and \(B(x_2, y_2)\), then \(x_M = \frac{x_1 + x_2}{2}\) and \(y_M = \frac{y_1 + y_2}{2}\) can each be solved for an unknown coordinate.
Worked example\(M(2, 4)\) is the midpoint of \(A(x, 1)\) and \(B(7, 7)\). Find \(x\).
Using the \(x\)-coordinate formula:
\[\frac{x + 7}{2} = 2\]\[x + 7 = 4\]\[\boxed{x = -3}\]Check with the \(y\)-coordinate:
\[\frac{1 + 7}{2} = 4\]which matches \(y_M = 4\)

Distance between two points in 3D

\[d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}\]the distance between points \(A(x_1, y_1, z_1)\) and \(B(x_2, y_2, z_2)\).
Worked exampleA storage box has vertices including \(B(0, 3, 4)\) and \(R(2, 0, 0)\), all coordinates in metres. Find the length of diagonal \(BR\), the maximum length of a tool that fits in the box.
\[BR = \sqrt{(2 - 0)^2 + (0 - 3)^2 + (0 - 4)^2}\]\[BR = \sqrt{4 + 9 + 16}\]\[BR = \sqrt{29}\]\[\boxed{BR = 5.39 \text{ m (3 sf)}}\]

Midpoint of two points in 3D

\[M = \left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}, \frac{z_1 + z_2}{2}\right)\]the midpoint of the segment joining \(A(x_1, y_1, z_1)\) and \(B(x_2, y_2, z_2)\).
Worked exampleA cuboid has a diagonal with endpoints \(A(4, 0, 0)\) and \(C_1(0, 5, 2)\), coordinates in metres. Find the midpoint \(M\) of this diagonal.
\[M = \left(\frac{4 + 0}{2}, \frac{0 + 5}{2}, \frac{0 + 2}{2}\right)\]\[\boxed{M = (2, 2.5, 1)}\]
