Angle of elevation

The angle of elevation, θ, is the angle above the horizontal from an observer up to an object. Using right-angled trigonometry, tan θ = opposite / adjacent = height / horizontal distance.
Worked exampleAn observer stands 40 m from the base of a tree. The angle of elevation to the top of the tree is 32°. Find the height of the tree.
tan 32° = height / 40
height = 40 × tan 32°
height = 40 × 0.6249
height ≈ 25.0 m (3 sf)

Angle of depression

The angle of depression, θ, is the angle below the horizontal from an observer down to an object. It is measured using the same right-angled trigonometry: tan θ = opposite / adjacent = height (of the observer above the object) / horizontal distance. The angle of depression from the observer equals the angle of elevation from the object back to the observer (alternate angles between parallel horizontal lines).
Worked exampleFrom the top of a cliff, the angle of depression to a boat is 25°. The boat is 200 m from the base of the cliff. Find the height of the cliff.
tan 25° = height / 200
height = 200 × tan 25°
height = 200 × 0.4663
height ≈ 93.3 m (3 sf)

Combining elevation and depression from one point

When an observer at height h above the ground sees the base of an object at an angle of depression θ1 and the top of the object at an angle of elevation θ2, first use tan θ1 = h / d to find the horizontal distance d, then use tan θ2 = x / d to find the extra height x above the observer's eye level. The total height of the object is x + h.
Worked exampleFrom a window 6.5 m above the ground, the angle of depression to the base of a building across the street is 18°, and the angle of elevation to the top of the same building is 55°. Find the height of the building.
Horizontal distance: tan 18° = 6.5 / d, so d = 6.5 / tan 18° = 20.0049 m (unrounded)
Extra height above window: tan 55° = x / d, so x = 20.0049 × tan 55° = 28.57 m (2 dp)
Total height = 28.57 + 6.5 = 35.07 m (2 dp) — keep the unrounded value of d in the second step to avoid losing accuracy
