Combinations, nCr

\(\binom{n}{r} = \dfrac{n!}{r!(n-r)!}\), where \(n! = n \times (n-1) \times (n-2) \times \ldots \times 2 \times 1\), and \(\binom{n}{r}\) counts the number of ways to choose \(r\) successes from \(n\) trials.
Worked exampleCalculate \(\binom{6}{2}\).
\[\boxed{\binom{6}{2} = \frac{6!}{2! \times 4!} = \frac{6 \times 5}{2 \times 1} = \frac{30}{2} = 15}\]

Binomial probability distribution: P(X = x)

If \(X \sim B(n, p)\), then \(P(X = x) = \binom{n}{x} p^x (1-p)^{n-x}\), for \(x = 0, 1, 2, \ldots, n\), where \(n\) is the fixed number of independent trials, \(p\) is the constant probability of success on each trial, and \(x\) is the number of successes.
Worked exampleA multiple-choice quiz has 8 questions, each with 4 equally likely options. \(X\) is the number of correct guesses, so \(X \sim B(8, 0.25)\). Find \(P(X = 3)\).
\[P(X = 3) = \binom{8}{3} \times 0.25^3 \times 0.75^5\]\[\binom{8}{3} = 56, \ 0.25^3 = 0.015625, \ 0.75^5 = 0.2373046875\]\[\boxed{P(X = 3) = 56 \times 0.015625 \times 0.2373046875 = 0.208 \ (3 \text{ sf})}\]

Cumulative binomial probability

\(P(X \le x) = P(X = 0) + P(X = 1) + \ldots + P(X = x)\), found by summing the individual binomial probabilities from 0 up to \(x\).
Worked example\(X \sim B(5, 0.4)\). Find \(P(X \le 2)\).
\[P(X = 0) = 0.6^5 = 0.07776\]\[P(X = 1) = \binom{5}{1} \times 0.4 \times 0.6^4 = 5 \times 0.4 \times 0.1296 = 0.2592\]\[P(X = 2) = \binom{5}{2} \times 0.4^2 \times 0.6^3 = 10 \times 0.16 \times 0.216 = 0.3456\]\[\boxed{P(X \le 2) = 0.07776 + 0.2592 + 0.3456 = 0.683 \ (3 \text{ sf})}\]

Mean of a binomial distribution

If \(X \sim B(n, p)\), then \(E(X) = \mu = n \times p\).
Worked example\(X \sim B(20, 0.25)\). Find \(E(X)\).
\[\boxed{E(X) = 20 \times 0.25 = 5}\]

Variance and standard deviation of a binomial distribution

If \(X \sim B(n, p)\), then \(Var(X) = n \times p \times (1-p)\), and the standard deviation is \(\sqrt{Var(X)} = \sqrt{n \times p \times (1-p)}\).
Worked example\(X \sim B(15, 0.6)\). Find the variance and standard deviation of \(X\).
\[Var(X) = 15 \times 0.6 \times 0.4 = 3.6\]\[\boxed{\text{Standard deviation} = \sqrt{3.6} = 1.90 \ (3 \text{ sf})}\]
