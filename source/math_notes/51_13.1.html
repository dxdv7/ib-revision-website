Rectangle (strip) approximation: lower and upper bounds

The area under a curve on \([a, b]\) can be approximated by dividing it into \(n\) rectangles of equal width \(w = \dfrac{b - a}{n}\). Using the smaller height on each strip gives a lower bound estimate; using the larger height on each strip gives an upper bound estimate. The true area \(A\) satisfies \(\text{lower bound} \le A \le \text{upper bound}\).
Worked exampleEstimate the area under \(f(x) = x^2 + 1\) between \(x = 0\) and \(x = 2\) using 2 rectangles of width 1.
Heights at \(x = 0, 1, 2\): \(f(0) = 1\), \(f(1) = 2\), \(f(2) = 5\)
Lower bound (left-hand heights) \[= 1(1) + 1(2) = 3\]Upper bound (right-hand heights) \[= 1(2) + 1(5) = 7\]\[\boxed{3 \le A \le 7}\]

Area of a single trapezoid

Area \(= \dfrac{1}{2}(b_1 + b_2) \times h\), where \(b_1\) and \(b_2\) are the lengths of the two parallel sides (the function values at the two endpoints) and \(h\) is the distance between them (the width of the interval).
Worked exampleFind the area under \(f(x) = -x + 6\) between \(x = 1\) and \(x = 4\).
\[b_1 = f(1) = -1 + 6 = 5\]\[b_2 = f(4) = -4 + 6 = 2\]\[h = 4 - 1 = 3\]\[\text{Area} = \frac{1}{2}(5 + 2) \times 3 = \frac{1}{2}(7)(3)\]\[\boxed{\text{Area} = 10.5}\]

The trapezoidal rule (n strips)

Area \(\approx \dfrac{h}{2} \times [y_0 + y_n + 2(y_1 + y_2 + \ldots + y_{n-1})]\), where the interval \([a, b]\) is divided into \(n\) strips of equal width \(h = \dfrac{b - a}{n}\), and \(y_0, y_1, \ldots, y_n\) are the function values at the \(n + 1\) equally spaced \(x\)-values, with \(y_0\) and \(y_n\) the end values and \(y_1\) to \(y_{n-1}\) the interior values.
Worked exampleEstimate the area under \(f(x) = e^x\) over \(0 \le x \le 1\) using 5 trapezoids.
\[h = \frac{1 - 0}{5} = 0.2\]\[y_0 = f(0) = 1, \ y_1 = f(0.2) = 1.2214, \ y_2 = f(0.4) = 1.4918, \ y_3 = f(0.6) = 1.8221, \ y_4 = f(0.8) = 2.2255, \ y_5 = f(1) = 2.7183\]\[\text{Area} \approx \frac{0.2}{2}[1 + 2.7183 + 2(1.2214 + 1.4918 + 1.8221 + 2.2255)]\]\[= 0.1 \times [3.7183 + 2(6.7608)] = 0.1 \times [3.7183 + 13.5216]\]\[= 0.1 \times 17.2399\]\[\boxed{\text{Area} \approx 1.72 \text{ (3 sf)}}\]
