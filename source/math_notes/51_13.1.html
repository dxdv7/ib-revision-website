Rectangle (strip) approximation: lower and upper bounds

The area under a curve on [a, b] can be approximated by dividing it into n rectangles of equal width w = (b − a) / n. Using the smaller height on each strip gives a lower bound estimate; using the larger height on each strip gives an upper bound estimate. The true area A satisfies lower bound ≤ A ≤ upper bound.
Worked exampleEstimate the area under f(x) = x2 + 1 between x = 0 and x = 2 using 2 rectangles of width 1.
Heights at x = 0, 1, 2: f(0) = 1, f(1) = 2, f(2) = 5
Lower bound (left-hand heights) = 1(1) + 1(2) = 3
Upper bound (right-hand heights) = 1(2) + 1(5) = 7
So 3 ≤ A ≤ 7

Area of a single trapezoid

Area = (1/2)(b1 + b2) × h, where b1 and b2 are the lengths of the two parallel sides (the function values at the two endpoints) and h is the distance between them (the width of the interval).
Worked exampleFind the area under f(x) = −x + 6 between x = 1 and x = 4.
b1 = f(1) = −1 + 6 = 5
b2 = f(4) = −4 + 6 = 2
h = 4 − 1 = 3
Area = (1/2)(5 + 2) × 3 = (1/2)(7)(3) = 10.5

The trapezoidal rule (n strips)

Area ≈ (h/2) × [y0 + yn + 2(y1 + y2 + ... + yn−1)], where the interval [a, b] is divided into n strips of equal width h = (b − a) / n, and y0, y1, ..., yn are the function values at the n + 1 equally spaced x-values, with y0 and yn the end values and y1 to yn−1 the interior values.
Worked exampleEstimate the area under f(x) = ex over 0 ≤ x ≤ 1 using 5 trapezoids.
h = (1 − 0) / 5 = 0.2
y0 = f(0) = 1, y1 = f(0.2) = 1.2214, y2 = f(0.4) = 1.4918, y3 = f(0.6) = 1.8221, y4 = f(0.8) = 2.2255, y5 = f(1) = 2.7183
Area ≈ (0.2/2)[1 + 2.7183 + 2(1.2214 + 1.4918 + 1.8221 + 2.2255)]
= 0.1 × [3.7183 + 2(6.7608)] = 0.1 × [3.7183 + 13.5216] = 0.1 × 17.2399 = 1.72 (3 sf)
