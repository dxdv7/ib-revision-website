The derivative as the gradient of a tangent

The gradient of a secant (chord) joining two points on a curve gives the average rate of change between them. As the second point moves closer to the first, the gradient of the secant approaches the gradient of the tangent at that point — this is the instantaneous rate of change. The derivative of f(x), giving the gradient of the tangent at any point x, is denoted f′(x) or dy/dx. For a linear function, the derivative of y = mx is m, and the derivative of y = c (a constant) is 0.
Worked exampleState the derivative (gradient) of the functions y = 7 and y = −5x.
y = 7 is a constant function (y = c with c = 7), so its derivative is dy/dx = 0 — the line is horizontal.
y = −5x is of the form y = mx with m = −5, so its derivative is dy/dx = −5 — the constant gradient of the line.

The power rule for differentiation

If f(x) = axn, then f′(x) = anxn−1, where a is a constant coefficient and n is an integer. To find the gradient of the curve at a specific point, substitute the x-value into f′(x).
Worked exampleFind the derivative of f(x) = 3x4, then find the gradient of the curve at the point where x = 2.
f′(x) = 4 × 3x4−1 = 12x3
At x = 2: f′(2) = 12(2)3 = 12(8) = 96
The gradient of the curve at x = 2 is 96.

Differentiating a polynomial

To differentiate a sum of terms, differentiate each term separately using the power rule: if f(x) = axn + bxm + c, then f′(x) = anxn−1 + bmxm−1 + 0, since the derivative of a constant term is 0.
Worked exampleFind dy/dx for y = x3 + 2x + 1, then find the gradient of the curve at x = 2.
dy/dx = 3x2 + 2(1)x0 + 0 = 3x2 + 2
At x = 2: dy/dx = 3(2)2 + 2 = 3(4) + 2 = 14
The gradient of the curve at x = 2 is 14.

Differentiating terms written as negative powers

Before differentiating a term written as a fraction, rewrite it using a negative exponent: a / xn = ax−n. Then apply the power rule f(x) = axn ⇒ f′(x) = anxn−1 as usual (the resulting exponent will be one less than the negative exponent you started with).
Worked exampleFind dy/dx for y = 2/x + x, then find the gradient of the curve at x = 2.
Rewrite: y = 2x−1 + x
dy/dx = (−1)(2)x−1−1 + 1 = −2x−2 + 1
At x = 2: dy/dx = −2(2)−2 + 1 = −2/4 + 1 = −0.5 + 1 = 0.5
The gradient of the curve at x = 2 is 0.5.

Marginal cost as a derivative

In applied contexts, if C(x) models total cost as a function of the quantity produced, x, then the derivative C′(x), called the marginal cost, gives the approximate cost of producing one more unit. It is found by differentiating each term of C(x) using the power rule.
Worked exampleA company's daily cost of producing x motorcycle helmets is modelled by C(x) = 600 + 7x − 0.0001x3 for 0 ≤ x ≤ 150 (in US dollars). Find C′(x), then find the marginal cost of producing 20 helmets and the marginal cost of producing 80 helmets.
C′(x) = 0 + 7 − 0.0003x2 = 7 − 0.0003x2
C′(20) = 7 − 0.0003(20)2 = 7 − 0.0003(400) = 7 − 0.12 = 6.88
C′(80) = 7 − 0.0003(80)2 = 7 − 0.0003(6400) = 7 − 1.92 = 5.08
The marginal cost is US$6.88 per helmet at x = 20, and US$5.08 per helmet at x = 80.
