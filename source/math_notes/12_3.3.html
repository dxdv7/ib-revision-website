Population variance and standard deviation

\[\text{Variance} = \sigma^2 = \frac{\sum(x - \text{mean})^2}{n}\]where \(x\) is each data value, mean is the average of all values, and \(n\) is the number of values.
\[\text{Standard deviation} = \sigma = \sqrt{\text{variance}}\]
Worked exampleFind the variance and standard deviation of: 2, 4, 4, 4, 5, 5, 7, 9.
\[n = 8, \quad \text{mean} = \frac{2+4+4+4+5+5+7+9}{8} = \frac{40}{8} = 5\]Deviations from the mean: \(-3, -1, -1, -1, 0, 0, 2, 4\)
Squared deviations: 9, 1, 1, 1, 0, 0, 4, 16, sum = 32
\[\text{Variance} = \frac{32}{8} = 4\]\[\boxed{\text{Standard deviation} = \sqrt{4} = 2}\]

Interquartile range (IQR)

\[IQR = Q_3 - Q_1\]where \(Q_1\) is the lower quartile (median of the lower half of the ordered data) and \(Q_3\) is the upper quartile (median of the upper half). The IQR measures the spread of the middle 50% of the data.
Worked exampleFind the IQR of: 3, 5, 7, 8, 9, 11, 13, 15, 17 (already ordered, \(n = 9\)).
Median (5th value) = 9
Lower half: 3, 5, 7, 8, so \(Q_1 = \frac{5+7}{2} = 6\)
Upper half: 11, 13, 15, 17, so \(Q_3 = \frac{13+15}{2} = 14\)
\[\boxed{IQR = Q_3 - Q_1 = 14 - 6 = 8}\]

Five-number summary and the box-and-whisker plot

The five-number summary is: minimum, \(Q_1\), median, \(Q_3\), maximum. A box-and-whisker plot draws a box from \(Q_1\) to \(Q_3\) (with a line at the median) and whiskers out to the minimum and maximum (non-outlier) values.
Worked exampleGive the five-number summary for: 3, 5, 7, 8, 9, 11, 13, 15, 17.
Minimum = 3
\(Q_1 = 6\)
Median = 9
\(Q_3 = 14\)
Maximum = 17
\[\boxed{\text{Five-number summary: } 3, 6, 9, 14, 17}\]

Identifying outliers

A value is an outlier if it is below \(Q_1 - 1.5 \times IQR\) (lower boundary) or above \(Q_3 + 1.5 \times IQR\) (upper boundary).
Worked exampleTest the data 12, 14, 15, 16, 18, 19, 20, 21, 50 for outliers (\(n = 9\), already ordered).
Median (5th value) = 18
Lower half: 12, 14, 15, 16, so \(Q_1 = \frac{14+15}{2} = 14.5\)
Upper half: 19, 20, 21, 50, so \(Q_3 = \frac{20+21}{2} = 20.5\)
\[IQR = 20.5 - 14.5 = 6\]\[\text{Lower boundary} = 14.5 - 1.5 \times 6 = 14.5 - 9 = 5.5\]\[\text{Upper boundary} = 20.5 + 1.5 \times 6 = 20.5 + 9 = 29.5\]Since \(50 > 29.5\), the value 50 IS an outlier.
