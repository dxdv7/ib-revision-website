Solving ax = b using logarithms

If \(a^x = b\), then \[x = \frac{\log b}{\log a}\](any consistent base, e.g. base 10 or base e), where \(a > 0\), \(a \ne 1\), and \(b > 0\).
Worked exampleSolve \(3^x = 5\) for \(x\).
Taking logarithms of both sides: \[\log(3^x) = \log 5\]\[x \log 3 = \log 5\]\[x = \frac{\log 5}{\log 3}\]\[x = \frac{0.69897}{0.47712}\]\[\boxed{x = 1.465 \text{ (3 dp)}}\]

Solving growth and decay models for time

If \(N(t) = N_0 \times b^t\), then to find the time \(t\) at which \(N\) reaches a target value: \[b^t = \frac{N}{N_0}\]so \[t = \frac{\log(N / N_0)}{\log b}\]
Worked exampleA bacteria culture is modelled by \(N(t) = 200 \times 1.15^t\), where \(N\) is the number of bacteria and \(t\) is the time in hours. Find the time taken for the population to reach 800.
\[800 = 200 \times 1.15^t\]\[4 = 1.15^t\]\[t = \frac{\log 4}{\log 1.15}\]\[t = \frac{1.386294}{0.139762}\]\[\boxed{t = 9.92 \text{ hours (3 sf)}}\]

Converting between logarithmic form and exponential form

\(\log_a b = x\) is equivalent to \(a^x = b\). In particular, \(\log x\) means \(\log_{10} x\), so \(\log x = b\) means \(x = 10^b\); and \(\ln x\) means \(\log_e x\), so \(\ln x = b\) means \(x = e^b\).
Worked examplea) Find \(x\) if \(\log x = 2.5\).
\[x = 10^{2.5}\]\[\boxed{x = 316.23 \text{ (2 dp)}}\]
b) Find \(x\) if \(\ln x = 3\).
\[x = e^3\]\[\boxed{x = 20.09 \text{ (2 dp)}}\]

Laws of logarithms

\[\log(ab) = \log a + \log b \text{ (product law)}\]\[\log\left(\frac{a}{b}\right) = \log a - \log b \text{ (quotient law)}\]\[\log(a^n) = n \log a \text{ (power law)}\]
Worked exampleGiven \(\log 2 = 0.301\) and \(\log 3 = 0.477\) (3 dp), find \(\log 6\), \(\log(2/3)\) and \(\log 9\).
\[\log 6 = \log(2 \times 3) = \log 2 + \log 3 = 0.301 + 0.477\]\[\boxed{\log 6 = 0.778}\]\[\log\left(\frac{2}{3}\right) = \log 2 - \log 3 = 0.301 - 0.477\]\[\boxed{\log\left(\frac{2}{3}\right) = -0.176}\]\[\log 9 = \log(3^2) = 2 \log 3 = 2 \times 0.477\]\[\boxed{\log 9 = 0.954}\]

Change of base formula

\[\log_a b = \frac{\log b}{\log a} = \frac{\ln b}{\ln a}\]This lets you evaluate a logarithm to any base using a GDC, which only has LOG (base 10) and LN (base e) keys.
Worked exampleEvaluate \(\log_5 12\).
\[\log_5 12 = \frac{\log 12}{\log 5}\]\[\log_5 12 = \frac{1.079181}{0.698970}\]\[\boxed{\log_5 12 = 1.544 \text{ (3 dp)}}\]
