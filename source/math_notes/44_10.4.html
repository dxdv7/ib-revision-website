Solving ax = b using logarithms

If ax = b, then x = log b / log a (any consistent base, e.g. base 10 or base e), where a > 0, a ≠ 1, and b > 0.
Worked exampleSolve 3x = 5 for x.
Taking logarithms of both sides: log(3x) = log 5
x log 3 = log 5
x = log 5 / log 3
x = 0.69897 / 0.47712
x = 1.465 (3 dp)

Solving growth and decay models for time

If N(t) = N0 × bt, then to find the time t at which N reaches a target value: bt = N / N0, so t = log(N / N0) / log b.
Worked exampleA bacteria culture is modelled by N(t) = 200 × 1.15t, where N is the number of bacteria and t is the time in hours. Find the time taken for the population to reach 800.
800 = 200 × 1.15t
4 = 1.15t
t = log 4 / log 1.15
t = 1.386294 / 0.139762
t = 9.92 hours (3 sf)

Converting between logarithmic form and exponential form

loga b = x is equivalent to ax = b. In particular, log x means log10 x, so log x = b means x = 10b; and ln x means loge x, so ln x = b means x = eb.
Worked examplea Find x if log x = 2.5.
x = 102.5
x = 316.23 (2 dp)
b Find x if ln x = 3.
x = e3
x = 20.09 (2 dp)

Laws of logarithms

log(ab) = log a + log b (product law)
log(a / b) = log a − log b (quotient law)
log(an) = n log a (power law)
Worked exampleGiven log 2 = 0.301 and log 3 = 0.477 (3 dp), find log 6, log(2/3) and log 9.
log 6 = log(2 × 3) = log 2 + log 3 = 0.301 + 0.477 = 0.778
log(2/3) = log 2 − log 3 = 0.301 − 0.477 = −0.176
log 9 = log(32) = 2 log 3 = 2 × 0.477 = 0.954

Change of base formula

loga b = log b / log a = ln b / ln a. This lets you evaluate a logarithm to any base using a GDC, which only has LOG (base 10) and LN (base e) keys.
Worked exampleEvaluate log5 12.
log5 12 = log 12 / log 5
log5 12 = 1.079181 / 0.698970
log5 12 = 1.544 (3 dp)
