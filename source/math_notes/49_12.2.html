Equation of the tangent to a curve at a point

The tangent to the curve \(y = f(x)\) at the point \((x_1, y_1)\) has gradient \(m = f'(x_1)\), and its equation is \(y - y_1 = f'(x_1)(x - x_1)\), where \(y_1 = f(x_1)\).
Worked exampleFind the equation of the tangent to the curve \(f(x) = 2x^2 - 4\) at the point where \(x = 3\).
\[y_1 = f(3) = 2(3)^2 - 4 = 18 - 4 = 14\]so the point is \((3, 14)\)
\[f'(x) = 4x\]\[f'(3) = 4(3) = 12\]\[y - 14 = 12(x - 3)\]\[\boxed{y = 12x - 22}\]

Equation of the normal to a curve at a point

The normal to the curve \(y = f(x)\) at the point \((x_1, y_1)\) is perpendicular to the tangent there. Since perpendicular gradients multiply to give \(-1\), the normal has gradient \(\dfrac{-1}{f'(x_1)}\) (provided \(f'(x_1) \ne 0\)), and its equation is \(y - y_1 = \left[\dfrac{-1}{f'(x_1)}\right](x - x_1)\).
Worked exampleFind the equation of the normal to the curve \(f(x) = 2x^3 + 3x - 2\) at the point where \(x = 1\).
\[y_1 = f(1) = 2(1)^3 + 3(1) - 2 = 2 + 3 - 2 = 3\]so the point is \((1, 3)\)
\[f'(x) = 6x^2 + 3\]\[f'(1) = 6(1)^2 + 3 = 9\]Gradient of normal \(= \dfrac{-1}{9}\)
\[y - 3 = \left(\frac{-1}{9}\right)(x - 1)\]\[\boxed{y = -\frac{1}{9}x + \frac{28}{9}}\]

Finding both the tangent and normal at the same point

At a point \((x_1, y_1)\) on \(y = f(x)\), first find \(y_1 = f(x_1)\) and the gradient \(f'(x_1)\). The tangent uses gradient \(f'(x_1)\): \(y - y_1 = f'(x_1)(x - x_1)\). The normal uses gradient \(\dfrac{-1}{f'(x_1)}\): \(y - y_1 = \left[\dfrac{-1}{f'(x_1)}\right](x - x_1)\).
Worked exampleFind the equations of the tangent and normal to the curve \(y = x^4 - 6x + 3\) at the point where \(x = 2\).
\[y_1 = (2)^4 - 6(2) + 3 = 16 - 12 + 3 = 7\]so the point is \((2, 7)\)
\[\frac{dy}{dx} = 4x^3 - 6\]so at \(x = 2\): \[4(2)^3 - 6 = 32 - 6 = 26\]Tangent: \[y - 7 = 26(x - 2) \Rightarrow \boxed{y = 26x - 45}\]Normal gradient \(= \dfrac{-1}{26}\)
Normal: \[y - 7 = \left(\frac{-1}{26}\right)(x - 2) \Rightarrow \boxed{y = -\frac{1}{26}x + \frac{92}{13}}\]

Finding an unknown coefficient from a given tangent gradient

If the gradient of the tangent to \(f(x)\) at a given point is known, set \(f'(x_1)\) equal to that gradient to form an equation in any unknown coefficients, then solve. Substitute \(x_1\) into \(f(x)\) to find any remaining unknown, such as the \(y\)-coordinate.
Worked exampleThe gradient of the tangent to the curve \(f(x) = ax^2 + 3x - 1\) at the point \((2, b)\) is \(7\). Find the values of \(a\) and \(b\).
\[f'(x) = 2ax + 3\]\[f'(2) = 4a + 3 = 7 \Rightarrow 4a = 4 \Rightarrow a = 1\]\[f(2) = (1)(2)^2 + 3(2) - 1 = 4 + 6 - 1 = 9\]so \(b = 9\)
\[\boxed{a = 1, \ b = 9}\]

Finding an unknown coefficient from a given normal gradient

If the gradient of the normal at a given point is known, the gradient of the tangent there is the negative reciprocal of it. Set \(f'(x_1)\) equal to this tangent gradient to solve for any unknown coefficients, then substitute \(x_1\) into \(f(x)\) to find any remaining unknown.
Worked exampleThe gradient of the normal to the curve \(f(x) = kx^3 - 2x + 1\) at the point \((1, b)\) is \(-\dfrac{1}{4}\). Find the values of \(k\) and \(b\).
Since the normal gradient is \(-\dfrac{1}{4}\), the tangent gradient is \(4\)
\[f'(x) = 3kx^2 - 2\]\[f'(1) = 3k - 2 = 4 \Rightarrow 3k = 6 \Rightarrow k = 2\]\[f(1) = 2(1)^3 - 2(1) + 1 = 2 - 2 + 1 = 1\]so \(b = 1\)
\[\boxed{k = 2, \ b = 1}\]

Intersection point of two normal lines

To find where two normal lines to a curve meet, find the equation of each normal separately using \(y - y_1 = \left[\dfrac{-1}{f'(x_1)}\right](x - x_1)\) at each point, then solve the two linear equations simultaneously for \(x\) and \(y\).
Worked exampleFind the point where the normals to \(f(x) = x^2\) at \(x = 2\) and \(x = -2\) meet.
At \(x = 2\): \(f(2) = 4\), \(f'(x) = 2x\) so \(f'(2) = 4\); normal gradient \(= -\dfrac{1}{4}\)
Normal 1: \[y - 4 = \left(-\frac{1}{4}\right)(x - 2) \Rightarrow y = -\frac{1}{4}x + 4.5\]At \(x = -2\): \(f(-2) = 4\), \(f'(-2) = -4\); normal gradient \(= \dfrac{1}{4}\)
Normal 2: \[y - 4 = \left(\frac{1}{4}\right)(x + 2) \Rightarrow y = \frac{1}{4}x + 4.5\]By symmetry both lines meet where \(x = 0\): \(y = 4.5\)
\[\boxed{(0, 4.5)}\]
