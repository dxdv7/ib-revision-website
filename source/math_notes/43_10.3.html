General exponential function – asymptote, y-intercept, growth or decay

For f(x) = k(a)x + c, where a > 0 and a ≠ 1: the horizontal asymptote is y = c, the y-intercept is the point (0, k + c), and the function is increasing (growth) if a > 1, or decreasing (decay) if 0 < a < 1.
Worked exampleFor f(x) = 3(2)x + 2, find (i) the horizontal asymptote, (ii) the y-intercept, (iii) state whether it is increasing or decreasing.
i) c = 2, so the asymptote is y = 2
ii) f(0) = 3(2)0 + 2 = 3(1) + 2 = 5, so the y-intercept is (0, 5)
iii) a = 2 > 1, so f(x) is increasing (growth)

For g(x) = 5(0.2)x − 3, find the same three features.
i) c = −3, so the asymptote is y = −3
ii) g(0) = 5(0.2)0 − 3 = 5(1) − 3 = 2, so the y-intercept is (0, 2)
iii) a = 0.2, and 0 < 0.2 < 1, so g(x) is decreasing (decay)

Exponential growth model from a constant percentage increase

y = a(1 + r)x, where a is the initial value (at x = 0), r is the growth rate per unit of x written as a decimal, and x is the independent continuous variable (such as time). This models a quantity that increases by a fixed percentage over each unit of x.
Worked exampleA bacteria colony starts with 500 bacteria and grows continuously at 12% per hour. The model is y = 500(1.12)x, where x is time in hours.
Find the population after 6 hours (interpolation within the modelled range).
y = 500(1.12)6 = 500 × 1.97382 = 986.91
Population ≈ 987 bacteria (3 s.f.)

Predict the population after 24 hours (extrapolation).
y = 500(1.12)24 = 500 × 15.1786 = 7589.31
Population ≈ 7590 bacteria (3 s.f.)

Exponential decay model from a constant percentage decrease

y = a(1 − r)x, where a is the initial value (at x = 0), r is the decay rate per unit of x written as a decimal, and x is the independent continuous variable. This models a quantity that decreases by a fixed percentage over each unit of x.
Worked exampleSaul buys a tractor for US$51000. Its value decreases by 8% each year, so the model is y = 51000(0.92)x, where x is time in years.
Find the value of the tractor after 4 years.
y = 51000(0.92)4 = 51000 × 0.716393
y = US$36536.04 (2 d.p.)

Using technology to find when a model reaches a target value

To find the value of x for which an exponential model y = f(x) reaches a specific target value y0, graph y = f(x) and the horizontal line y = y0 using technology, and read the x-coordinate of the point of intersection of the two graphs.
Worked exampleUsing the tractor model y = 51000(0.92)x, find how many years it takes for the tractor to be worth half its original value, US$25500.
Graph y = 51000(0.92)x and y = 25500 on your GDC.
The graphs intersect at x ≈ 8.31
It takes approximately 8.31 years (3 s.f.) for the tractor to lose half its value.

Continuous growth or decay using base e

y = a × ekx, where a is the initial value (at x = 0), k is the continuous growth rate (k > 0 for growth, k < 0 for decay), and x is the independent continuous variable.
Worked exampleA 130 g sample of a radioactive substance decays continuously according to the model m(t) = 130 × e−0.15t, where t is time in years.
Find the mass remaining after 4 years.
m(4) = 130 × e−0.15(4) = 130 × e−0.6
m(4) = 130 × 0.548812
m(4) = 71.3 g (3 s.f.)

Fitting an exponential model to data and using it to predict

If data shows an approximately constant ratio between y-values at equally spaced x-values (rather than a constant difference), an exponential model y = a(b)x can be fitted to the data using technology (exponential regression). The model can then be used to interpolate (predict within the range of the data) or extrapolate (predict beyond the range of the data).
Worked exampleThe length of a plant, in cm, is recorded every 2 weeks: (1, 5), (3, 7), (5, 11), (7, 15), (9, 23), (11, 31), (13, 45), (15, 64), (17, 92).
Using exponential regression on a GDC, the fitted model is approximately y = 4.23(1.20)x.
Use the model to estimate the length after 10 weeks (interpolation, since 10 lies between the recorded weeks 9 and 11).
y = 4.23(1.20)10 = 4.23 × 6.19174
y = 26.2 cm (3 s.f.), which is a reasonable estimate since it lies between the recorded lengths of 23 cm (week 9) and 31 cm (week 11).
