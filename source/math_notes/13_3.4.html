Pearson’s product-moment correlation coefficient (r)

\[r = \frac{S_{xy}}{\sqrt{S_{xx} \times S_{yy}}}\]where \(S_{xy} = \sum (x - \bar{x})(y - \bar{y})\), \(S_{xx} = \sum (x - \bar{x})^2\), \(S_{yy} = \sum (y - \bar{y})^2\), and \(\bar{x}\), \(\bar{y}\) are the means of \(x\) and \(y\). The value of \(r\) lies between \(-1\) and \(1\) and measures the strength and direction of the linear correlation between \(x\) and \(y\).
Worked exampleFive students recorded the number of hours they revised (\(x\)) and their test score out of 10 (\(y\)): \(x = 1, 2, 3, 4, 5\); \(y = 2, 4, 5, 4, 6\). Find \(r\).
\[\bar{x} = \frac{1+2+3+4+5}{5} = 3\]\[\bar{y} = \frac{2+4+5+4+6}{5} = 4.2\]
\[S_{xy} = (-2)(-2.2) + (-1)(-0.2) + (0)(0.8) + (1)(-0.2) + (2)(1.8) = 4.4 + 0.2 + 0 - 0.2 + 3.6 = 8.0\]
\[S_{xx} = (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4 + 1 + 0 + 1 + 4 = 10\]
\[S_{yy} = (-2.2)^2 + (-0.2)^2 + 0.8^2 + (-0.2)^2 + 1.8^2 = 4.84 + 0.04 + 0.64 + 0.04 + 3.24 = 8.8\]
\[r = \frac{8.0}{\sqrt{10 \times 8.8}} = \frac{8.0}{\sqrt{88}} = \frac{8.0}{9.381} \approx \boxed{0.853}\]This is a strong, positive linear correlation between revision hours and test score.

Covariance

\[\text{Covariance} = \frac{S_{xy}}{n} = \frac{\sum (x - \bar{x})(y - \bar{y})}{n}\]where \(n\) is the number of data pairs. A positive covariance means the two variables tend to increase together; a negative covariance means one tends to increase as the other decreases.
Worked exampleUsing the revision data above, where \(n = 5\) and \(S_{xy} = 8.0\), find the covariance.
\[\text{Covariance} = \frac{8.0}{5} = \boxed{1.6}\]The positive value confirms that test score tends to rise as revision hours rise.

Equation of the regression line (line of best fit)

The least-squares regression line of \(y\) on \(x\) is \(y = mx + c\), where the gradient
\[m = \frac{S_{xy}}{S_{xx}}\]and the intercept \(c = \bar{y} - m\bar{x}\). This line always passes through the point \((\bar{x}, \bar{y})\).
Worked exampleUsing the revision data (\(S_{xy} = 8.0\), \(S_{xx} = 10\), \(\bar{x} = 3\), \(\bar{y} = 4.2\)), find the regression line.
\[m = \frac{S_{xy}}{S_{xx}} = \frac{8.0}{10} = 0.8\]\[c = \bar{y} - m\bar{x} = 4.2 - (0.8 \times 3) = 4.2 - 2.4 = 1.8\]The regression line is
\[\boxed{y = 0.8x + 1.8}\]

Using the regression line to make predictions

To predict a \(y\)-value, substitute the chosen \(x\) into the regression equation. The prediction is called interpolation if \(x\) lies within the range of the original data, and extrapolation if \(x\) lies outside that range; extrapolated predictions are less reliable.
Worked exampleThe revision data covered \(x\) from 1 to 5 hours, giving the line \(y = 0.8x + 1.8\). Predict the score for a student who revises for 4 hours, and for a student who revises for 8 hours.
4 hours (interpolation, within the data range):
\[y = 0.8(4) + 1.8 = 3.2 + 1.8 = \boxed{5}\]8 hours (extrapolation, outside the data range):
\[y = 0.8(8) + 1.8 = 6.4 + 1.8 = \boxed{8.2}\]The prediction for 8 hours is less reliable because it extrapolates beyond the original data.
