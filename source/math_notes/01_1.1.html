Estimating a product by rounding to 1 significant figure

To estimate the value of a multiplication, round each number in the calculation to 1 significant figure (unless told to use a different precision) before multiplying: estimate = (first value rounded to 1sf) \(\times\) (second value rounded to 1sf).
Worked exampleEstimate the value of \(48.7 \times 21.3\).
Round each number to 1 significant figure: \(48.7 \approx 50\) and \(21.3 \approx 20\).
\[\boxed{\text{Estimate} = 50 \times 20 = 1000}\]The exact value (by calculator) is 1040 to 3sf, so the estimate is a reasonable approximation.

Estimating a quotient by rounding to 1 significant figure

To estimate the value of a division, round each number to 1 significant figure before dividing: estimate = (first value rounded to 1sf) \(\div\) (second value rounded to 1sf).
Worked exampleEstimate the value of \(723 \div 38.4\).
Round each number to 1 significant figure: \(723 \approx 700\) and \(38.4 \approx 40\).
\[\boxed{\text{Estimate} = 700 \div 40 = 17.5}\]The exact value is 18.8 to 3sf, so the estimate is close to the exact value.

Estimating a calculation with more than one operation

For a calculation with several numbers and operations, round every number to 1 significant figure first, then carry out the operations in the usual order: estimate = full calculation using each value rounded to 1sf.
Worked exampleEstimate the value of \((52.3 \times 8.7) \div 3.2\).
Round each number to 1 significant figure: \(52.3 \approx 50\), \(8.7 \approx 9\), \(3.2 \approx 3\).
\[\boxed{\text{Estimate} = (50 \times 9) \div 3 = 450 \div 3 = 150}\]The exact value is 142 to 3sf, so the estimate is a reasonable approximation.

Estimating using a stated level of precision

An estimate can also be made by rounding each value to a different stated precision (for example, 2 significant figures) instead of 1 significant figure, if the question specifies this: estimate = calculation using each value rounded to the stated precision.
Worked exampleEstimate the value of \(6.283 \times 194\), rounding each number to 2 significant figures.
\(6.283 \approx 6.3\) and \(194 \approx 190\).
\[\text{Estimate} = 6.3 \times 190 = 1197\]\[\boxed{\text{Estimate} \approx 1200 \text{ (3sf)}}\]The exact value is 1220 to 3sf, so the estimate is close to the exact value.

Comparing an estimate with a real-world calculation

In real-world problems, such as cost calculations, the same process applies: round each value to 1 significant figure to find a quick estimate, then compare it with the exact calculator value.
Worked exampleA shop sells 32 identical items at $4.85 each. Estimate the total cost.
Round each number to 1 significant figure: \(32 \approx 30\) and \(4.85 \approx 5\).
\[\boxed{\text{Estimate} = 30 \times 5 = 150}\] (that is, $150).
The exact cost is \(32 \times 4.85 = 155.20\) (that is, $155.20), so the estimate is close to, but lower than, the exact value.
