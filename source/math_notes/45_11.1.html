Period of a periodic function

A function f(x) is periodic with period T if f(x + T) = f(x) for all x, where T is the length of the shortest interval after which the function's values repeat exactly.
Worked exampleA periodic function f(x) satisfies f(x) = f(x + 12) for all x, and no smaller repeat length works. State the period, then use it to find f(37) given that f(1) = 9.
Period T = 12
37 = 1 + 3(12) = 1 + 36, so f(37) = f(1) = 9

Frequency and its relationship to period

Frequency f = 1 / T, where T is the period. Equivalently, period T = 1 / f. Frequency measures the number of complete cycles per unit of the independent variable.
Worked exampleA periodic electrical current repeats every 2 milliseconds. Find its frequency in cycles per millisecond.
T = 2
f = 1 / T = 1 / 2 = 0.5 cycles per millisecond
Worked exampleA periodic signal has a frequency of 4 cycles per second. Find its period.
f = 4
T = 1 / f = 1 / 4 = 0.25 seconds

Reading the maximum, minimum and zeros directly from a periodic graph or table

For a periodic function given by a graph or a table of values, the maximum value and the x-values at which it occurs, the minimum value and the x-values at which it occurs, and the zeros (x-values where the function equals 0) can be read directly, then extended to further cycles by repeatedly adding or subtracting the period T.
Worked exampleA periodic function has period 8, a maximum value of 15 at x = 2, and a minimum value of 3 at x = 6, over one cycle 0 ≤ x < 8. State the maximum value and one further x-value (greater than 8) at which it occurs.
Maximum value = 15 at x = 2
Next occurrence: x = 2 + T = 2 + 8 = 10

Sine of an obtuse angle in terms of the related acute angle

For 0° ≤ θ ≤ 180°, sin(θ) = sin(180° − θ), so an obtuse angle and its supplement (180° minus the angle) have the same sine value.
Worked exampleGiven that sin(34°) = 0.559 (3 sf), find sin(146°) without a calculator.
146° = 180° − 34°
sin(146°) = sin(180° − 34°) = sin(34°) = 0.559

Cosine of an obtuse angle in terms of the related acute angle

For 0° ≤ θ ≤ 180°, cos(180° − θ) = −cos(θ), so an obtuse angle's cosine is the negative of its supplement's cosine.
Worked exampleGiven that cos(40°) = 0.766 (3 sf), find cos(140°).
140° = 180° − 40°
cos(140°) = −cos(40°) = −0.766

Solving sin θ = k for a given domain

To solve sin θ = k for 0° ≤ θ < 360°, find the principal value θ1 = sin−1(k), then the second solution (when it exists in the domain) is θ2 = 180° − θ1. If k is negative, both solutions lie between 180° and 360°.
Worked exampleSolve sin θ = 0.6 for 0° ≤ θ < 360°.
θ1 = sin−1(0.6) = 36.9° (3 sf)
θ2 = 180° − 36.9° = 143° (3 sf)
Solutions: θ = 36.9° or θ = 143°

Solving cos θ = k for a given domain

To solve cos θ = k for 0° ≤ θ < 360°, find the principal value θ1 = cos−1(k), then the second solution is θ2 = 360° − θ1.
Worked exampleSolve cos θ = −0.1 for 0° ≤ θ < 360°.
θ1 = cos−1(−0.1) = 95.7° (3 sf)
θ2 = 360° − 95.7° = 264° (3 sf)
Solutions: θ = 95.7° or θ = 264°

Locating a point on a circular path using sine and cosine

For a point moving on a circle of radius r, centred at the origin, with θ measured anticlockwise from the positive x-axis, the height above the x-axis is r sin(θ) and the horizontal distance to the right of the y-axis is r cos(θ).
Worked exampleA Ferris wheel pod moves on a circle of radius 70 m, with θ measured anticlockwise from the x-axis. Find all values of θ (0° ≤ θ < 360°) for which the pod is 40 m above the x-axis.
r sin(θ) = 40
sin(θ) = 40 / 70 = 0.571
θ1 = sin−1(0.571) = 34.8° (3 sf)
θ2 = 180° − 34.8° = 145° (3 sf)
Solutions: θ = 34.8° or θ = 145°
