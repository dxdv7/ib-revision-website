Period of a periodic function

A function \(f(x)\) is periodic with period \(T\) if \(f(x + T) = f(x)\) for all \(x\), where \(T\) is the length of the shortest interval after which the function's values repeat exactly.
Worked exampleA periodic function \(f(x)\) satisfies \(f(x) = f(x + 12)\) for all \(x\), and no smaller repeat length works. State the period, then use it to find \(f(37)\) given that \(f(1) = 9\).
Period \(T = 12\)
\[37 = 1 + 3(12) = 1 + 36\]so \(f(37) = f(1) = \boxed{9}\)

Frequency and its relationship to period

Frequency \[f = \frac{1}{T}\]where \(T\) is the period. Equivalently, period \[T = \frac{1}{f}\]Frequency measures the number of complete cycles per unit of the independent variable.
Worked exampleA periodic electrical current repeats every 2 milliseconds. Find its frequency in cycles per millisecond.
\(T = 2\)
\[f = \frac{1}{T} = \frac{1}{2}\]\[\boxed{f = 0.5 \text{ cycles per millisecond}}\]
Worked exampleA periodic signal has a frequency of 4 cycles per second. Find its period.
\(f = 4\)
\[T = \frac{1}{f} = \frac{1}{4}\]\[\boxed{T = 0.25 \text{ seconds}}\]

Reading the maximum, minimum and zeros directly from a periodic graph or table

For a periodic function given by a graph or a table of values, the maximum value and the x-values at which it occurs, the minimum value and the x-values at which it occurs, and the zeros (x-values where the function equals 0) can be read directly, then extended to further cycles by repeatedly adding or subtracting the period \(T\).
Worked exampleA periodic function has period 8, a maximum value of 15 at \(x = 2\), and a minimum value of 3 at \(x = 6\), over one cycle \(0 \le x < 8\). State the maximum value and one further x-value (greater than 8) at which it occurs.
Maximum value = 15 at \(x = 2\)
Next occurrence: \[x = 2 + T = 2 + 8\]\[\boxed{x = 10}\]

Sine of an obtuse angle in terms of the related acute angle

For \(0^{\circ} \le \theta \le 180^{\circ}\), \[\sin(\theta) = \sin(180^{\circ} - \theta)\]so an obtuse angle and its supplement (\(180^{\circ}\) minus the angle) have the same sine value.
Worked exampleGiven that \(\sin(34^{\circ}) = 0.559\) (3 sf), find \(\sin(146^{\circ})\) without a calculator.
\[146^{\circ} = 180^{\circ} - 34^{\circ}\]\[\sin(146^{\circ}) = \sin(180^{\circ} - 34^{\circ}) = \sin(34^{\circ})\]\[\boxed{\sin(146^{\circ}) = 0.559}\]

Cosine of an obtuse angle in terms of the related acute angle

For \(0^{\circ} \le \theta \le 180^{\circ}\), \[\cos(180^{\circ} - \theta) = -\cos(\theta)\]so an obtuse angle's cosine is the negative of its supplement's cosine.
Worked exampleGiven that \(\cos(40^{\circ}) = 0.766\) (3 sf), find \(\cos(140^{\circ})\).
\[140^{\circ} = 180^{\circ} - 40^{\circ}\]\[\cos(140^{\circ}) = -\cos(40^{\circ})\]\[\boxed{\cos(140^{\circ}) = -0.766}\]

Solving sin θ = k for a given domain

To solve \(\sin \theta = k\) for \(0^{\circ} \le \theta < 360^{\circ}\), find the principal value \[\theta_1 = \sin^{-1}(k)\]then the second solution (when it exists in the domain) is \[\theta_2 = 180^{\circ} - \theta_1\]If \(k\) is negative, both solutions lie between \(180^{\circ}\) and \(360^{\circ}\).
Worked exampleSolve \(\sin \theta = 0.6\) for \(0^{\circ} \le \theta < 360^{\circ}\).
\[\theta_1 = \sin^{-1}(0.6) = 36.9^{\circ} \text{ (3 sf)}\]\[\theta_2 = 180^{\circ} - 36.9^{\circ} = 143^{\circ} \text{ (3 sf)}\]Solutions: \(\boxed{\theta = 36.9^{\circ} \text{ or } \theta = 143^{\circ}}\)

Solving cos θ = k for a given domain

To solve \(\cos \theta = k\) for \(0^{\circ} \le \theta < 360^{\circ}\), find the principal value \[\theta_1 = \cos^{-1}(k)\]then the second solution is \[\theta_2 = 360^{\circ} - \theta_1\]
Worked exampleSolve \(\cos \theta = -0.1\) for \(0^{\circ} \le \theta < 360^{\circ}\).
\[\theta_1 = \cos^{-1}(-0.1) = 95.7^{\circ} \text{ (3 sf)}\]\[\theta_2 = 360^{\circ} - 95.7^{\circ} = 264^{\circ} \text{ (3 sf)}\]Solutions: \(\boxed{\theta = 95.7^{\circ} \text{ or } \theta = 264^{\circ}}\)

Locating a point on a circular path using sine and cosine

For a point moving on a circle of radius \(r\), centred at the origin, with \(\theta\) measured anticlockwise from the positive x-axis, the height above the x-axis is \(r \sin(\theta)\) and the horizontal distance to the right of the y-axis is \(r \cos(\theta)\).
Worked exampleA Ferris wheel pod moves on a circle of radius 70 m, with \(\theta\) measured anticlockwise from the x-axis. Find all values of \(\theta\) (\(0^{\circ} \le \theta < 360^{\circ}\)) for which the pod is 40 m above the x-axis.
\[r \sin(\theta) = 40\]\[\sin(\theta) = \frac{40}{70} = 0.571\]\[\theta_1 = \sin^{-1}(0.571) = 34.8^{\circ} \text{ (3 sf)}\]\[\theta_2 = 180^{\circ} - 34.8^{\circ} = 145^{\circ} \text{ (3 sf)}\]Solutions: \(\boxed{\theta = 34.8^{\circ} \text{ or } \theta = 145^{\circ}}\)
