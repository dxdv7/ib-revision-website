Percentage error

Percentage error = |(VA − VE) / VE| × 100%, where VA is the approximate (measured) value and VE is the exact (true) value.
Worked exampleThe fraction 22/7 is often used as an approximation for π.
22/7 = 3.142857... (approximate value) and π = 3.141593... (exact value, 6 dp)
Percentage error = |(3.142857... − 3.141593...) / 3.141593...| × 100%
= |0.001264... / 3.141593...| × 100%
= 0.0402...%
Percentage error ≈ 0.04% (correct to 2 dp)

Upper and lower bounds of a rounded measurement

If a measurement is rounded to a given precision (the smallest unit of rounding), then lower bound = rounded value − (precision / 2), and upper bound = rounded value + (precision / 2). The exact value V lies in the interval: lower bound ≤ V < upper bound.
Worked exampleJane's weight is 68 kg, correct to the nearest kg (precision = 1 kg).
Lower bound = 68 − 0.5 = 67.5 kg
Upper bound = 68 + 0.5 = 68.5 kg
So 67.5 kg ≤ weight < 68.5 kg

Majid's 100 m running time is 11.3 seconds, correct to the nearest tenth of a second (precision = 0.1 s).
Lower bound = 11.3 − 0.05 = 11.25 s
Upper bound = 11.3 + 0.05 = 11.35 s
So 11.25 s ≤ time < 11.35 s

Bounds of a quantity calculated from rounded measurements

For a quantity that increases as each measurement increases (such as a sum, perimeter, or area), the upper bound of the calculated quantity is found using the upper bounds of all the measurements, and the lower bound is found using the lower bounds of all the measurements.
Worked exampleA rectangular garden plot is measured as 172 m by 64 m, each correct to the nearest metre.
Length: 171.5 m ≤ L < 172.5 m
Width: 63.5 m ≤ W < 64.5 m
Lower bound of perimeter = 2 × (171.5 + 63.5) = 2 × 235 = 470 m
Upper bound of perimeter = 2 × (172.5 + 64.5) = 2 × 237 = 474 m
So 470 m ≤ P < 474 m

Lower bound of area = 171.5 × 63.5 = 10890.25 m2
Upper bound of area = 172.5 × 64.5 = 11126.25 m2
So 10890.25 m2 ≤ A < 11126.25 m2

Avoiding premature rounding in multistep calculations

Density = mass / volume. In any multistep calculation, intermediate results should be kept with full accuracy (unrounded) and only the final answer should be rounded, since rounding intermediate values introduces extra error into the final result.
Worked exampleA cube of sugar has mass 2.45 g and side length 1.2 cm, correct to 1 dp.
Correct method (round only the final answer):
Volume = 1.23 = 1.728 cm3 (unrounded)
Density = 2.45 / 1.728 = 1.41782... g/cm3 = 1.4 g/cm3 (correct to 1 dp)

Incorrect method (rounding intermediate values first):
Round the volume to 1 dp first: 1.728 → 1.7 cm3
Density = 2.45 / 1.7 = 1.470588... g/cm3 = 1.5 g/cm3 (correct to 1 dp)
This premature rounding gives 1.5 g/cm3 instead of the correct 1.4 g/cm3, a percentage error of |1.5 − 1.41782...| / 1.41782... × 100% ≈ 5.80%
